# 账号包装

一个陌生人刷到你的某条视频，觉得有用，点进主页。接下来几秒钟他要决定：关注，还是退出。这几秒钟里他看到的就是账号包装：名字、头像、简介、背景图、置顶和合集。

包装的目标只有一个：**让刚点进来的人立刻确认「这个账号会持续给我想要的东西」**。它不负责好看，也不负责体现你的个性，它负责把第 1 章的一页定位卡翻译成主页上的六个位置。

简介文案的通用写法（一句话定位、怎么写自己）见[《文案与内容》第 6 章](../copywriting-content/06-personal-brand.md)「个人品牌」，这一章只讲短视频平台主页上的具体位置和规则。

## 先看规则：哪些东西不能放

包装出问题，轻则资料被重置，重则账号被处置。下面几条来自监管文件和平台公告，动手前先过一遍：

| 规则 | 来源 | 对包装的影响 |
|---|---|---|
| 个人账号的职业信息要与真实职业一致 | 《互联网用户账号信息管理规定》，国家网信办，2022-08-01 施行 | 名字和简介里的职业、身份要真实 |
| 账号信息包括名称、头像、封面、简介、签名、认证信息等 | 同上 | 这些位置都在监管范围内，不只是名字 |
| 金融、教育、医疗卫生、司法等领域要资质认证并展示 | 《关于加强「自媒体」管理的通知》，2023-07 | 没认证就别在这些领域挂专业身份 |
| 未认证加注「知名经济学家」「资深法律顾问」等头衔、在头像或背景图里用军警服或医用工作服冒充职业人员，属于整治对象 | 「清朗·整治账号名称信息乱象」专项行动通知，中国网信网，2026-06-18 | 头像、背景图不要用制服、白大褂等职业形象来暗示身份 |
| 小红书处置违规个人资料信息、关闭仿冒账号，涉及头像暗嵌违规引流信息等 | IT之家，2026-07-17 | 头像和背景图里不要藏联系方式 |

另外，各平台对主页里留站外联系方式（微信号、手机号、谐音、二维码）都限制得很严，具体见[《国内私域与内容平台》第 5 章](../private-domain-cn/05-douyin-bilibili.md)「抖音与 B 站」和第 3 章「小红书」。

改名、改头像的次数和间隔限制，各平台有规定但没有找到统一的官方公开说明，以 App 内「编辑资料」页面的提示为准。实际操作上的建议是：**定好之后至少一两个月不要改**，频繁改动会让老观众认不出你，也可能触发审核。

## 名字

### 原则

1. **让人看名字就知道讲什么**。新号没有知名度，名字是唯一能免费传递定位的地方
2. **好记、好搜、好念**。别人想推荐你时，能用嘴说出来；想找你时，能在搜索框里打出来
3. **不和对标撞名，不碰瓷名人和品牌**

### 常见结构

| 结构 | 例子（均为虚构） | 适合 |
|---|---|---|
| 称呼 + 领域词 | 「阿杰聊 AI 办公」「老周讲表格」 | 有人设、想做个人 IP |
| 领域词 + 结果 | 「表格不加班」「三分钟会 AI」 | 不出镜、工具型内容 |
| 身份 + 领域 | 「程序员小林的 AI 工具箱」 | 身份本身就是信任来源 |
| 纯昵称 | 「小林」 | 已经有知名度的人；新号不推荐 |

### 正例和反例

| 反例 | 问题 | 改成 |
|---|---|---|
| 「Jarvis_2026」 | 看不出领域，英文 + 数字难搜 | 「阿杰聊 AI 办公」 |
| 「AI 赚钱研究院」 | 「研究院」暗示机构身份；「赚钱」容易被归入夸大收益类 | 「程序员试 AI 副业」，并且如实讲收入和花费 |
| 「Excel 官方教程」 | 冒充品牌官方，属于仿冒 | 「老周讲表格」 |
| 「表格不加班 2 号」 | 碰瓷对标，观众会以为是小号或山寨 | 起一个自己的名字 |
| 「💻阿杰💻AI✨办公🔥」 | 符号太多，搜不到、念不出 | 「阿杰聊 AI 办公」 |
| 「资深架构师老王」 | 如果不是真的，就是虚构职业身份 | 只写真实身份，或者去掉头衔 |

### 起名的检查步骤

```text
1. 写出 10 个候选名，每个都按上表的结构之一
2. 每个候选在主平台搜一遍：有没有重名？有没有很像的大号？
3. 把候选念给一个朋友听，让他打在手机上：能不能一次打对？
4. 去掉含「官方」「研究院」「首席」「导师」「专家」等词的候选
5. 剩下的里面，选最能让陌生人猜出「这个号讲什么」的那个
```

## 头像

头像在信息流里只有一个很小的圆形，所以只要求两点：**缩小后还认得出、和定位一致**。

| 定位 | 推荐 | 不推荐 |
|---|---|---|
| 真人出镜 | 本人清晰的半身照，背景干净，和视频里形象一致 | 风景照、宠物、远景全身照 |
| 不出镜 | 一个简洁的图形或文字标识，颜色和视频字幕风格统一 | 网上找的明星、动漫角色图（版权和仿冒风险） |
| AI 画面 | 账号自己的 AI 角色形象，并在简介里说明是 AI 形象 | 用 AI 生成一张逼真的「真人照片」冒充本人 |

额外注意：

- 不出镜的账号，头像里放 1–2 个字（「表」「AI」）比放完整名字更容易认，字太多缩小后看不清
- 头像里不要嵌二维码、微信号、谐音，上面的规则表已经说过，这是平台明确在处置的行为
- 不要用工牌照、公司门口的照片做头像

## 简介

简介是主页上信息密度最高的位置。一个可以直接套用的结构：

```text
第 1 行：身份（真实） + 专长证据
第 2 行：这个账号讲什么（人群 + 需求）
第 3 行：更新节奏或栏目
第 4 行（可选）：合规的合作入口，如「商务合作请私信」或平台提供的官方组件
```

示例：

```text
在职 8 年后端程序员｜写过几百个自动化小脚本
教上班族用 AI 收拾乱七八糟的表格｜Excel / WPS / Mac 都讲
每周二、四、六更新
```

### 正例和反例

| 反例 | 问题 |
|---|---|
| 「热爱生活，记录美好」 | 没有任何定位信息 |
| 「带你月入过万｜0 基础包会」 | 收益承诺和效果保证，涉及虚假宣传风险 |
| 「AI 领域顶级专家」 | 无法证明的最高级表述，也是监管整治的「包装权威形象」 |
| 「V：jie_ai2026」 | 直接留站外联系方式，违反平台导流规则 |
| 「前 XX 大厂员工」 | 如果是真的可以写，但想清楚要不要暴露前雇主；涉及在职公司则不建议写 |
| 十几行长文，讲自己的人生经历 | 主页上一屏看不完，关键信息被淹没 |

## 背景图

背景图（主页头图）位置大、被看到的次数多，但很多人留空或随便放一张风景。它适合放**一句补充简介的话**或**栏目导航**：

| 写法 | 例子 |
|---|---|
| 价值承诺 | 「每条只解决一个表格问题」 |
| 栏目导航 | 「合集：AI 理表格｜WPS 专区｜Mac 专区」 |
| 行动引导 | 「先看置顶三条」 |

注意事项：

- 主页头图在不同手机上会被裁切，文字放在中间区域，四周留空
- 不要放制服、证件、奖状等暗示身份的图，除非是真的并且该领域不需要资质认证
- 不要放联系方式

## 置顶

多数平台允许在主页置顶少量作品（具体数量以平台为准）。置顶是新访客最先看到的内容，作用是**替你回答「这个账号值不值得关注」**。

置顶的三种思路：

| 思路 | 放什么 | 适合 |
|---|---|---|
| 代表作 | 数据最好的 2–3 条 | 已经有几条跑出来的作品 |
| 入门导航 | 「先看这条」：介绍账号讲什么、栏目有哪些 | 栏目多、内容成体系的账号 |
| 最能体现差异的 | 你和对标最不一样的那条 | 冷启动期，还没有爆款时 |

冷启动期（前 30 条）建议：

- 前 10 条：不急着置顶，或者置顶一条「账号介绍」
- 第 10–30 条：把数据相对最好的、最能代表定位的 2–3 条置顶
- 每两周看一次：如果新作品比置顶的更能代表你，就换

### 反例

- 置顶一条和定位无关的爆款（比如做表格的账号置顶了一条宠物视频，因为它点赞最高）：新访客以为你讲宠物，关注了也会很快取关
- 置顶广告合作内容：新访客第一眼看到的是广告
- 置顶三条都是同一个选题的不同版本：浪费位置

## 合集

合集（各平台叫法不同，如合集、专辑、系列）把作品按主题归档，对工具型、教程型账号尤其重要：观众看完一条，会顺着合集一直看下去。

### 合集怎么设计

| 原则 | 正例 | 反例 |
|---|---|---|
| 按观众的问题分，而不是按你的内容类型分 | 「表头乱了怎么办」「月底对账」「WPS 专区」 | 「教程」「分享」「日常」 |
| 名字说清楚是什么 | 「AI 理表格：从乱到整齐」 | 「第一季」 |
| 有足够条数再开 | 至少有 3–5 条再建合集 | 开了 8 个合集，每个只有 1 条 |
| 合集之间不重叠 | 三个合集分别对应三个场景 | 「AI」合集和「AI 工具」合集 |

合集数量建议：冷启动期 1–3 个，跟着你的内容支柱走（内容支柱在第 6 章讲）。

## 包装一致性检查

六个位置做完后，把主页截图发给一个不认识你的朋友，问他三个问题：

```text
1. 这个账号是讲什么的？
2. 适合什么人关注？
3. 你觉得下一条会发什么？
```

三个答案都和你的一页定位卡一致，包装才算合格。不一致的地方，回到对应位置改。

最后对照下表逐项打勾：

| 位置 | 检查项 | 通过 |
|---|---|---|
| 名字 | 能看出领域；没有「官方」「专家」等词；搜得到、念得出 | |
| 头像 | 缩小后认得出；与出镜形式一致；没有联系方式和职业制服 | |
| 简介 | 有身份 + 讲什么 + 更新节奏；无收益承诺、无最高级、无联系方式 | |
| 背景图 | 文字在中间安全区；与简介互补 | |
| 置顶 | 代表定位，不是无关爆款或广告 | |
| 合集 | 按观众问题命名；每个至少 3 条 | |
| 整体 | 陌生人能答对三个问题 | |

## 本章要点

- 包装只有一个目标：让点进主页的人立刻确认这个账号会持续给他想要的东西
- 名称、头像、简介、背景图都在《互联网用户账号信息管理规定》的监管范围内；职业信息要真实，未认证不挂专业头衔，不用制服暗示身份，不藏联系方式
- 名字要能看出领域、好搜好念，不碰瓷、不冒充；头像缩小后要认得出
- 简介按「身份 + 讲什么 + 更新节奏」写，避开收益承诺和最高级
- 置顶放最能代表定位的作品，不放无关爆款和广告；合集按观众的问题命名，有 3 条以上再开
- 做完找陌生人回答三个问题来检验，定好之后一两个月内不要频繁改

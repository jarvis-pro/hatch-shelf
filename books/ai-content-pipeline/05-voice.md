# 声音：TTS、配音与音色授权

声音在短视频里的分量常被低估。画面差一点观众能忍，声音难听、吞字、读错字，观众会直接划走。AI 语音合成（TTS）这两年的进步，让不出镜、不想用自己声音的账号也能有一条听得过去的旁白；音色克隆让你可以用自己的声音批量配音，不用每条都对着麦克风录。

但声音也是 AI 内容里法律风险最集中的地方之一：用别人的声音，即使是 AI 合成的，也可能构成侵权。这一章讲 TTS 怎么选、稿子怎么写给机器念、怎么克隆自己的声音，以及用别人声音的授权问题。语音合成的技术原理见[《多模态应用》第 5 章](../multimodal-ai/05-speech.md)，AI 短剧多角色配音和口型同步见[《AI 短剧后期》](../ai-drama-post/)。

## 自媒体里声音的几种用法

| 用法 | 典型账号 | AI 的作用 |
|---|---|---|
| 旁白配音 | 知识科普、书单、影视解说、图文转视频 | TTS 直接合成 |
| 自己声音的批量配音 | 有固定人设但不想每条都录的博主 | 克隆自己的音色，再用 TTS 合成 |
| 多语种版本 | 出海、双语账号 | 翻译 + 多语种 TTS 或保留音色的跨语种合成 |
| 声音修复 | 所有自录口播 | 降噪、去混响、人声增强 |
| 背景音乐和音效 | 所有视频 | AI 音乐生成，或平台曲库 |

## TTS 选型

> [!WARNING]
> 下表按截至 2026-11 的公开资料整理，能力和价格以各服务官网和定价页为准。

截至 2026 年 11 月，中文 TTS 的主要选择：

| 类型 | 代表 | 特点 |
|---|---|---|
| 剪辑软件内置配音 | 剪映等 | 零门槛，音色多；但热门音色被大量使用，辨识度低 |
| 国内大模型语音 | 豆包语音 / 火山引擎、MiniMax 语音、阿里云、腾讯云、讯飞 | 中文自然度高，情绪和语气可控，有声音复刻，API 按字符计费 |
| 开源 | CosyVoice（阿里）等 | 可本地部署，零样本音色复刻，适合量大或有私有化需求 |
| 海外 | ElevenLabs 等 | 多语种和情绪表现强，中文略弱于国内头部，适合出海 |

选型时用同一段 200 字的稿子在几家横向试听，重点听：

1. **多音字和数字**：「重新」「银行」「行长」「2026 年」「3.5 万」「50%」读得对不对
2. **中英混读**：「SaaS」「DOU+」「iPhone」读成什么
3. **长句的气口**：是否在不该停的地方停、该停的地方不停
4. **情绪可控性**：能不能用参数或文字指令让它「轻松一点」「严肃一点」「语速快一点」
5. **音色的辨识度**：这个音色是不是已经在你刷到的视频里出现过几百次

最后一条值得多说一句。某些剪辑软件的默认热门音色，观众一听就知道「又是一个模板号」。如果账号想长期做，**声音是人设的一部分**，要么用自己的声音（真录或克隆），要么选一个不那么泛滥的音色并长期固定下来。

## 稿子要写给机器念

同一份稿子，给人念和给 TTS 念的写法不同。TTS 的常见错误几乎都来自稿子：

| 问题 | 例子 | 改法 |
|---|---|---|
| 数字读法 | 「2026」可能读成「两千零二十六」 | 按想要的读法写：「二零二六年」 |
| 多音字 | 「重新」「长大」「行业」 | 用服务支持的音标或发音词典；或换个说法 |
| 英文缩写 | 「SaaS」 | 写成「萨斯」或者服务支持的发音标注 |
| 符号 | 「%」「~」「/」 | 写成「百分之」「到」「或者」 |
| 长句 | 一句话 40 个字 | 拆成两句，句号是 TTS 最可靠的停顿 |
| 括号和注释 | 「（见下图）」 | 删掉，那是给眼睛看的 |

可以用一个提示词把口播稿转成「朗读稿」：

```text
把下面的口播稿改写成给语音合成用的朗读稿。

规则：
1. 不改变意思和用词风格，只处理读法
2. 阿拉伯数字按口语读法写成汉字，年份逐字读（「二零二六年」），金额和数量按位读（「三点五万」）
3. 百分号、斜杠、波浪号等符号改成文字
4. 英文缩写按下面的发音表替换：{{SaaS=萨斯，DOU+=逗加，V2EX=V二EX}}
5. 超过 25 字的句子在自然停顿处拆成两句
6. 删除括号内的注释和「见下图」类提示
7. 在需要强调或换气的地方用「……」标出较长的停顿

输出两栏：原句 | 朗读稿句子，最后输出完整朗读稿。
```

注意：**字幕用原稿，配音用朗读稿**。字幕上显示「2026 年」「SaaS」更易读，配音念「二零二六年」「萨斯」更自然。流水线里两份稿子要分开存，第 7 章的数据结构里会体现。

### 发音词典

量大时，把高频读法问题沉淀成一个发音词典，合成前用代码统一替换，比每次让模型改更稳定：

```ts
// pronounce.ts —— 合成前的确定性替换（示例代码，未在生产环境跑过）
const DIGITS = "零一二三四五六七八九";

type Rule = [RegExp, string | ((match: string, ...groups: string[]) => string)];

const LEXICON: Rule[] = [
  [/SaaS/g, "萨斯"],
  [/DOU\+/g, "逗加"],
  [/(\d+)%/g, "百分之$1"],
  // 年份逐字读：2026年 -> 二零二六年
  [/(\d{4})年/g, (_m, y) => [...y].map((d) => DIGITS[Number(d)]).join("") + "年"],
];

export function toReadable(text: string): string {
  return LEXICON.reduce(
    (out, [pattern, rep]) =>
      typeof rep === "string" ? out.replace(pattern, rep) : out.replace(pattern, rep),
    text,
  );
}
```

很多 TTS 服务也支持在请求里传自定义发音词典或 SSML 标注，能用服务端的就优先用服务端的，读法更准。

## 情绪和节奏

一整段稿子一次合成，常见问题是从头到尾一个调子。改善办法：

- **分段合成**：按段落（对应画面）分别合成，每段可以设不同的语速和情绪参数，再在剪辑里拼接
- **语速**：中文口播常见在每分钟 200–260 字之间，知识类偏慢、资讯类偏快。先用自己的对标账号掐表算一下
- **停顿**：段落之间留 0.3–0.6 秒，强调词前留一个短停顿。TTS 默认的段间停顿往往太短
- **试听三遍**：一遍闭眼听自然度，一遍对着字幕查错读，一遍配上画面看节奏

## 克隆自己的声音

用自己的声音做克隆，是兼顾「人设」和「产能」的办法：重要的视频自己录，量大的日常内容用克隆音色合成。

主流服务的声音复刻流程大致相同：

```mermaid
flowchart LR
  A["实名认证"] --> B["录制样本<br/>按服务要求朗读指定文本"]
  B --> C["声纹核验<br/>确认是本人"]
  C --> D["训练音色"]
  D --> E["试听调整"]
  E --> F["在账号内使用"]
```

很多国内服务要求**朗读平台指定的文本**，这是为了核验是本人在录，防止拿别人的录音去克隆。这个环节不要想办法绕过，它就是在保护你和别人。

录样本的要点：

- 安静的房间，关掉空调和风扇，手机录音也行，但不要离嘴太远
- 用你平时做视频的语气和语速，而不是播音腔；克隆出来的就是这个状态
- 样本时长按服务要求，一般十几秒到几分钟不等，样本越干净，效果越好

用克隆音色要注意两件事：

1. **账号安全**。克隆音色存在你的账号里，账号泄露意味着别人可以用你的声音说任何话。开二次验证，不要把账号借给别人
2. **依然要标识**。用克隆的自己的声音合成的配音，仍然是 AI 生成的音频内容。观众以为是你本人在说话，而实际是合成的，这正是标识要解决的问题

## 别人的声音：授权问题

这是本章最重要的一节。

### 法律怎么规定

> [!WARNING]
> 本节按截至 2026-11 的法规和 2024 年的公开判例整理，可能已有新的规定或司法解释，以国家网信办、国家法律法规数据库的原文和最新司法实践为准。

几条直接相关的规定（法律细节见[《自媒体与短剧合规财税》](../media-compliance/)）：

- 《民法典》第 1023 条第 2 款：对自然人声音的保护，参照适用肖像权保护的有关规定。也就是说，未经同意使用他人声音，可能构成侵权
- 《互联网信息服务深度合成管理规定》（2023 年 1 月 10 日施行）要求，提供人脸、人声等生物识别信息编辑功能的，应当提示使用者依法告知被编辑的个人，并取得其单独同意
- 2024 年北京互联网法院审理了被称为「全国首例 AI 生成声音人格权侵权案」的案件，一位配音演员的声音被 AI 化后对外销售，法院认定侵权，判决相关公司赔礼道歉并赔偿

平台规则也在收紧：小红书 2026 年 4 月的 AI 内容治理规则把「克隆他人声音或面孔」列为 AI 造假行为。

### 不能做的

- 克隆明星、网红、主播的声音做内容，哪怕是「模仿秀」「恶搞」
- 用影视剧、动画角色的声音（背后是配音演员）
- 用网上下载的音色包、「某某同款声音」
- 拿朋友、同事、家人的录音去克隆，没有取得明确的书面同意
- 用克隆的声音冒充本人说话、带货、推荐产品

### 合法用他人声音：授权书要点

如果确实需要用别人的声音（比如合作的配音员、团队成员），要拿到书面授权。授权书至少写清楚：

| 条款 | 写什么 |
|---|---|
| 授权人和被授权人 | 双方身份信息 |
| 授权内容 | 允许录制声音样本、允许用于训练音色模型、允许用该音色合成新内容 |
| 用途范围 | 哪些账号、哪些平台、哪类内容（如「仅限知识科普类视频」），明确排除的用途（如广告代言、政治、成人内容） |
| 期限 | 授权多久；到期后已发布内容如何处理 |
| 报酬 | 一次性还是按条、按月 |
| 内容审核权 | 授权人是否有权审看用其音色合成的内容 |
| 撤回 | 授权人能否撤回、撤回后音色模型如何删除 |
| 标识 | 双方同意按规定对合成内容进行标识 |

这只是要点清单，不是法律文书，正式使用前找律师审一遍。配音演员和配音工作室通常有自己的 AI 授权报价，比自己拟合同省事。

## 背景音乐和音效

AI 音乐生成工具（截至 2026 年 11 月，常见的有 Suno、海绵音乐、天工 SkyMusic、MiniMax 音乐等）可以按描述生成背景音乐。用之前确认两件事：

1. **商用权**：多数服务只有付费档允许商用，免费档生成的曲子用于商单、带货可能违约
2. **平台识别**：AI 生成的音乐也属于生成合成内容，需要声明；另外偶尔会生成和已有作品相似的旋律，引发版权投诉

对大多数账号，**平台曲库仍然是最省心的选择**：在平台内选用曲库音乐，授权问题由平台解决。但要注意曲库音乐的授权通常只限在该平台使用，同一条视频分发到其他平台时要换成有授权的音乐。音乐版权的完整讨论见[《拍摄与剪辑实务》](../shooting-editing/)和《自媒体与短剧合规财税》。

## 声音修复和响度

自录口播几乎都需要修复。AI 降噪、去混响、人声增强功能在剪辑软件和各类音频工具里都有，效果已经很好。两个注意点：

- **降噪不要开到最大**，人声会变得发闷、有金属感。宁可录音时环境安静一点
- **统一响度**。一个账号的视频忽大忽小很影响体验。可以用 ffmpeg 的 loudnorm 滤镜统一到一个目标响度：

```bash
# 统一到 -16 LUFS 左右，真峰值不超过 -1.5 dBTP（目标值可按平台和个人习惯调整）
ffmpeg -i voice.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 voice-norm.wav
```

## 配音质检清单

- [ ] 多音字、数字、英文缩写全部读对
- [ ] 没有吞字、重复字、突然的电流音或爆音
- [ ] 段落之间的停顿自然，不像机关枪
- [ ] 和字幕逐句对得上（字幕用原稿，配音用朗读稿，意思一致）
- [ ] 响度和账号其他视频一致
- [ ] 音色是自己的、已授权的，或者服务商提供的可商用音色
- [ ] 发布时声明含 AI 生成内容

## 常见坑

| 坑 | 表现 | 怎么办 |
|---|---|---|
| 用最热门的音色 | 观众一听就是模板号 | 用自己的声音，或选冷门音色长期固定 |
| 原稿直接合成 | 数字、英文、符号读错 | 先转朗读稿，用发音词典 |
| 一整段一次合成 | 从头到尾一个调子 | 按段合成，分别设语速和情绪 |
| 字幕和配音用同一份稿 | 字幕上出现「二零二六年」 | 字幕用原稿，配音用朗读稿 |
| 克隆他人声音 | 侵权、平台处罚 | 只用自己的或书面授权的声音 |
| 克隆音色账号被盗 | 被人用你的声音说话 | 开二次验证，不借账号 |
| AI 音乐不看条款 | 商单交付后被投诉 | 用付费可商用档或平台曲库 |

## 本章要点

- TTS 选型用同一段稿子横向试听多音字、数字、中英混读、气口、情绪控制和音色辨识度；热门音色辨识度低，声音是人设的一部分
- 稿子要写给机器念：数字、符号、英文缩写转成读法，长句拆短；字幕用原稿，配音用朗读稿，高频问题沉淀成发音词典
- 分段合成并控制语速和停顿，试听三遍
- 克隆自己的声音要走服务商的实名和指定文本核验，保护好账号，合成内容仍要标识
- 他人声音受法律保护：《民法典》声音保护参照肖像权，深度合成规定要求取得单独同意，已有 AI 声音侵权判例；只用自己的或书面授权的声音
- AI 音乐看商用条款，平台曲库最省心但授权通常限于本平台；统一响度

# 调色与画面统一

AI 生成的每个镜头单独看都不错，剪在一起就露馅：这一镜偏暖、下一镜偏青，这一镜锐利、下一镜发糊，人物的脸在一个镜头里微微「呼吸」闪烁。观众说不出哪里不对，但会觉得「廉价」「AI 味」。

这一章处理 AI 素材特有的画面问题：色差、闪烁、画质不一、局部穿帮。目标不是调出电影感，而是**让 28 个来自不同批次、不同模型的镜头看起来像同一部剧**。调色的基础概念和剪映调色面板的操作见《拍摄与剪辑实务》。

## AI 素材常见的画面问题

| 问题 | 表现 | 原因 |
|---|---|---|
| 镜头间色差 | 同一场戏，色温、饱和度、对比度、黑位每镜不同 | 每个镜头单独生成，模型每次「理解」的光线不同；不同模型的默认风格不同 |
| 亮度闪烁 | 画面整体亮度一帧一帧轻微波动 | 视频模型逐帧生成时亮度不稳定 |
| 纹理抖动 | 头发、衣料、背景细节在「沸腾」，线条轻微颤动 | 帧间细节不一致；漫画线条风格尤其明显 |
| 画质不一 | 有的镜头清晰，有的发糊、有压缩块 | 不同生成分辨率、对口型后局部变糊、多次转码 |
| 帧率不一 | 有的镜头 24 fps，有的 30 fps，混剪后动作一卡一卡 | 不同模型、不同工具的默认输出帧率不同 |
| 局部穿帮 | 六根手指、文字乱码、多出来的人、道具凭空出现 | 生成模型的固有缺陷 |
| 水印 | 生成平台在画面角落加的水印 | 平台规则或免费档限制 |

**关于水印要特别注意**：生成平台按《人工智能生成合成内容标识办法》添加的 AI 标识（显式标识和文件里的隐式标识），**不得恶意删除、篡改或隐匿**。如果你用的档位会加水印而你不希望它出现在成片里，正确做法是换用允许无水印导出的档位，并在成片里按规定自己添加 AI 生成标识（第 8 章），而不是用工具把水印抹掉。

## 处理顺序

```mermaid
flowchart LR
  A["统一规格<br/>分辨率、帧率"] --> B["修补<br/>穿帮、乱码"]
  B --> C["去闪烁、稳定"]
  C --> D["一级校正<br/>白平衡、曝光"]
  D --> E["风格化<br/>全剧 LUT"]
  E --> F["统一质感<br/>颗粒、锐化"]
```

顺序的道理：规格不统一，后面每一步都会被变速、缩放干扰；修补和去闪烁要在原始颜色上做；先校正到一致，再套风格，否则同一个 LUT 套在色差很大的两个镜头上，差异会被放大。

## 统一规格

所有镜头在进剪辑之前统一到同一个分辨率和帧率。示例剧用 1080×1920、30 fps：

```bash
# 统一成 1080x1920、30fps；比例不对的先等比缩放再居中裁切
mkdir -p norm
for f in shots/*.mp4; do
  ffmpeg -y -i "$f" \
    -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30" \
    -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p -an \
    "norm/$(basename "$f")"
done
```

`crf 16` 是接近无损的中间文件质量，体积大一些，但避免了多次转码叠加的画质损失。素材音轨一般不用，`-an` 直接去掉。

帧率转换要注意：24 fps 的素材转 30 fps，简单的 `fps=30` 是重复帧，动作会有轻微卡顿。对动作多的镜头，可以用插帧：

```bash
# 运动补偿插帧，慢但更平滑；对 AI 素材偶尔会在快速运动处产生拖影，转完要看
ffmpeg -i in_24.mp4 -vf "minterpolate=fps=30:mi_mode=mci" -c:v libx264 -crf 16 out_30.mp4
```

也可以用专门的 AI 插帧工具（RIFE 一类的开源模型，或商业视频增强软件），效果通常比 ffmpeg 的插帧好。更省事的办法是从源头约定：**全剧所有镜头生成时就用同一个帧率**。

## 修补穿帮

AI 画面的穿帮按处理成本从低到高：

| 手段 | 适用 | 做法 |
|---|---|---|
| 裁掉 | 穿帮只在开头或结尾几帧 | 剪辑时直接剪掉，第 6 章说过默认裁首尾 |
| 二次构图 | 穿帮在画面边缘（多出来的手、边上的路人） | 放大 110%–120% 裁掉边缘；1080 素材放大会损失清晰度，放大后再锐化一点 |
| 缩短或换镜头 | 穿帮在画面中心但只闪一下 | 缩短到穿帮出现前；或用反应镜头盖住 |
| 遮罩模糊 | 背景里的乱码文字、无意义的标志 | 加跟踪遮罩，局部模糊或虚化 |
| 贴字替换 | 画面里的牌匾、信件、书页文字是乱码 | 用跟踪功能把正确的文字贴上去，或者干脆让文字区域虚化，正确内容用字幕或特写镜头另行给出 |
| 局部重绘 | 手指、五官等关键部位出错 | 回到画面生成工具做局部重绘（inpainting）或重新生成该镜头 |

**画面里的文字**是 AI 短剧的高频穿帮点。古风剧里的婚书、牌匾、信封，AI 生成的字几乎都是似是而非的「伪汉字」。观众截图发到评论区，就成了笑话。示例剧的处理：婚书只给撕碎的动作，不给能看清字的特写；信封的特写在后期贴上「沈知微亲启」五个字（用已授权字体），并加轻微的纸张纹理让它融进画面。

## 去闪烁与稳定

亮度闪烁的处理：

- **剪辑软件的去闪烁效果**：例如达芬奇的去闪烁（Deflicker）效果，针对的就是这类帧间亮度波动（需要付费版 Studio）。剪映等软件里也有类似的「防闪烁」或画质修复功能，以当前版本为准
- **ffmpeg 的 deflicker 滤镜**：按相邻帧的平均亮度做平滑，对整体亮度波动有效

```bash
# 用前后 5 帧的平均亮度平滑闪烁
ffmpeg -i in.mp4 -vf "deflicker=size=5:mode=am" -c:v libx264 -crf 16 out.mp4
```

纹理抖动（头发、线条「沸腾」）比亮度闪烁难处理。可以尝试：

- 轻微的时域降噪（剪辑软件的降噪里有「时域」选项），会抹掉一部分抖动，代价是细节变软
- 把镜头缩短到抖动不明显的长度
- 漫剧可以降低线条锐度、加一点颗粒，让抖动「融」进质感里
- 严重的回到生成阶段，换种子或换模型重做

## 一级校正：先让镜头一致

一级校正的目标是：同一场戏的所有镜头，白平衡、曝光、对比度一致。方法：

1. **选一个参考镜头**：这场戏里最好看、颜色最「对」的镜头，通常是主角的近景
2. **把其他镜头往它靠**：剪辑软件里把参考镜头和待调镜头并排或分屏对比，调色温、色调、曝光、对比度
3. **看示波器而不是只看眼睛**：波形图看亮度分布（黑位、白位是否一致），矢量图看颜色偏向。眼睛会被前一个镜头带偏，示波器不会
4. **先看肤色**：人对肤色最敏感。在矢量图上，正常肤色会落在一条固定的「肤色线」附近，偏离太多就是偏色了

很多软件有自动匹配功能（达芬奇的镜头匹配、剪映的色彩匹配类功能等），可以先自动匹配一遍，再手动微调。

快速检查整集的颜色是否一致，可以用 ffmpeg 抽出每个镜头的一帧拼成联系表：

```bash
# 按画面变化检测镜头切换，每个镜头取一帧，缩小后拼成 6 列网格
ffmpeg -i ep01_v3.mp4 \
  -vf "select='gt(scene,0.3)',scale=180:-1,tile=6x5" \
  -frames:v 1 ep01_contact.png
```

把联系表打开，哪一格颜色跳出来一眼就能看到。这张图也适合附在质检记录里。

## 风格化：全剧一个 LUT

一级校正把镜头拉齐之后，再套全剧统一的风格。最简单的方式是做一个 LUT（颜色查找表，常见的是 `.cube` 文件），或者在剪辑软件里保存一个调色预设：

| 剧型 | 风格倾向 |
|---|---|
| 古风 | 暖色调、略低饱和、柔和对比；夜戏偏青 |
| 都市甜宠 | 明亮、粉嫩、高光柔和 |
| 悬疑复仇 | 低饱和、偏青绿、对比较强、暗部压得深 |
| 漫剧 | 保持原画风的色彩设计，少做风格化，重点是一致 |

LUT 放在 `00-bible/lut/`，全剧每集都套同一个。用 ffmpeg 批量套 LUT：

```bash
ffmpeg -i ep01_graded_in.mp4 -vf "lut3d=file=00-bible/lut/tuihun_v1.cube" -c:v libx264 -crf 16 out.mp4
```

LUT 是在一级校正之后套的。如果某个镜头套完颜色怪异，说明它一级校正没做到位，回去调，而不是换 LUT。

**漫剧特别提醒**：2D 漫剧的颜色是角色设计的一部分（女主的衣服是月白色、反派是绛紫色），风格化不能把这些设计色偏掉。调完后对照角色设定图检查主要角色的服装和发色。

## 统一质感

AI 画面往往「太干净」：没有噪点、边缘过分平滑，和对口型、超分处理过的镜头放在一起时，质感差异很明显。最后一步：

- **加轻微颗粒**：全片统一加一层细颗粒，能掩盖镜头间的质感差异、压缩块和轻微的纹理抖动。颗粒量要小，手机上几乎看不出才对
- **统一锐化**：糊的镜头单独锐化，但全片不要过度锐化，平台二次压缩后锐化过度的画面会出现白边
- **超分辨率**：生成分辨率低于 1080 的镜头，或对口型后脸部变糊的镜头，先用超分工具（商业视频增强软件，或 Real-ESRGAN 一类开源模型）放大，再参与调色。超分会「编造」细节，人脸超分后要检查是否变了长相

## 漫剧和写实的取舍

| 环节 | 漫剧 / 动态漫 | AI 仿真人写实剧 |
|---|---|---|
| 色差 | 较少，画风统一时颜色也较稳定 | 严重，每镜光线都可能不同 |
| 闪烁与抖动 | 线条抖动明显 | 肤色和亮度闪烁明显 |
| 穿帮容忍度 | 较高，观众接受夸张 | 低，手指、牙齿一出错就出戏 |
| 平台门槛 | 按平台规则 | 部分平台对 AI 仿真人剧的画面衔接、人物形象有更高要求 |
| 调色工作量 | 小 | 大 |

这也是很多一人团队从漫剧起步的原因之一：后期的画面统一工作量明显更小。

## 本章要点

- AI 镜头的典型问题：色差、亮度闪烁、纹理抖动、画质和帧率不一、局部穿帮、水印
- 生成平台添加的 AI 标识不得恶意删除或篡改，需要无水印就换档位并自行做合规标识
- 处理顺序：统一规格、修补、去闪烁、一级校正、全剧 LUT、统一质感
- 进剪辑前统一分辨率和帧率，最好从生成阶段就约定同一帧率
- 画面里的文字几乎都是乱码，虚化、裁掉或后期贴字，正确信息用字幕或特写给出
- 一级校正选参考镜头、看示波器、先看肤色；用 ffmpeg 抽帧拼联系表快速发现色差
- 全剧一个 LUT，漫剧调色不能偏掉角色设计色；最后加细颗粒统一质感

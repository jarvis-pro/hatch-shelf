# 从剧本到分镜表

剧本告诉你「发生了什么」，分镜表告诉你「观众按什么顺序、从什么距离、看多久」。在 AI 短剧里，分镜表还多了一层职责：它是**生成任务的清单**，每一行都要能直接交给图像或视频模型执行。

这一章先讲拆镜的方法（一场戏拆几个镜头、每个镜头多长），再逐列讲 AI 分镜表，最后给出模板。

## 拆镜之前：先给剧本标三样东西

拿到一场戏的剧本，先别急着想画面，用三种标记过一遍：

1. **信息点**：观众必须在这场戏里知道的事。比如「当票上写的是女主的名字」「来客知道她的身世」。每个信息点至少要有一个镜头让观众看清
2. **情绪点**：人物情绪发生变化的瞬间。比如「女主从不耐烦变成震惊」。情绪点通常要给近景或特写
3. **动作点**：会改变空间关系的动作。比如「来客把当票推过柜台」「女主后退一步」。动作点决定了要不要换景别、要不要动作接

一场 1 分钟的戏，通常有 2–4 个信息点、2–3 个情绪点、3–6 个动作点。这些标记加起来，基本就是你的镜头骨架。

## 一场戏拆几个镜头

没有固定公式，但有可用的经验区间。竖屏短剧节奏快，**平均镜头时长通常在 2–4 秒**，对话密集的戏更短，氛围和开场镜头更长。

$$
\text{镜头数} \approx \frac{\text{本场时长（秒）}}{\text{平均镜头时长（秒）}}
$$

一场 60 秒的对话戏，按平均 3 秒算，大约 20 个镜头。但 AI 生成和实拍不同，还要考虑两个约束：

- **视频模型的单次时长**：主流工具单次生成多在 5–15 秒，部分新版本能更长。一个镜头最好在一次生成内完成，不要依赖「延长」功能，延长的部分更容易跑偏
- **生成成本**：镜头越多，出图和出视频的次数越多。动态漫可以多拆，视频短剧要在节奏和预算之间取舍

一个实用的做法是**先按信息点和情绪点拆出「必要镜头」，再看节奏补「过渡镜头」**：

| 镜头类型 | 来源 | 数量占比（经验） | 典型景别 |
|---|---|---|---|
| 建立镜头 | 场景开头，交代地点 | 每场 1 个 | 远景 / 全景 |
| 信息镜头 | 每个信息点 | 每个信息点 1–2 个 | 特写 / 大特写（道具、文字） |
| 情绪镜头 | 每个情绪点 | 每个情绪点 1–2 个 | 近景 / 特写 |
| 对话镜头 | 台词 | 每句关键台词 1 个，短句可合并 | 中景 / 近景 / 过肩 |
| 反应镜头 | 听的人的表情 | 关键台词后 1 个 | 近景 / 特写 |
| 过渡镜头 | 空镜、细节 | 按节奏补 | 大特写 / 空镜 |

**反应镜头**是新手最容易漏的。短剧的爽点往往不在说话的人，而在听的人：反派听到真相时的表情、配角看到主角逆袭时的震惊。每一句「炸」的台词后面，都值得给一个反应镜头。

## 时长怎么分配

时长分配有三条原则：

1. **看得清就切**。一个镜头的时长至少要够观众读完画面信息：一个简单特写 1–2 秒，有文字的道具特写要按阅读速度算（中文约每秒 4–5 个字，再加 0.5 秒），一个人说一句话按台词长度算
2. **情绪点留长一点**。震惊、心碎、对视这些时刻，比信息镜头多留 0.5–1 秒，给观众反应的时间
3. **开头三秒要满**。前三秒决定观众是否划走，开场镜头不要留空镜慢慢铺，直接给冲突或悬念。选题和钩子的方法见[《选题与爆款结构》](../topic-and-hooks/)

台词时长可以粗略这样估：

$$
\text{对话镜头时长} \approx \frac{\text{台词字数}}{4.5} + 0.5 \text{ 秒}
$$

比如一句 18 个字的台词，约 $18 / 4.5 + 0.5 = 4.5$ 秒。实际以配音后的长度为准，所以分镜表里的时长是**预估值**，粗剪时还会调整。生成视频时要按预估值**略长**一点生成（多 1 秒左右），给剪辑留余量。

## AI 分镜表：在传统分镜上加了什么

传统分镜表（短视频脚本里常见的那种，见[《短视频脚本与分镜》](../video-script-storyboard/)）一般有这些列：镜号、景别、运镜、画面内容、台词、音效、时长。它是写给摄影师和演员看的，人能理解上下文，「同上」「她」「那个房间」都能看懂。

AI 分镜表是写给模型看的。模型**没有上下文**：它不知道「她」是谁，不知道上一个镜头里她穿什么，不知道「那个房间」长什么样。所以 AI 分镜表要把每一行写成**自包含**的：每一行都能脱离其他行独立生成。

为此，AI 分镜表在传统列之外加了这些列：

| 新增列 | 为什么需要 |
|---|---|
| 角色引用 | 指向角色设定卡和参考图，而不是写「她」 |
| 场景引用 | 指向场景设定卡，保证同一场景的光线、陈设一致 |
| 画面提示词 | 生成关键帧用的完整描述 |
| 负面提示词 | 本镜头特别要避免的东西 |
| 参考图 | 本镜头生成时要上传的图：角色图、场景图、上一镜的尾帧 |
| 生成工具与参数 | 用哪个工具、哪个模型版本、比例、种子、参考强度 |
| 镜头时长 | 要生成的视频长度，和剪辑时长分开记 |
| 运动描述 | 视频提示词：人物怎么动、镜头怎么动 |
| 生成状态 | 这一镜做到哪一步了 |

## 逐列讲解

下面按顺序讲每一列怎么填。示例都取自后面一集完整示例里的同一个镜头。

### 镜号

格式建议 `场次-镜号`，如 `S02-05`（第 2 场第 5 镜）。插镜头时用 `S02-05a`，不要整体重排，因为文件名和生成记录都挂在镜号上。

### 场次与场景引用

场景引用写场景卡的 ID，如 `SC-当铺柜台-夜雨`。同一个 ID 意味着同一套光线、陈设和轴线约定。

### 景别、角度、构图

三列分开填，取值用上一章的词汇表。分开写的好处是便于检查：把景别列单独拉出来看，就能发现「连续四个中景」这种问题。

### 运镜

只写一种，带速度：`缓推` `固定` `右摇` `跟移`。

### 画面内容

用一两句话写**这一镜观众看到了什么**，给人看的。如：「陆归把当票推过柜台，手指按在票面名字上。」

### 台词 / 旁白 / 音效

台词写说话人和原文；音效写关键的声音（雨声、算盘、门响），后期会用到。注意：画面生成不处理台词，但台词决定了这一镜的时长，以及人物是否需要张嘴。

### 角色引用

写角色卡 ID 和这一镜用的造型版本，如 `CH-陆归@斗笠装`。多个角色时写清**谁在左、谁在右**：`左：CH-沈青禾@掌柜装；右：CH-陆归@斗笠装`。

### 画面提示词

生成关键帧的完整提示词。结构见图像提示词一章，这里只强调一点：**提示词里要把角色引用和场景引用「展开」成文字**，比如不能只写「陆归」，要写「戴黑色斗笠、穿深灰长衫的中年男子」。即使你上传了参考图，文字描述也能帮模型在参考图和提示词之间对齐。

### 负面提示词

写这一镜特有的风险。通用的负面词（畸形的手、多余的手指、水印）放在模板里统一加，这一列只写本镜头的：如「斗笠遮住整张脸」「两个人穿同样的衣服」。不支持负面提示词的工具，把这些改写成正面描述放进画面提示词。

### 参考图

写要上传的文件名：角色参考图、场景参考图、上一镜尾帧。如 `CH-lugui-front.png; SC-dangpu-main.png`。

### 生成工具与参数

写工具、模型版本、比例、分辨率、种子、参考强度等。模型版本一定要写，同一个工具升级后效果可能完全不同。如 `即梦 / 图片 4.0 / 9:16 / 2K`。

### 镜头时长

两个数：剪辑预估时长和生成时长。如 `剪 3s / 生 5s`。

### 运动描述

视频生成的提示词：主体动作 + 镜头运动 + 节奏。如「陆归的手缓慢把当票推向前方，停住，食指按在纸上；镜头固定。」写法见视频生成一章。

### 生成状态

建议用固定的几个值，便于筛选：

| 状态 | 含义 |
|---|---|
| 待出图 | 提示词写好了，还没生成关键帧 |
| 图待审 | 关键帧已生成，待一致性检查 |
| 图通过 | 关键帧定稿 |
| 待出视频 | 准备做图生视频 |
| 视频待审 | 视频已生成，待动作和连戏检查 |
| 定稿 | 可以进剪辑 |
| 返工 | 写明返工原因 |
| 静帧处理 | 决定不做视频，用动态漫方式处理 |

## 模板

### 表格版（适合飞书多维表格、Notion、Excel）

把下面的表头复制到表格工具里，每一列一个字段。手机上看会很宽，建议在电脑上填。

```text
镜号 | 场景引用 | 景别 | 角度 | 构图 | 运镜 | 画面内容 | 台词/旁白 | 音效 | 角色引用 | 画面提示词 | 负面提示词 | 参考图 | 生成工具与参数 | 镜头时长 | 运动描述 | 转场 | 生成状态 | 备注
```

### CSV 版（适合用脚本批量处理）

```csv
shot_id,scene_ref,shot_size,angle,composition,camera_move,action,dialogue,sfx,char_refs,image_prompt,negative_prompt,ref_images,tool_params,duration_edit_s,duration_gen_s,motion_prompt,transition,status,notes
S02-05,SC-dangpu-night,特写,平视,居中,固定,陆归把当票推过柜台，食指按住票面名字,,纸张摩擦声,右:CH-lugui@douli,"竖构图特写，柜台木面上一张泛黄的旧当票……",文字乱码；多余的手指,CH-lugui-hand.png;PR-dangpiao.png,即梦/图片4.0/9:16,2,5,"手缓慢把当票推向前方后停住，食指按在纸上；镜头固定",视线接,图待审,票面文字后期合成
```

用 CSV 的好处是可以写脚本：把通用风格词和负面词拼到每一行的提示词上，按镜号生成文件名，批量调用 API，把结果回写到 `status` 列。批量生产与管理一章会讲文件命名和生成记录。

### 单镜头卡片版（适合一个镜头一个镜头地讨论）

表格太宽时，可以用卡片形式写每个镜头，内容和表格一一对应：

```text
【S02-05】特写 · 平视 · 居中 · 固定 · 剪 2s / 生 5s
场景：SC-当铺柜台-夜雨
角色：右 CH-陆归@斗笠装（只出手）
画面：陆归把当票推过柜台，食指按住票面上的名字
音效：纸张摩擦声
画面提示词：竖构图特写，深色木纹柜台上一张泛黄的旧当票，一只骨节分明的男人的手从画面右侧把当票推向前方，食指按在票面中央，烛光从左侧照来，暖色调，雨夜室内，国风厚涂插画风格
负面提示词：文字乱码，多余的手指，画面中出现人脸
参考图：CH-lugui-hand.png；PR-dangpiao.png
工具参数：即梦 / 图片 4.0 / 9:16 / 2K
运动描述：手缓慢把当票推向前方后停住，食指按在纸上，烛光轻微摇曳；镜头固定
转场：视线接（下一镜沈青禾低头看）
状态：图待审
备注：票面文字不让模型写，后期用剪辑软件合成
```

## 拆镜的检查清单

分镜表写完、开始生成前，过一遍这张清单：

| 检查项 | 怎么查 |
|---|---|
| 每个信息点都有镜头让观众看清 | 对照剧本标记逐个找 |
| 每句关键台词后有反应镜头 | 看台词列和下一行 |
| 没有连续三个相同景别 | 单独看景别列 |
| 相邻镜头景别差一档或角度明显不同 | 避免跳切 |
| 轴线一致 | 同一场景的镜头，角色左右位置一致 |
| 开头三秒有冲突或悬念 | 看第一、二个镜头 |
| 每一行都能独立生成 | 提示词里没有「她」「同上」「那个房间」 |
| 视频镜头的生成时长不超过工具单次上限 | 对照工具参数 |
| 要出现文字的道具已标注后期合成 | 看备注列 |
| 镜头总时长接近目标时长 | 剪辑时长求和 |

最后一条可以直接在表格里用公式算。如果总时长比目标长 30% 以上，先删镜头再生成，比生成完再剪掉省钱得多。

## 本章要点

- 拆镜前先给剧本标信息点、情绪点、动作点，它们就是镜头骨架
- 竖屏短剧平均镜头 2–4 秒；先拆必要镜头，再按节奏补过渡镜头，别漏反应镜头
- 对话镜头时长按「字数 ÷ 4.5 + 0.5 秒」估，视频生成时长比剪辑时长多留 1 秒左右
- AI 分镜表的每一行必须自包含：角色、场景都要用 ID 引用并在提示词里展开成文字
- 新增的列是角色引用、场景引用、画面提示词、负面提示词、参考图、工具参数、镜头时长、运动描述、生成状态
- 生成前用检查清单过一遍，总时长超了先删镜头再生成

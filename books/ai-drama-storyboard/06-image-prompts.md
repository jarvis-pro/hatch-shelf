# 图像提示词

关键帧是视频的起点：图生视频时，视频的第一帧就是这张图，构图、人物、光线基本都由它决定。关键帧不对，后面的视频再怎么调也救不回来。

这一章讲关键帧提示词的结构、权重和负面词，给出中英文两套模板，最后是常见问题的排查表。图像生成的基本原理和通用 prompt 方法在《多模态应用》里讲过，这里专讲分镜场景下的写法。

## 结构：按「镜头 → 主体 → 环境 → 风格」排序

分镜用的提示词和单张插画不同，它要同时满足三个要求：符合分镜（景别、角度、构图）、符合设定（角色、场景）、符合风格（风格圣经）。按下面的顺序组织：

| 顺序 | 部分 | 来源 | 示例 |
|---|---|---|---|
| 1 | 画幅与镜头 | 分镜表：景别、角度、构图 | 竖构图，近景，平视，人物位于画面左侧三分之一 |
| 2 | 主体：谁 | 角色卡：外貌描述 + 造型 | 二十岁出头的年轻女子，鹅蛋脸……深青色交领上衣 |
| 3 | 主体：在做什么 | 分镜表：画面内容 | 双手撑在柜台上，身体微微前倾 |
| 4 | 主体：表情与视线 | 分镜表 + 表情表 | 眉头微皱，眼睛盯着画面右侧 |
| 5 | 其他人物与位置 | 分镜表：角色引用 | 画面右侧前景是一个戴黑色斗笠的男人的肩膀，虚化 |
| 6 | 环境 | 场景卡：场景提示词 + 锚点物件 | 古代当铺内景，雨夜，柜台左端一盏油灯…… |
| 7 | 光线 | 场景卡：光线 | 暖橙色烛光从左侧照来，脸部半明半暗 |
| 8 | 风格 | 风格圣经：风格词 | 国风厚涂插画风格，电影感光影，低饱和暖色调 |
| 9 | 画质与留白 | 通用 | 高细节，画面底部留出字幕空间 |

为什么镜头放最前？大多数模型对提示词开头的内容更重视。景别和构图如果放在最后，常常被长长的外貌描述「淹没」，结果出来一张居中的半身像。

为什么风格放最后？风格词是每个镜头都一样的「公共后缀」，放在固定位置，便于脚本拼接和检查。

## 中文还是英文

国内工具（即梦、可灵、海螺、Vidu、通义万相）对中文提示词理解良好，直接写中文即可；Midjourney、Stable Diffusion 系列等海外或开源模型通常英文效果更稳。几条经验：

- **跟着工具的主语言走**，不要在一个提示词里中英混写，除非是专有术语
- 中国古代服饰、建筑、器物，用中文描述在国内工具里往往更准确（「交领」「半臂」「发髻」）；在英文模型里要换成描述性写法（cross-collar top, short-sleeved overgarment, hair bun）
- 角色卡和场景卡里同时保存中英两版描述，换工具时直接切换

## 权重：让模型更重视某些词

不同工具调权重的方式不一样，下面是常见写法。**以你所用工具当前的文档为准**，有的工具网页版不支持权重语法，写了也会被当成普通文字。

| 方式 | 写法 | 适用 |
|---|---|---|
| 位置 | 重要的词放前面 | 几乎所有工具 |
| 重复 | 关键特征在提示词里出现两次（换种说法） | 几乎所有工具，但不要滥用 |
| 括号权重 | `(red hair ribbon:1.3)` 提高，`(background:0.7)` 降低 | Stable Diffusion 系列的常见前端（如 ComfyUI） |
| 多段权重 | `ancient pawnshop::2 rainy night::1` | Midjourney 的多段提示 |
| 参数 | 参考强度、风格强度等滑块 | 各工具界面 |

权重的常见用法：

- 识别特征被忽略时（簪子总是不见），给它加权或提前
- 背景喧宾夺主时，降低环境描述的权重，或减少环境描述的字数
- 权重不要拉太高（括号权重一般不超过 1.5），否则画面会过饱和、变形，或者那个元素在画面里到处出现

## 负面提示词

负面提示词告诉模型「不要什么」。它的原理在《多模态应用》讲过：在引导过程中替代「无提示」那一项，把结果往远离这些词的方向推。

### 通用负面词（每个镜头都加）

```text
中文：低质量，模糊，畸形的手，多余的手指，手指融合，多余的肢体，扭曲的脸，五官错位，水印，文字，签名，logo，画面边框，拼贴
英文：low quality, blurry, deformed hands, extra fingers, fused fingers, extra limbs, distorted face, asymmetrical eyes, watermark, text, signature, logo, frame border, collage
```

### 题材负面词（按剧加）

```text
古装：现代服装，现代建筑，电灯，玻璃，塑料，眼镜，手表 / modern clothing, modern building, electric light, glass, plastic, glasses, wristwatch
漫剧：照片，写实摄影，3D 渲染 / photo, photorealistic, 3D render
写实：动漫，插画，卡通，过度磨皮，塑料感皮肤 / anime, illustration, cartoon, airbrushed skin, plastic skin
```

### 镜头负面词（按镜头加，写在分镜表）

针对这一镜的特定风险，比如「两个人穿同样的衣服」「斗笠遮住整张脸」「人物看向镜头」。

### 不支持负面词的工具

很多国内工具的网页版没有单独的负面提示词框。这时把负面需求**改写成正面描述**：

| 负面写法 | 改成正面描述 |
|---|---|
| 不要现代物品 | 所有陈设都是古代木质器物 |
| 不要文字 | 纸面只有模糊的墨迹，无法辨认 |
| 不要看镜头 | 她的视线看向画面右侧的人 |
| 不要两人同样的衣服 | 女子穿深青色上衣，男子穿深灰色长衫 |

在正面提示词里直接写「不要 XX」通常适得其反：模型看到「现代物品」这几个字，反而更可能画出现代物品。

## 模板

下面是可以直接套用的关键帧模板。方括号是要替换的部分，从分镜表、角色卡、场景卡、风格圣经里取。

### 中文模板：单人镜头

```text
竖构图，[景别]，[角度]，[构图：人物在画面的位置]。
[角色外貌描述]，[造型版本的服装]。
[动作：在做什么]，[表情：具体的面部动作]，[视线：看向哪里]。
背景是[场景提示词，含锚点物件和位置]。
[光线：主光方向和颜色，脸部明暗]。
[风格词]。画面底部留出字幕空间。
```

### 中文模板：双人镜头（过肩 / 对话）

```text
竖构图，过肩[景别]，[角度]。
前景[左/右]侧是[角色 A 的简短识别描述]的[肩膀和后脑]，虚化。
画面[右/左]侧是[角色 B 的完整外貌描述]，[动作]，[表情]，视线看向画面[左/右]侧的[角色 A]。
两人服装区分：[A 的服装主色]，[B 的服装主色]。
背景是[场景提示词]。[光线]。
[风格词]。
```

### 中文模板：道具特写

```text
竖构图，[特写/大特写]，[俯拍/平视]。
[道具卡外观描述]，[道具状态：被谁的手拿着、放在什么上面]。
[文字处理：纸面只有模糊的墨迹，无法辨认]。
[背景：虚化的场景元素]。[光线]。
[风格词]，浅景深。
```

### 英文模板：single character

```text
vertical composition, [shot size], [camera angle], [subject position in frame].
[character appearance], wearing [outfit].
[action], [facial expression described as muscle movements], looking toward [direction].
background: [scene description with anchor props and their positions].
[lighting: key light direction and color].
[style keywords]. leave empty space at the bottom of the frame for subtitles.
```

### 英文模板：two characters, over-the-shoulder

```text
vertical composition, over-the-shoulder [shot size], [camera angle].
[short description of character A]'s shoulder and back of head in the [left/right] foreground, out of focus.
[full appearance of character B] on the [right/left] side of the frame, [action], [expression], looking toward frame [left/right] at [character A].
outfits clearly different: A wears [color], B wears [color].
background: [scene description]. [lighting].
[style keywords].
```

### 英文模板：prop close-up

```text
vertical composition, [close-up / extreme close-up], [angle].
[prop description], [state: held by whose hand, resting on what].
the paper shows only blurred ink marks, no legible text.
background: [blurred scene elements]. [lighting].
[style keywords], shallow depth of field.
```

## 一次出几张、怎么挑

大多数工具一次生成 4 张左右。建议的流程：

1. **第一轮**：用完整提示词出一组，看「方向对不对」（构图、景别、人物是否大致符合）
2. **改提示词**：方向不对就改提示词，不要在错误的方向上反复抽卡
3. **第二轮起**：方向对了，固定提示词和种子（工具支持时），只改一两个词微调细节
4. **挑选**：按一致性检查清单挑，先看识别特征和站位，再看脸，最后看细节
5. **局部修补**：整体满意、局部有问题（手指、配饰、一小块背景），用局部重绘修补，不要整张重来

一个经验阈值：**同一个提示词出了三组（十几张）还没有可用的，就停下来改提示词或换方法**，不要继续抽卡。问题多半出在提示词结构、参考图或者镜头设计本身。

## 生成失败排查表

| 现象 | 常见原因 | 解决办法 |
|---|---|---|
| 景别不对（要近景出了半身居中像） | 景别词在后面，被外貌描述淹没 | 景别和构图词放最前；减少外貌描述的字数 |
| 人物总在正中间 | 默认构图倾向 | 明确写「人物位于画面左侧三分之一，右侧留空」 |
| 脸不像定妆图 | 参考图不干净；提示词与参考图矛盾；景别太远 | 换干净的正面参考；外貌描述与参考图对齐；需要看脸的镜头用近景 |
| 识别特征丢失（簪子、发带不见） | 细节太小或描述太靠后 | 提前、加权、重复描述；必要时局部重绘补上 |
| 两人同框时外貌混在一起 | 模型把两个人的描述混合 | 每人一张参考图并标清对应；写明服装主色区分；或分两次生成再合成 |
| 手部畸形 | 手是模型的老问题 | 负面词；让手做简单动作（握拳、放在桌上）；遮挡手部；局部重绘 |
| 多出一个人 | 提示词里人物描述含糊，如「他们」 | 明确写人数「画面中只有一个人」 |
| 风格和前面的镜头不一致 | 风格词变了、换了工具或模型版本 | 风格词复制粘贴；固定工具和版本；加风格参考图 |
| 画面里出现乱码文字 | 提示词提到了文字或招牌 | 改为「模糊的墨迹」；文字后期合成 |
| 时代穿帮（古装出现现代物品） | 模型默认偏现代 | 题材负面词；正面写明「古代木质器物」 |
| 光线方向与场景卡不符 | 没写光源方向 | 写明「暖光从画面左侧照来」 |
| 画面太满，没地方放字幕 | 没写留白 | 写「画面底部留出空间」；或生成时用略宽松的景别再裁切 |
| 生成结果被平台拦截 | 提示词触发审核（暴力、血腥、敏感词） | 换更克制的描述；短剧的暴力和恐怖镜头本身也受审核，见《短剧发行、投流与备案》 |

## 判断一张关键帧能不能用

不要追求完美，按下面的顺序判断，前面不过就不用看后面：

1. **分镜对不对**：景别、角度、构图、站位符合分镜表
2. **人对不对**：识别特征齐全，和定妆图一眼认得出
3. **场景对不对**：锚点物件在，光线方向对
4. **有没有硬伤**：畸形的手和脸、多余的人、穿帮物件、乱码
5. **好不好看**：情绪是否到位，画面是否有质感

前四项是硬标准，第五项是软标准。前四项都过、第五项一般的图，比第五项惊艳但站位错了的图更有用。

如果这一镜还要做图生视频，再加一条：**关键帧要给动作留余地**。人物如果要抬手，手不要贴着画面边缘；镜头要推近，主体周围要有空间。见视频生成一章。

## 本章要点

- 关键帧提示词按「画幅与镜头 → 主体 → 动作表情视线 → 其他人物 → 环境 → 光线 → 风格 → 留白」排序
- 跟着工具的主语言写；角色卡、场景卡同时保存中英两版描述
- 权重写法因工具而异；位置靠前是最通用的加权方式，括号权重不要超过 1.5 左右
- 负面词分通用、题材、镜头三层；不支持负面词的工具改写成正面描述
- 同一个提示词出三组还不可用就停下来改方法；局部问题用局部重绘
- 判断顺序：分镜、人、场景、硬伤、好看，前四项是硬标准

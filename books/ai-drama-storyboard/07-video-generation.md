# 视频生成

关键帧定稿之后，下一步是让画面动起来。视频生成是整个流程里最贵、最不稳定的一环：一条几秒的视频，可能要生成三五次才有一条能用。这一章讲四种生成方式怎么选、运动怎么描述、时长怎么控制、动作和表情的写法，再给出工具对比、提示词模板和失败排查表。

## 四种生成方式

| 方式 | 输入 | 控制力 | 适合的镜头 |
|---|---|---|---|
| 文生视频 | 只有文字 | 最低：人物和场景都由模型决定 | 空镜、氛围镜头、不出现主要角色的画面 |
| 图生视频（首帧） | 关键帧 + 运动描述 | 中：第一帧确定，之后由模型发挥 | 大多数镜头的默认选择 |
| 首尾帧 | 首帧 + 尾帧 + 运动描述 | 高：起点和终点都确定 | 动作接动作、有明确结束状态的镜头、转场 |
| 参考生视频 | 角色 / 场景参考图（有的支持参考视频、音频）+ 描述 | 中到高：人物一致，构图由模型决定 | 关键帧难出、需要人物大幅运动、多人互动 |

**AI 短剧的主力是图生视频**。原因在前面几章已经铺垫过了：关键帧阶段已经把构图、人物、场景、光线都检查过，图生视频只需要解决「怎么动」。文生视频的人物一致性无法保证，只适合不露主角的镜头。

首尾帧是被低估的功能。很多镜头本质上是「从状态 A 到状态 B」：从低头到抬头、从门外走到柜台前、从当票特写拉到全景。给定首尾帧，模型只需要补中间的过程，成功率和可控性都会明显提高。代价是要多出一张尾帧，而尾帧和首帧的人物、场景必须一致。

参考生视频适合两种情况：一是关键帧很难出（比如复杂的多人走位），二是动作幅度大到首帧无法约束（比如转身跑出画面）。有的工具还支持用参考视频来指定动作或运镜，比如通义万相 2.7 的参考生视频接口支持参考图和参考视频混合输入，Kling 4.0 的全能参考可以把视频作为动作、运镜和节奏的参考（截至 2026 年 11 月，以官方文档为准）。用参考视频时，视频素材本身也必须是你有权使用的，不能拿影视剧片段做动作参考然后商用。

## 运动描述怎么写

视频提示词的核心是**运动**，不是画面。画面已经由关键帧决定了，再把外貌和场景描述一遍，模型反而可能「重画」画面，导致首帧之后人物变样。

### 结构

| 顺序 | 部分 | 示例 |
|---|---|---|
| 1 | 主体动作 | 女子缓慢抬起头 |
| 2 | 动作细节与节奏 | 先抬眼，再抬头，动作停在视线与镜头右侧的人对上 |
| 3 | 表情变化 | 眉头逐渐皱起，嘴唇抿紧 |
| 4 | 次要运动 | 油灯火苗轻微摇曳，窗外雨丝落下 |
| 5 | 镜头运动 | 镜头缓慢推近至面部特写 |
| 6 | 约束 | 人物保持在画面左侧，背景不变 |

几条原则：

- **一个镜头一个主要动作**。「她抬头、站起来、走到门口、回头」在 5 秒里做不完，模型会压缩成一团乱。拆成多个镜头
- **写动作的过程和终点**。「抬头」不如「缓慢抬起头，停在平视画面右侧的位置」
- **写速度**。缓慢、平稳、突然、快速。短剧大多数镜头用缓慢的动作和缓慢的运镜，突然的动作留给少数冲击时刻
- **区分人物运动和镜头运动**。「向前移动」是人在走还是镜头在推？写清楚：「人物向前走两步」「镜头向前推」
- **次要运动让画面「活」**。头发、衣角、烛火、雨、烟、尘埃，这些小幅运动很容易生成成功，能让固定镜头也不显得像静帧
- **不重复外貌描述**。图生视频时只写运动；参考生视频时才需要写人物和场景

### 动作和表情的写法

模型对「宏观动作」（走、坐、转身）和「微观动作」（眨眼、嘴角上扬）的把握程度不同。

| 类型 | 模型的把握 | 写法建议 |
|---|---|---|
| 次要运动（头发、衣服、火、雨） | 好 | 直接写，几乎每镜都可以加 |
| 头部动作（抬头、低头、转头） | 较好 | 写方向和幅度：「向右转头约 45 度」 |
| 手部简单动作（推、拿、放） | 中 | 动作简单，手在画面中占比不要太小 |
| 表情变化 | 中 | 写肌肉动作而不是情绪词：「眼睛慢慢睁大，嘴微张」 |
| 走路 | 中 | 短距离，方向明确；全身入画时脚部容易出错 |
| 转身、坐下、起立 | 较差 | 容易出现肢体扭曲；能用剪辑跳过就跳过 |
| 两人肢体接触（拉手、拥抱、打斗） | 差 | 尽量用特写或剪辑暗示，避免一镜完成复杂互动 |
| 说话的口型 | 依工具而定 | 口型同步交给后期处理更稳，见[《AI 短剧后期》](../ai-drama-post/) |

对于做不出来的动作，最好的办法是**改分镜，不是硬抽卡**。比如「她猛地起身」可以拆成：手拍桌面的特写（1 秒）+ 她已经站起来的近景（2 秒）。观众的大脑会自动补上中间的过程，这正是剪辑的基本原理。

### 说话的镜头

有台词的镜头要决定：人物要不要张嘴？

- **不张嘴**：画外音、内心独白、背对镜头、远景。最简单
- **生成时张嘴**：在提示词里写「人物在说话，嘴部自然开合」，之后由后期做口型同步。部分工具支持直接生成带对白的音画同步视频，但台词内容、音色和口型的可控性通常不如后期处理
- **生成时闭嘴，后期做口型**：适合口型同步工具成熟的流程

具体怎么选，取决于你后期的口型方案，和后期的同事（或另一个自己）先对齐。

## 时长控制

| 问题 | 做法 |
|---|---|
| 剪辑只需要 2 秒，工具最短 4–5 秒 | 按最短时长生成，剪辑时取最好的一段。运动要慢，否则 2 秒的片段里动作只完成一半 |
| 需要 8 秒，工具单次能生成 | 一次生成；动作写得舒展一些，避免模型在后半段「无事可做」开始乱动 |
| 需要比单次上限更长 | 优先拆成两个镜头；必须连续时用「延长」或用上一段的尾帧做下一段的首帧 |
| 运动太快 | 提示词加「缓慢」「平稳」；减少动作数量；生成时长加长 |
| 后半段跑偏 | 用首尾帧约束终点；或缩短生成时长 |

关于「延长」：多数工具支持基于已生成视频继续延长，但每次延长都可能累积偏差，人物越来越不像。长镜头在 AI 短剧里本来就少用，**宁可多拆镜头，不要硬延长**。

用尾帧接下一段时，先把上一段的最后一帧导出成图片，检查一致性（这一帧往往比首帧更「跑偏」），必要时修图后再作为下一段的首帧。

选型建议：

1. **先选一个主力工具，图和视频都在里面做**。跨工具最大的损失是风格和画质的差异，以及来回导出导入的时间
2. **用自己的镜头做对比**：从分镜表里挑 5 个有代表性的镜头（一个固定近景、一个推镜、一个走路、一个双人、一个道具特写），在两三个工具里各生成 3 次，记录一次成功率和单条成本
3. **看你最需要的能力**：多人同框多就看多主体参考；动作戏多就看首尾帧和多关键帧；对口型要求高就看音画同步和口型功能
4. **算总账**：单价低但成功率低，可能比单价高但成功率高的工具更贵。用第一章的公式算
5. **看商用条款**：会员档位不同，商用权利、水印、分辨率常常不同。发布前确认你用的档位允许商用，并保存当时的条款截图

## 提示词模板

### 中文模板：图生视频

```text
[主体]缓慢[主要动作]，[动作过程与终点]。
[表情变化：具体的面部动作]。
[次要运动：头发 / 衣角 / 烛火 / 雨丝]。
镜头[运镜方式，含速度]。
人物保持在画面[位置]，背景与光线保持不变，动作自然流畅。
```

### 中文模板：首尾帧

```text
从首帧过渡到尾帧：[主体]从[首帧状态][动作过程]到[尾帧状态]。
动作[速度]，[节奏：前段慢后段快 / 匀速]。
[次要运动]。镜头[运镜]。
人物外貌和服装全程保持一致，背景不变。
```

### 中文模板：参考生视频

```text
[竖屏 9:16]，[景别]，[角度]。
[图1]中的[角色 A 简短描述]位于画面[左侧]，[动作]；
[图2]中的[角色 B 简短描述]位于画面[右侧]，[动作]。
场景参考[图3]：[场景简述与锚点物件]。
[光线]。镜头[运镜]。[风格词]。
```

### 英文模板：image to video

```text
[subject] slowly [main action], [process and end state of the action].
[facial change described as muscle movements].
[secondary motion: hair / clothes / candle flame / rain].
camera: [camera movement with speed].
the subject stays on the [position] of the frame, background and lighting remain unchanged, natural and smooth motion.
```

### 英文模板：first and last frame

```text
transition from the first frame to the last frame: [subject] [action process] from [start state] to [end state].
[speed], [pacing].
[secondary motion]. camera: [camera movement].
the character's face and outfit stay consistent throughout, background unchanged.
```

### 英文模板：reference to video

```text
vertical 9:16, [shot size], [angle].
the [character A] from Image 1 stands on the left side of the frame, [action];
the [character B] from Image 2 stands on the right side of the frame, [action].
scene reference Image 3: [scene summary with anchor props].
[lighting]. camera: [camera movement]. [style keywords].
```

参考素材的指代写法（「图1」「Image 1」「@主体名」等）各工具不同，按工具文档写。

## 生成失败排查表

| 现象 | 常见原因 | 解决办法 |
|---|---|---|
| 首帧之后脸变了 | 运动幅度大；提示词重新描述了外貌；关键帧脸部太小 | 只写运动不写外貌；减小动作幅度；关键帧用近景；用首尾帧锁定尾帧 |
| 人物几乎不动 | 运动描述太弱或太抽象 | 写具体动作和终点；加次要运动 |
| 动作太快、像快进 | 动作太多；生成时长太短 | 一镜一动作；加「缓慢」；加长生成时长 |
| 镜头乱飞乱晃 | 没写运镜，模型自由发挥 | 明确写「固定镜头」或具体运镜 |
| 人物运动和镜头运动混了 | 描述含糊 | 分开写「人物……」「镜头……」 |
| 肢体扭曲（转身、坐下） | 复杂全身动作 | 改分镜拆镜头；用剪辑跳过中间过程 |
| 多出一个人或人物分裂 | 参考图或首帧里人物边缘被裁；多人描述混淆 | 首帧人物完整；每人一张参考图并标清位置 |
| 两人互动穿模 | 肢体接触本身是难点 | 用特写局部（手的特写）或正反打代替同框接触 |
| 后半段跑偏 | 时长过长、没有终点约束 | 首尾帧；缩短时长 |
| 背景物件变化（油灯消失） | 背景细节没有锁定 | 提示词写「背景不变」；关键帧里锚点物件不要太靠边 |
| 画面闪烁、纹理流动 | 风格化画面的常见问题 | 降低运动幅度；换工具或模型版本；严重时改用动态漫做法 |
| 嘴在乱动 | 模型默认人物在说话 | 不需要口型时写「人物闭着嘴，没有说话」 |
| 延长后越来越不像 | 偏差累积 | 少用延长，拆镜头；用修过的尾帧重新起一段 |
| 生成被拦截 | 动作或内容触发审核 | 换更克制的表达；暴力血腥场景本身也受内容审核 |

## 判断一条视频能不能用

| 顺序 | 标准 | 硬 / 软 |
|---|---|---|
| 1 | 人物在整段中都认得出，没有在中途变脸 | 硬 |
| 2 | 没有肢体扭曲、多余的人、物体凭空出现或消失 | 硬 |
| 3 | 动作和分镜表一致，起点和终点对得上上下镜头 | 硬 |
| 4 | 剪辑需要的那几秒是好的（不要求整段都好） | 硬 |
| 5 | 运动自然、节奏合适 | 软 |
| 6 | 表情到位 | 软 |

第 4 条最重要也最容易忘：**一条 5 秒的视频，只要中间有 2 秒能用，它就是可用的**。用剪辑的眼光挑片，不要用「整条完美」的标准，否则返工率会高得离谱。

另一个判断：如果一个镜头重试了五次以上还没有可用的，停下来考虑三条退路，按成本从低到高：改成动态漫处理（静帧加运镜，见下一章）；改分镜（换景别、拆镜头、换一种表现方式）；换工具。

## 本章要点

- 四种方式：文生视频只用于空镜，图生视频是主力，首尾帧用于有明确终点的动作，参考生视频用于关键帧难出或大幅运动
- 视频提示词写运动不写外貌：主体动作、过程与终点、表情、次要运动、镜头运动、约束
- 一镜一动作，写速度；复杂动作改分镜，用剪辑让观众脑补
- 生成时长按工具下限或略长于剪辑时长，少用延长，宁可拆镜头
- 选型用自己的 5 个代表镜头做对比，按「单价 ÷ 一次成功率」算总账，并确认会员档位的商用条款
- 只要有剪辑需要的那几秒是好的就可用；重试五次不行就改动态漫、改分镜或换工具

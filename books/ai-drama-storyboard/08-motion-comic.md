# 动态漫

动态漫（也常被叫作动态漫画、静帧漫剧）是 AI 短剧里成本最低、最容易起步的形态：画面主体是静态图，靠**镜头运动、分层视差和局部动效**让它「动起来」，再配上配音、音效和字幕。

它不是「做不出视频时的妥协」。很多漫剧本来就以这种形态为主，观众接受度高；而且即使做视频短剧，也会有相当一部分镜头更适合用动态漫的方式处理：道具特写、空镜、情绪停顿、视频反复失败的镜头。

## 动态漫的三层手法

| 层次 | 做法 | 成本 | 效果 |
|---|---|---|---|
| 1. 镜头运动 | 在剪辑软件里对静帧做推、拉、摇、移 | 极低 | 画面有了方向和节奏 |
| 2. 分层视差 | 把前景、人物、背景拆成独立图层，以不同速度移动 | 中 | 有了纵深感，像真正的镜头运动 |
| 3. 局部动效 | 头发、衣角、火苗、雨丝、眨眼等局部动起来 | 中到高 | 画面「活」了 |

一集动态漫不需要每个镜头都用满三层。常见的配比是：所有镜头都有第 1 层；重要镜头加第 2 层；情绪高点和开场加第 3 层。

## 第一层：镜头运动

### 原理

在剪辑软件里，给静帧图片的**缩放**和**位置**打关键帧，就能模拟摄影机的运动：

| 模拟的运镜 | 关键帧怎么设 | 用途 |
|---|---|---|
| 推 | 缩放从 100% 到 110%–120% | 聚焦、情绪加深 |
| 拉 | 缩放从 120% 到 100% | 揭示环境 |
| 横摇 / 横移 | 位置从左到右平移 | 扫视、交代空间 |
| 竖摇 | 位置从下到上平移 | 从脚到脸、从地面到天空 |
| 推 + 移 | 缩放和位置同时变化 | 从全景推到某个人物 |
| 抖动 | 位置做小幅随机变化 | 冲击、爆炸、慌乱 |

### 参数经验

- **幅度要小**：3 秒的镜头，缩放变化 5%–15% 就够了。幅度太大会显得廉价，也会把图片放大到糊
- **加缓入缓出**：关键帧之间用缓动曲线（ease in / ease out），而不是匀速。匀速运动看起来像机械扫描
- **方向要有意义**：推向人物的脸是「聚焦情绪」，从当票摇到人物脸是「视线接」。不要每个镜头都随便推一下
- **相邻镜头运动方向协调**：上一镜向左摇、下一镜向右摇，会让观众觉得画面在来回晃

### 对图片的要求

要做推镜和移镜，**图片必须比画面大**。推到 120% 时，原图要有足够分辨率保持清晰。所以：

- 动态漫的关键帧生成时，用工具支持的最高分辨率，必要时再用超分工具放大
- 要做横移的镜头，生成时用更宽的画幅（比如为竖屏横移生成 3:4 甚至 1:1 的图），留出移动空间
- 构图时考虑运动的起点和终点：推镜的终点画面也要构图完整，不能推完了人物被切掉半张脸

剪映、Premiere、Final Cut、达芬奇等剪辑软件都能做关键帧缩放和位移，入门用剪映就够了。剪辑软件的通用操作见[《拍摄与剪辑实务》](../shooting-editing/)。

## 第二层：分层视差

只对整张图做缩放，画面里所有东西以同样的速度变大，看起来像「放大一张照片」。真实的摄影机移动时，近处的东西移动得快、远处的东西移动得慢，这种差异就是视差，它带来纵深感。

### 做法

1. **拆层**：把一张关键帧拆成 2–4 层，常见的是：前景（虚化的门框、柜台边缘）、人物、背景
2. **补背景**：人物抠出去以后，背景上会留下一个洞，需要补全。用 AI 的局部重绘或「消除」功能补上被人物挡住的部分
3. **分层运动**：在剪辑或合成软件里，让三层以不同幅度运动。比如推镜：前景放大 15%、人物放大 10%、背景放大 5%

### 用 AI 简化拆层

拆层是动态漫最耗时间的环节，可以借助 AI 工具：

- **抠图**：多数修图和剪辑工具都有自动抠人像的功能，漫画风格的人物通常也能抠得比较干净
- **补背景**：局部重绘或扩图功能
- **直接分开生成**：更省事的办法是在生成阶段就分开出图：先出无人的场景母版（场景与道具一章讲过），再单独出透明背景或纯色背景的人物，最后合成。这样天然就是分层的

分开生成时要注意：人物和背景的光线方向、透视角度要匹配，否则合成后人物像「贴」上去的。在人物提示词里写上和场景卡一致的光线描述。

## 第三层：局部动效

### 适合做局部动效的元素

| 元素 | 做法 | 难度 |
|---|---|---|
| 雨、雪、烟、尘埃、光斑 | 剪辑软件的粒子特效或素材叠加 | 低 |
| 火苗、烛光闪烁 | 亮度和颜色的小幅随机变化；或火焰素材叠加 | 低 |
| 头发、衣角、旗帜飘动 | AI 图生视频，限定只有这部分动 | 中 |
| 眨眼 | 生成一张闭眼的图，切换 2–3 帧 | 中 |
| 嘴部开合 | 生成闭嘴和张嘴两张图交替；或用口型工具 | 中 |
| 呼吸起伏 | 人物图层做极小幅度的缩放循环 | 低 |
| 泪水滑落 | AI 图生视频或手工绘制 | 高 |

### 用图生视频做局部动效

图生视频不一定要让人物大幅运动。用它做「几乎不动、只有局部在动」的视频，成功率非常高，而且人物几乎不会变脸，因为整体画面基本没变。

```text
中文：画面基本静止，只有[局部元素]在[运动方式]。人物保持不动，表情不变，镜头固定，背景不变。
英文：the scene is almost still, only the [element] is [motion]. the character stays still with the same expression, static camera, background unchanged.
```

例如：「画面基本静止，只有女子鬓边的碎发和油灯的火苗在轻轻飘动。人物保持不动，表情不变，镜头固定。」

部分工具提供「运动笔刷」「局部运动」之类的功能，可以在画面上涂抹指定哪些区域动、往哪个方向动，做局部动效更精确。功能名称和是否提供以各工具当前版本为准。

### 眨眼和口型的简易做法

眨眼：用局部重绘把关键帧的眼睛改成闭眼，得到第二张图。在剪辑时间线上：睁眼图 → 闭眼图（2–3 帧，约 0.1 秒）→ 睁眼图。每隔 3–5 秒眨一次，人物就有了生气。

口型：生成闭嘴、微张、张开三张图，按台词节奏切换。这种做法很粗糙，适合风格化较强的漫剧；要更自然的效果，交给后期的口型同步工具，见[《AI 短剧后期》](../ai-drama-post/)。

## 动态漫的分镜表写法

动态漫的分镜表在 AI 分镜表的基础上，把「运动描述」一列换成「动效设计」，写清三层各做什么：

```text
【S01-01】远景 · 俯拍 · 固定转缓推 · 剪 3s
画面：雨夜的城南街巷，青石板路，远处一家亮着灯的当铺
关键帧：场景母版 SC-street-night-wide.png（3:4，留横移空间）
第 1 层 镜头：缩放 100%→108%，位置向右上方微移，缓入缓出
第 2 层 视差：前景屋檐滴水层放大 15%，背景当铺层放大 6%
第 3 层 动效：雨丝粒子叠加；当铺灯笼亮度轻微闪烁；屋檐滴水用图生视频（只动水滴）
音效：雨声（铺满）、远处更鼓一声
状态：图通过，待合成
```

## 漫画分格式的变体

有一类漫剧更接近「会动的条漫」：画面里保留漫画的分格、对话气泡、拟声字，镜头在格与格之间移动。做法上的区别：

- 关键帧按漫画分格设计，一张图里可能有 2–3 个格子
- 镜头运动在格子之间移动，相当于「读漫画」的视线引导
- 对话气泡和拟声字后期加，不要让模型生成文字
- 竖屏下，一格的宽度通常就是屏幕宽度，类似条漫

这种形式制作更快，但观众感受更接近「看漫画」而不是「看剧」，适合轻喜剧、日常、网文改编的快节奏内容。改编网文涉及授权问题，见[《短剧编剧》](../drama-scriptwriting/)。

## 动态漫的参数速查

下面是一组可以直接套用的起始参数，适用于 9:16 竖屏、30 帧的工程。它们是经验起点，按你的风格和节奏调整：

| 镜头类型 | 时长 | 运镜参数 | 动效 |
|---|---|---|---|
| 开场远景 | 3–4 秒 | 缩放 100%→108%，或横移画面宽度的 10% | 天气粒子 + 光源闪烁 |
| 对话近景 | 按台词 | 固定，或缩放 100%→104% 极慢推 | 眨眼（每 3–5 秒一次）+ 口型切换 + 发丝 |
| 情绪特写 | 2–3 秒 | 缩放 100%→112%，缓入缓出 | 呼吸起伏；需要时泪光 |
| 道具特写 | 2–3 秒 | 缩放 100%→110%，终点对准关键信息 | 光影轻微变化 |
| 冲击时刻 | 0.5–1 秒 | 快速推 + 位置抖动 3–5 帧 | 闪白 2 帧 + 音效 |
| 空镜过渡 | 1.5–2 秒 | 横摇或竖摇 | 天气粒子 |

时长的经验：动态漫的单镜头时长可以比视频短剧略长一点，因为观众需要时间「读图」；但整体节奏仍然要快，一个镜头超过 5 秒还没有新信息，观众就会划走。

### 一集动态漫的工作量

以上一章示例的 19 个镜头为例，如果全部用动态漫方式处理：

| 工作 | 数量 | 说明 |
|---|---|---|
| 关键帧 | 18 张定稿 | 黑场不需要；首尾帧镜头在动态漫里只需一张 |
| 分层合成 | 约 6 个重要镜头 | 开场、震惊特写、摘斗笠等 |
| 局部动效素材 | 眨眼图、口型图若干 | 每个有台词的近景准备闭眼和张嘴两张 |
| 图生视频局部动效 | 3–5 条 | 只用在发丝、雨水、火苗这类局部 |

和全视频方案相比，生成成本可以降到很低，主要成本转移到修图和剪辑上。一个熟练的人一天能做完一集；第一次做会慢很多，因为需要摸索剪辑工程的模板。把第一集的剪辑工程存成模板（运镜预设、粒子图层、眨眼的时间线片段），从第二集开始就快了。

## 动态漫和视频怎么混用

在一集视频短剧里混用动态漫镜头很常见，关键是**让观众察觉不到切换**：

| 做法 | 说明 |
|---|---|
| 动态漫镜头放在「本来就该静」的位置 | 道具特写、空镜、人物凝视、情绪停顿 |
| 动态漫镜头也加次要运动 | 至少有烛火、雨丝、发丝在动，避免完全静止 |
| 统一画质 | 视频的分辨率和锐度往往低于静帧，静帧镜头可适当柔化，避免一清一糊 |
| 统一色调 | 调色时把两类镜头一起调 |
| 运动方向衔接 | 视频镜头结尾在推，接上的静帧镜头也从推开始 |

反过来，在一部以动态漫为主的作品里，在高潮镜头加入一两个完整的视频镜头，会形成明显的「爆发」感，是很好的节奏手段。

## 动态漫的常见坑

| 坑 | 表现 | 解决 |
|---|---|---|
| 每个镜头都在推 | 观众看着累，像幻灯片的自动特效 | 有意义才动，一部分镜头固定，只靠局部动效 |
| 推镜推糊了 | 放大后图片模糊 | 生成高分辨率；控制缩放幅度；超分 |
| 合成的人物像贴纸 | 光线、透视、边缘不匹配 | 人物提示词写和场景一致的光线；边缘羽化；加统一的颗粒和调色 |
| 背景补全有破绽 | 拆层时补的背景和原图不一致 | 优先分开生成，而不是事后拆 |
| 完全静止的镜头 | 观众以为卡了 | 至少有一种次要运动 |
| 动效素材有版权问题 | 用了来源不明的粒子、火焰素材 | 用剪辑软件自带的、有明确授权的素材库，或自己生成 |

## 本章要点

- 动态漫三层手法：镜头运动、分层视差、局部动效；所有镜头都有第一层，重要镜头加后两层
- 静帧运镜幅度要小、要加缓动，方向要有意义；图片分辨率要比画面大，横移要留空间
- 分层视差靠前景、人物、背景以不同速度运动；最省事的是生成时就分开出场景母版和人物
- 用图生视频做「只有局部在动」的镜头，成功率高且几乎不变脸
- 动态漫和视频可以混用：静帧放在本该静的位置，统一画质、色调和运动方向

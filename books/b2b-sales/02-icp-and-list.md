# 理想客户画像与名单

上一章算过：一个人的时间只够认真跟进很少的店。所以销售的第一个动作不是开口，而是**挑**——挑出最可能买、买了最可能用起来、用起来最可能续费的那一类店，其余的先不碰。

这一章做两件事：把「理想客户画像」（Ideal Customer Profile，ICP）写成能打分的条目，再把符合画像的店变成一份可以执行的名单。

## 画像不是「餐饮门店」

「中小餐饮门店」是市场，不是画像。按中国饭店协会《2026 中国餐饮业年度报告》的口径，截至 2025 年底全国收录的餐饮商户约 757.77 万家，比 2023 年底净增 72.14 万家（[北京日报客户端，2026-09-15](https://news.bjd.com.cn/2026/09/15/11959786.shtml)）。店多得是，不缺你去找的；但餐饮又是开店、关店都极其频繁的行业，各家机构每年统计的关店数量口径不一、差别很大，这里不引具体数字。对你来说结论是一样的：**挑错了店，你刚交付完它就关了**，续费更无从谈起。

画像要具体到你在街上看一眼、聊两句就能判断。写画像的方法是：**从产品能力倒推「谁用得上」，再从已成交和已流失的客户里修正**。

### hatch-counter 的产品能力决定了什么样的店用得上

| 产品事实 | 推出的画像条件 |
|---|---|
| 价值来自「导入收银报表算销量 + 配方扣库存」 | 有收银系统、能导出品项销售明细；菜单相对稳定，能配配方 |
| 内置报表格式只有美团收银一份，别家要指一次列 | 用美团收银的店上手最快；用别家的也能用，但第一次要你陪着 |
| 网页端在电脑浏览器里用，移动端以看数为主 | 收银台旁边有一台 Windows 或 Mac 电脑 |
| 一家店成员上限 8 人，一个账号能进几家店 | 1 到几家店的小老板；连锁总部、几十家店的不是目标 |
| 店主最想知道「今天挣了没、该进什么货」 | 老板自己管账、自己定进货，而不是交给总部或代账 |

### 写成打分卡

画像写成打分卡，每家店去之前或聊完后打一次分。下面是 hatch-counter 的版本，总分 10 分：

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 业态 | 正餐、小馆子，菜品几十道 | 小吃、面馆，菜品少但固定 | 档口、只卖一两样，或纯外卖店 |
| 收银 | 美团收银，能导报表 | 其他收银系统，能导报表 | 没有收银系统，或只用收款码 |
| 决策人 | 老板天天在店里 | 老板常来、店长管日常 | 老板不露面，或是加盟店、总部统一采购软件 |
| 经营状态 | 开业半年以上，饭点有客 | 开业不到半年 | 门可罗雀、门口贴着转让 |
| 管账习惯 | 已经在用 Excel 或本子记进货、算成本 | 不记，但嘴上关心成本 | 明确说「不用算，心里有数」 |

**6 分以上进名单，8 分以上优先跑**。打分卡的作用不是精确，而是逼你在出门前想清楚：这家店我凭什么觉得它会买。

### 不要碰的店

比「找谁」更省时间的是「不找谁」。下面几类店，第一阶段直接跳过：

- **加盟连锁的单店**：软件、收银往往由品牌总部统一规定，单店老板说了不算，聊得再好也签不了
- **正在转让、装修、刚换老板的店**：经营不稳定，就算买了也大概率用不过三个月
- **老板明确表示「我不会用电脑」且店里没有会用的人**：hatch-counter 天天的动作在电脑上，这种店交付成本极高
- **要求大量定制的店**：「你给我加个会员积分」「能不能接我的进销存」，这不是你的产品，第 6 章会讲怎么拒绝
- **熟人但不符合画像的店**：朋友开的奶茶店不配配方、不进大宗货，卖给他是人情，不是验证

## 先找到一个能用的细分

画像之外，还要选一个**细分**作为起点，原则是同一细分里的店彼此认识、问题相似，打下一家能带动几家。几种常见切法：

| 切法 | 例子 | 好处 | 注意 |
|---|---|---|---|
| 按地理 | 公司或家附近 2 公里内的一条美食街 | 周末好跑，老板之间互相认识 | 一条街的店数有限，跑完要换 |
| 按菜系 | 川菜小馆、湘菜馆 | 配方结构相似，演示数据可以复用 | 菜系内部也有大小店之分 |
| 按收银系统 | 都用美团收银的店 | 报表格式内置，上手最顺 | 收银系统本身不在门口写着，要问 |
| 按关系网 | 同一个食材供应商的客户、同一个老乡商会 | 有人引荐，信任高 | 依赖中间人，第 3 章讲 |

hatch-counter 仓库的 mock 数据是一家虚构川菜馆开业以来几个月的账，演示门店里有一年自洽的数据。所以**按菜系选川菜小馆作为第一个细分**最省事：演示时老板看到的菜名、配方、进货单就是他熟悉的那一套。

## 名单从哪来

名单就是一张表，每行一家店。来源有以下几种，按信任度从高到低：

1. **你和亲友本来就认识的店老板**：数量少，但第一批客户多半从这里来。不符合画像的也可以先去聊，目的是练习和要转介绍
2. **已成交客户的转介绍**：最好的来源，第 3 章专门讲
3. **行业里能批量接触门店的人**：食材供应商、收银系统代理、代账会计、餐饮设备和装修公司。他们每天跟老板打交道
4. **扫街**：周末在目标商圈走一遍，记下每家店的店名、业态、门口能看到的信息（营业时间、是否有收银机、是否贴转让）
5. **公开的平台信息**：大众点评、美团上能看到店名、地址、营业时间、评价数和人均。适合用来**筛**（评价数多说明有客流、经营稳定），不适合用来**联系**

### 不要买名单，不要爬手机号

网上有人卖「餐饮老板手机号名单」，也有人教你从平台批量抓商家联系方式。不要碰：

- 手机号是个人信息。《个人信息保护法》要求处理个人信息要有合法依据，购买来源不明的名单、批量抓取，在源头上就不合法；情节严重的，《刑法》第二百五十三条之一「侵犯公民个人信息罪」覆盖非法获取、出售、提供个人信息的行为。个人信息保护的基本义务见[《国内合规实务》第 6 章](../opc-compliance-cn/06-pipl.md)
- 对没同意接收的手机号群发营销短信，违反《通信短信息服务管理规定》。该规定 2026 年 2 月由工信部令第 74 号修订、2026 年 5 月 1 日起施行，第二十一条要求短信服务提供者为商业性短信息核验接收方同意或请求接收的证明材料，拿不出就不给发（[条文整理](https://www.elawcn.com/rule/2026/0501/1820.html)）
- 就算不考虑法律，冷冰冰的群发短信和陌生电话在门店老板那里的回应率极低，还会让你的号码被标记

**名单里只记你合法得到的信息**：店名、地址、业态这些公开的经营信息可以记；老板的手机号和微信，要等他本人给你的时候才记。

## 名单的字段

名单和第 10 章的销售管道是同一张表的前半段。现在先定义名单阶段要有的字段：

| 字段 | 例子 | 说明 |
|---|---|---|
| id | `S-0042` | 自己编号，后面所有记录用它关联 |
| 店名 | 老街川菜馆 | |
| 区域 | 某路美食街东段 | 按你跑街的路线分，方便一个下午排一串 |
| 业态 / 菜系 | 正餐 · 川菜 | |
| 来源 | 扫街 / 张老板介绍 / 供应商李哥 | 后面算各来源的转化率 |
| 画像分 | 7 | 第一次打分，见面后可以改 |
| 收银系统 | 美团收银 / 未知 | 不知道就写未知，见面时问 |
| 联系人 | 老板（姓王） | 只记称呼，没加微信前不记号码 |
| 阶段 | 名单 | 第 1 章的阶段 |
| 下一步 | 周六下午 3 点去 | 必须有日期 |
| 备注 | 饭点人多，老板下午在门口抽烟 | 任何有助于下次开口的细节 |

两个习惯：

- **每家店必须有「下一步」和日期**。没有下一步的店，要么移到「暂不跟进」并写原因，要么定一个日期
- **记录「不合适」的原因**。被你排除的店，写下「加盟店」「准备转让」，三个月后回头看，这些原因就是你画像的修正依据

## 画像要随成交修正

画像是假设，前 10 家成交和前几家流失就是检验。每成交或流失一家，问三个问题：

1. 它的画像分是多少？高分店是不是真的更容易成交、更少流失？
2. 有没有低分但成交了、用得很好的店？它有什么共同点是打分卡没覆盖的？
3. 流失的店里，有没有在打分卡上就能提前看出来的信号？

举个可能出现的修正：你也许会发现「老板已经在用 Excel 记进货」这一条比「收银系统是哪家」更能预测成交——会用 Excel 的老板对数字敏感、愿意录数据。那就把它的权重调高。修正后的打分卡记下版本和日期，方便以后比较。

## 本章要点

- 「中小餐饮门店」是市场不是画像；全国七百多万家，每年大批关店，挑错店等于白交付
- 从产品能力倒推画像：有收银系统能导报表、菜单稳定、收银台有电脑、老板自己管账自己拍板
- 画像写成 10 分制打分卡，6 分以上进名单、8 分以上优先；加盟单店、转让中、要大量定制的店直接跳过
- 先选一个细分起步，hatch-counter 选川菜小馆，演示数据可直接复用
- 名单来源按信任度：熟人、转介绍、行业中间人、扫街、平台公开信息；不买名单、不爬手机号、不群发未经同意的营销短信
- 每家店必须有下一步和日期，排除的店写清原因，用成交和流失修正画像

# 签不签 MCN

做到一定程度，几乎每个博主都会收到 MCN 的签约邀请：「我们手上有很多品牌资源」「签了帮你接单、帮你运营」「我们旗下的 ×× 一年涨了 50 万粉」。对一个下班做内容、不懂商务的开发者来说，这听起来很诱人：把最头疼的谈价、对接、结算全部交给别人。

这一章讲 MCN 到底做什么、怎么分钱、什么情况下值得签，以及合同里最常见的坑。MCN 合同涉及的法律问题（合同性质、解约、违约金的司法实践）在[《自媒体与短剧合规财税》](../media-compliance/)里有系统讲解，这里从商单的角度讲判断和谈判。

## MCN 是什么

MCN（Multi-Channel Network）在国内泛指签约并运营一批博主的机构。不同 MCN 的业务差别很大：

| 类型 | 主要做什么 | 对你的价值 |
|---|---|---|
| **商务型** | 给旗下博主接商单，抽佣 | 解决「没单」和「不会谈」 |
| **孵化型** | 从内容策划、拍摄剪辑到运营全包，打造账号 | 解决「做不出来」；但你可能只是「出镜的人」 |
| **电商型** | 以直播带货、供应链为主 | 解决选品和货源；见[《带货与选品》](../ecommerce-selling/)[《直播实战》](../live-streaming/) |
| **平台服务型** | 帮你开通平台权限、拿流量扶持、做数据分析 | 价值有限，很多事情你自己能做 |

签之前先问清楚：**这家 MCN 到底是哪一种，靠什么挣钱，打算从你这里挣什么钱。**

## MCN 怎么分钱

商务型 MCN 最常见的模式是**商单分成**：MCN 帮你接到的商单（有时是你所有的商单），按比例分成。

分成比例没有可靠的公开行业数据，不同 MCN、不同博主量级差异很大，常常还会分档（比如 MCN 带来的单和你自己带来的单比例不同）。你要看的不是比例本身，而是下面这些问题：

| 问题 | 为什么重要 |
|---|---|
| **分成的基数是什么**：所有商业收入，还是只有 MCN 带来的单？ | 很多合同写「乙方全部商业收入」，包括你自己谈来的、平台激励、带货佣金、甚至线下活动 |
| **扣除什么之后再分**：平台服务费、税费、制作成本谁承担？ | 「先分再扣」和「先扣再分」差别很大 |
| **钱经过谁的手**：品牌付给 MCN 再分给你，还是直接付你？ | 钱过 MCN 的手，你就有被拖款的风险 |
| **结算周期**：MCN 收到款后多久付你？ | 见过「季度结算」「收到款后 90 天」 |
| **你能不能看到品牌的实际付款**？ | 有的 MCN 对品牌报 2 万、对博主说 1 万，再按 1 万分成 |

最后一条是 MCN 纠纷里最常见的一种：**信息不透明**。合同里要争取：「乙方有权查阅与其相关的商务合同及付款凭证」。

在星图上，MCN 达人的收益由 MCN 机构结算，不向平台开票（《巨量星图结算管理规则》），也就是说，平台订单的钱会先到 MCN。签约前要确认 MCN 给你的结算方式和周期。

## 什么情况下值得签

用这张表自评：

| 情况 | 签约价值 |
|---|---|
| 你的数据还不稳定，内容方向还在摸索 | **低**。MCN 对你的投入有限，合同却会锁你很多年 |
| 你有稳定数据，但完全没有商单，主动出击也没进展 | **中**。商务型 MCN 可能帮你破局；先试短期或非独家 |
| 你已经有稳定的商单，主要瓶颈是时间不够谈 | **中**。可以考虑，但要算清楚分成后是否比自己谈划算；或者考虑找按单付费的商务助理 |
| 你需要专业团队帮你做内容（拍摄、剪辑、策划） | **看情况**。孵化型 MCN 能做，但账号和 IP 的归属要谈清楚 |
| 你想把内容做成长期事业，账号是主要资产 | **谨慎**。签约等于把部分资产的控制权交出去 |
| 你是在职开发者，内容是副业 | **一般不需要**。副业的时间弹性和 MCN 的考核要求常常冲突 |

一个关键认知：**MCN 是一种外包**。你在用分成去购买它的服务（商务、运营、制作）。所以判断标准就是：它提供的服务，值不值得这个价格？你能不能用别的方式（自己学、兼职商务、按单付费的代理）更便宜地得到？

在职开发者的特殊情况还有一条：**你的劳动合同可能有兼职限制或竞业限制**，签 MCN 前先确认本职工作的合同和公司制度。

## 签之前要做的尽调

```text
□ 查公司：企业信用信息公示系统 / 企查查类工具，看成立时间、注册资本、
  股东、有没有经营异常、被执行记录、涉诉记录（尤其和博主的纠纷）
□ 问旗下博主：找 2–3 个它签约的、和你量级相近的博主私下聊，
  问接单量、结算是否准时、解约是否顺利
□ 看平台资质：是否是平台认证的 MCN（星图、蒲公英等平台都有机构入驻）
□ 要具体承诺：「每月保证 ×× 单」「首年商单收入不低于 ××」，
  对方愿不愿意写进合同？只口头说的，当作没说
□ 要合同全文：带回去看至少一周，不在对方办公室当场签
```

最后一条特别重要。「今天签有额外福利」「这个名额很紧张」，都是压你当场签的话术。

## 合同里最常见的坑

下面按合同条款逐条讲。拿到 MCN 合同，对照这张清单：

| 条款 | 常见写法 | 坑在哪里 | 争取 |
|---|---|---|---|
| **合同期限** | 3 年、5 年，甚至更长；自动续期 | 锁定你最有价值的几年 | 1–2 年；不自动续期，或续期需双方书面确认 |
| **独家** | 「独家经纪」，全部商业活动只能通过 MCN | 你自己谈来的单也要分成，甚至不能自己谈 | 非独家；或者只独家某一平台、某类合作 |
| **范围** | 「乙方在全平台、全渠道的一切商业活动」 | 包括你没签约的平台、未来新开的账号、线下活动 | 限定到具体平台和具体账号 |
| **账号归属** | 「账号由甲方运营，账号所有权归甲方」或要求你交出账号密码 | 解约时账号拿不回来 | 账号归你；MCN 只有运营协作的权限；不交密码 |
| **知识产权** | 「合同期间产生的全部内容著作权归甲方」 | 你的作品、你的 IP 不再属于你 | 你独立创作的内容著作权归你；MCN 出资制作的另行约定 |
| **艺名 / 账号名** | 「艺名及相关商标归甲方」 | 解约后不能再用这个名字 | 名字归你；MCN 若注册商标，解约时无偿转让给你 |
| **考核** | 每月必须更新 ×× 条、直播 ×× 小时 | 副业做不到，构成违约 | 删除或降低到你能做到的水平；未达标的后果不应是违约金 |
| **违约金** | 固定违约金几十万到几百万，或「合同期内预期收益」的若干倍 | 解约成本高到你无法承受，等于被锁死 | 与合同金额或实际损失挂钩；设置上限；对等约定 MCN 违约的责任 |
| **单方解约** | 只有 MCN 可以解约 | 不对等 | 约定双方的解约条件；MCN 未履行承诺（如连续 N 个月没有商单、拖欠款项）时你可以解约 |
| **结算** | 季度结算、「收到款后」结算 | 拖款 | 月结；收到品牌款后 15 个工作日内结算；有权查账 |
| **竞业** | 解约后若干年不得在同平台做同类内容 | 解约后你无法继续做内容 | 删除；或限定很短的期限并有补偿 |
| **成本扣除** | 「甲方为乙方支出的运营、推广、培训费用由乙方承担」 | 解约时突然冒出一笔「培训费」「推广费」要你还 | 删除；或者约定任何费用需你事先书面同意 |

### 几个坑展开说

**违约金和「天价索赔」**

MCN 合同纠纷里，最常见的局面是：博主想解约，MCN 主张高额违约金。合同里的违约金过分高于实际损失的，可以请求法院或仲裁机构适当减少（《民法典》第五百八十五条），但这需要你去打官司，时间和精力成本很高，而且结果不确定。**最好的办法是签之前就把违约金改到合理水平**。具体的司法实践和应对，见[《自媒体与短剧合规财税》第 7 章](../media-compliance/07-mcn-contracts.md)。

**账号归属**

账号是你最重要的资产。各平台的用户协议通常规定账号使用权属于实名注册人，但 MCN 合同可能约定账号由 MCN 管理、或要求你配合转让。原则：

- 账号用你自己实名注册的，就一直用你自己的实名
- 不交出主账号密码；需要协作的，用平台提供的机构授权、子账号等功能
- 合同里写明「账号的注册人、使用人和实际控制人为乙方」

**孵化型 MCN 的「你只是出镜的人」**

孵化型 MCN 出策划、出团队、出钱，你负责出镜。这种模式下，MCN 会主张账号和 IP 归它，因为它投入了大部分成本。这在商业上有其合理性，但你要清楚：**签了这种合同，你更接近一个按项目合作的演员，而不是账号的主人**。想清楚自己要的是哪种角色。

## 和 MCN 谈判

MCN 的合同通常是格式合同，但几乎所有条款都可以谈，尤其当你已经有稳定数据的时候。谈判话术：

```text
感谢你们的认可，我对合作很有兴趣。合同我看了，有几处想调整：

1. 期限：我希望先签 1 年，合作得好再续，这对双方都更稳妥。
2. 范围：我目前只希望把抖音账号的商单交给你们，
   小红书和我自己的公众号由我自己运营。
3. 独家：我自己谈来的品牌不经过你们，不参与分成；
   你们带来的单按约定比例分。
4. 账号：账号仍由我实名持有，我不交出密码，可以用平台的机构授权功能协作。
5. 违约金：希望改为不超过前 12 个月实际分成收入，并且双方对等。
6. 解约：如果连续 3 个月没有你们带来的商单，或者结算逾期超过 30 天，
   我可以书面通知解约。

这几条对我很重要，能谈的话我们继续推进。
```

如果 MCN 一条都不让，说明它对你的预期是「锁住」而不是「合作」，不签。

## 不签 MCN 的替代方案

不签 MCN，也有办法解决它想解决的问题：

| 你的需求 | 替代方案 |
|---|---|
| 没有单 | 第 3 章的主动出击；平台的招募 / 投稿任务；入驻平台后完善资料 |
| 不会谈价 | 第 4 章的倒推法和报价单；成交表积累数据 |
| 没时间对接 | 找一个兼职商务助理，按单付佣金，签书面协议，限定在单个合作内 |
| 需要剪辑、拍摄帮手 | 按条外包，签委托创作合同，约定著作权归你（[《合同与法律文书》第 6 章](../contracts-legal/06-ip-clauses.md)「知识产权条款」） |
| 想要流量扶持 | 平台官方的创作者计划、新人扶持，个人一般也能申请 |
| 结算和开票麻烦 | 注册个体户，自己开票（第 7 章；[《自媒体与短剧合规财税》第 9 章](../media-compliance/09-entity.md)） |

对多数在职开发者来说，这些替代方案组合起来，比签一份 3 年独家的 MCN 合同更灵活，也更安全。

## 已经签了怎么办

如果你已经签了一份不理想的 MCN 合同：

1. **重新读一遍合同**，找到解约条件、违约金、通知期
2. **整理证据**：MCN 没有履行的承诺（没有接到单、结算延迟、扣钱不透明），保留聊天记录、结算单、银行流水
3. **先谈**：书面提出你的诉求（调整条款或协商解约），很多 MCN 也不想打官司
4. **谈不拢找律师**：MCN 合同纠纷有不少判例，专业律师能帮你判断胜算和成本。什么时候需要律师、怎么找，见[《合同与法律文书》第 9 章](../contracts-legal/09-when-to-hire-lawyer.md)「什么时候找律师」
5. **合同存续期间不要单方面违约**（比如直接绕开 MCN 接单），这会让你在纠纷中处于不利地位

## 本章要点

- MCN 分商务型、孵化型、电商型、平台服务型，签之前先弄清它靠什么挣你的钱
- 看分成不只看比例：分成基数、先扣还是先分、钱经谁的手、结算周期、你能否查账
- MCN 是外包：判断它提供的服务值不值这个价，有没有更便宜的替代；在职开发者先确认本职合同的兼职和竞业限制
- 签约前尽调：查公司、问旗下博主、要书面承诺、合同带回去看
- 合同常见坑：期限过长、全范围独家、账号和名字归 MCN、内容著作权归 MCN、考核过严、天价违约金、单方解约、季度结算、解约后竞业、事后冒出的成本；逐条谈，一条都不让的不签
- 不签 MCN 也有替代方案：主动出击、倒推报价、兼职商务助理、按条外包、注册个体户
- 已经签了的：读合同、存证据、先谈、谈不拢找律师，存续期间不单方违约

# 个人品牌

大公司卖的是公司，一人公司卖的很大程度上是你这个人。用户愿意把门店的账交给一个没听说过的小产品，往往是因为他相信做这个产品的人。这一章讲个人品牌里「写」的那部分：怎么用一句话说清你是谁，简介和关于页怎么写，持续输出时怎么保持同一个声音，以及哪些东西不该写出来。在哪些平台上运营、怎么涨粉，见《获客与增长》。

## 个人品牌是什么

个人品牌不是人设，也不是包装。它就是**别人提到你时，会想到的那一两件事**。

对独立开发者来说，好的个人品牌通常长这样：

- 「那个做餐馆管理软件的，他特别懂小馆子怎么算账」
- 「那个写离线阅读器的，他的博客讲 Expo 讲得很实在」

注意这两句话的共同点：**一个领域 + 一个具体的特质**。不是「一个很厉害的开发者」，那等于没有印象。

个人品牌对一人公司有几个实际的作用：

| 作用 | 为什么 |
|---|---|
| 降低信任成本 | 用户看过你的文章、知道你是谁，比面对一个无名产品更敢试 |
| 产品之间可以传递 | 第一个产品的读者，是第二个产品的种子用户 |
| 带来意外的机会 | 合作、咨询、投资人、同行交流，大多是因为「看过你写的东西」 |
| 抵御抄袭 | 功能可以被抄，你这个人和你积累的信任抄不走 |

## 一句话定位

所有的个人品牌文案，都从一句话定位开始。它回答三个问题：

```text
我是 ______（身份），
为 ______（谁）
做 ______（什么，最好带结果）。
```

几个例子：

| 太泛 | 具体 |
|---|---|
| 全栈开发者，热爱技术 | 独立开发者，给中小餐馆做经营管理工具，帮店主看清哪道菜在赚钱 |
| 产品爱好者、终身学习者 | 一个人做 App，写 Expo 和离线优先的实践 |
| 连续创业者 | 做过三个小产品，正在做第四个，记录一人公司从零到有收入的过程 |

写不出具体的版本，往往不是文案问题，而是你还没决定要专注在什么上。这时候不要硬写，先回去想清楚方向（《一人公司方法论》和《产品思维》会帮你想）。

定位不是一辈子的。做到第二个产品时改一次很正常，但**同一时期内所有地方要一致**：社交平台简介、个人网站、产品的关于页、你在社区里的自我介绍，说的是同一句话。

## 简介怎么写

各个平台的个人简介字数都很少，所以更要每个字都有用。

一个好简介通常包含：

1. **你是谁**：一句话定位
2. **一个证据**：你做过什么、正在做什么
3. **一个去处**：读者想深入了解，去哪儿

```text
独立开发者。在做「掌柜眼」，给小馆子算清每道菜赚不赚钱。
写一人公司的产品、技术和账本。
```

不要写的：

- **一串身份标签**：「开发者 / 设计师 / 摄影师 / 咖啡爱好者 / 终身学习者」，读者记不住任何一个
- **空泛的口号**：「用代码改变世界」
- **让人猜的梗**：只有你朋友才懂的玩笑
- **过时的信息**：一年前的产品、已经停更的项目

头像和名字也是简介的一部分：**所有平台用同一个名字、同一个头像**。读者在一个平台见过你，到另一个平台能认出来，这比任何文案都重要。

## 关于页怎么写

个人网站或产品官网上的「关于」页，是读者想认真了解你时才会点开的。它的读者已经有了兴趣，所以可以写得比简介详细，但仍然要有结构。

```markdown
# 关于

## 我是谁
一两句话。一句话定位，加上你在哪、做这个多久了。

## 我在做什么
正在做的产品，每个一句话说清是什么、给谁用，附链接。

## 为什么做
你和这个领域的关系。为什么是你来做这件事。
这部分最能建立信任，要写真实的经历，不要写使命宣言。

## 我写什么
博客 / 公众号写哪些主题，挑两三篇代表作。

## 怎么找到我
联系方式。写清楚你愿意回复什么（用户反馈、合作），不回复什么。
```

「为什么做」是关于页的核心。对比两种写法：

```text
使命宣言式：
我们致力于用科技赋能传统餐饮行业，助力中小商户实现数字化转型。

真实经历式：
我家里有人开小馆子。每到月底，账本、进货单、收银小票摊一桌子，
算到半夜也说不清这个月到底赚没赚钱。我想做一个能把这件事变简单的工具。
```

第二种没有一个大词，但读者知道你为什么懂这件事、为什么会认真做下去。（上面是写法示例，你要写的是你自己的真实经历。）

## 同一个声音

个人品牌靠的是**重复**：读者在不同时间、不同地方看到你写的东西，感受到的是同一个人。这需要你的文字有稳定的「声音」。

声音由几个可以描述的东西组成：

| 维度 | 你可以选 | 例子 |
|---|---|---|
| 正式程度 | 口语 ↔ 书面 | 「重新登录一下」vs「请重新登录」 |
| 人称 | 你 / 您，我 / 我们 | 一人公司用「我」更真实，产品界面可以用「我们」指代服务方 |
| 态度 | 克制 ↔ 热情 | 少用感叹号，还是多用 |
| 幽默 | 几乎不用 ↔ 经常用 | 报错里不开玩笑，是很多产品的共识 |
| 专业度 | 解释术语 ↔ 直接用 | 看读者是谁 |

把你的选择写进第 5 章说的 `style.md`。这样即使让 agent 帮你写初稿，它也知道该用什么声音。

掌柜眼的声音就很清楚：口语、具体、像店里的人说话（「很久没用了，重新登录一下」「收条验证码就能进来」），不卖萌、不吓唬人。产品文案、官网、常见问题都是这个调子，所以读起来像一个人写的。

### 产品的声音和你的声音

一人公司有个特殊情况：产品和你本人是两个「说话的人」。它们可以有区别，但不要冲突：

- **产品界面**：克制、清楚，以用户完成任务为先
- **你的文章、社交平台**：可以更有个性，讲观点、讲过程、讲失败
- **官网**：介于两者之间，可以有「我」的存在（比如关于页），但主体是产品

## 写什么能建立品牌

持续输出的内容里，最能建立个人品牌的不是「新闻」和「转发」，而是**只有你能写的东西**：

| 内容 | 为什么有效 |
|---|---|
| 你做的决定和理由 | 展示判断力，这是别人最难复制的 |
| 你踩的坑和怎么爬出来 | 真实、有用，读者会记住你帮过他 |
| 你对领域的观点 | 有观点才会被记住，人云亦云不会 |
| 你的数据和复盘 | 公开数据需要勇气，读者会因此信任你 |
| 你学到的行业知识 | 为了做产品去学的东西，对别人也有用 |

不要写的：

- 纯转发新闻、不加自己的判断
- 和你的定位毫无关系的话题（偶尔可以，但别成为主体）
- 为了流量蹭热点
- 别人的观点换个说法当成自己的

### 观点要有边界

有观点才会被记住，但观点要说清边界：在什么情况下成立，什么情况下不成立。

```text
没有边界：空态里不要放按钮。

有边界：空态里的按钮如果只是页头按钮的复制品，就别放，同一件事摆两处会让人愣一下。
但如果那件事在这一页上只有空态这一处做得了，就该放。
```

后一种不会被轻易反驳，也显得你想得更深。这是掌柜眼界面规范的写法，规矩和例外写在一起。

## 不该写出来的东西

公开写作有风险，有些东西要守住：

- **用户和客户的数据**：具体店名、营业额、员工姓名、截图里的真实数据，一律不写。要用数据就用聚合后的、无法追溯到个人或门店的结论，最好先征得同意
- **安全相关信息**：服务器地址、域名配置细节、密钥、内部接口，哪怕只是截图里一闪而过
- **你自己不想公开的私事**：个人品牌不等于公开一切。想清楚哪些边界要守，比如家人、住址、收入的具体数字
- **对竞品和具体个人的攻击**：可以对比产品，不要攻击人。网络上的话会留很久
- **你没核实的说法**：尤其是法规、税务、安全方面，错误的说法会损害你的专业形象

写完发出前问一句：**如果这篇被我的用户、同行、未来的合作方看到，我会不会后悔？**

## 慢，但会复利

个人品牌是最慢的一种资产。头半年你写的东西可能只有几十个人看，这很正常。但它有复利：

- 文章会被搜到，一年后还在带来读者
- 读者会转发，你会被更多人知道
- 写得越多，你的声音越稳定，写得越快
- 第一个产品积累的信任，会转移到第二个产品

不要用「涨了多少粉」衡量它，用「有多少人因为看过我写的东西来找我」衡量。

## 本章要点

- 个人品牌就是别人提到你时想到的那一两件事：**一个领域 + 一个具体特质**
- 所有文案从一句话定位开始：我是谁、为谁、做什么；同一时期所有地方保持一致
- 简介写定位 + 一个证据 + 一个去处；所有平台用同一个名字和头像
- 关于页的核心是「为什么做」，写真实经历，不写使命宣言
- 把你的声音写成可以描述的几个维度，放进 `style.md`；产品的声音和你的声音可以不同但不冲突
- 最能建立品牌的是只有你能写的东西：决定、踩坑、观点、数据；观点要说清边界
- 用户数据、安全信息、私事、人身攻击、未核实的说法，不写

# 题材赛道与内容红线

动笔前的第一个决定是写什么题材。题材决定了受众是谁、他们为什么爽、平台愿不愿意收、做出来要花多少钱。这一章先讲男频和女频，再逐个拆主流题材的受众和核心爽点，然后讲哪些题材适合 AI 漫剧，最后讲内容红线：哪些写法过不了审，怎么改写。

## 男频和女频

男频、女频是网文行业沿用过来的分法，指作品主要面向的读者性别，不是写作者的性别。

| | 男频 | 女频 |
|---|---|---|
| 主角 | 多为男性 | 多为女性 |
| 核心欲望 | 变强、被认可、掌控局面 | 被爱、被尊重、独立、找回属于自己的东西 |
| 情绪重心 | 打脸、逆袭、实力碾压 | 情感拉扯、虐后甜、成长与反击 |
| 感情线 | 常作辅线 | 常作主线或与事业线并重 |
| 典型题材 | 逆袭、都市异能、玄幻修仙、战神 | 甜宠、虐恋、重生复仇、宅斗、萌宝 |

这只是粗分。很多剧男女观众都有，比如悬疑、家庭、年代题材。选男频还是女频，主要影响两件事：主角的欲望写什么，以及情绪兑现的方式（男频偏「赢」，女频偏「被看见」）。

## 主流题材拆解

下表是常见题材的受众和核心爽点。受众描述是行业里普遍的说法，属于经验判断，不同平台的观众画像差异很大，具体以平台后台数据为准。

| 题材 | 主要受众 | 核心爽点 | 常见骨架 | 主要风险 |
|---|---|---|---|---|
| 逆袭 | 男频为主，下沉市场 | 被看不起 → 实力揭晓 → 打脸 | 隐藏身份 / 能力的主角受辱，一步步翻盘 | 容易写成炫富、暴力复仇 |
| 甜宠 | 女频，年轻女性 | 被坚定地选择、被宠 | 误会 → 靠近 → 守护 → 确认心意 | 「霸总」式攀附权贵婚恋观 |
| 悬疑 | 男女都有 | 解谜、反转、真相揭晓 | 案件 / 谜团驱动，每集一个线索 | 逻辑漏洞；暴力、血腥画面尺度 |
| 家庭伦理 | 中年观众，女性偏多 | 委屈被看见，恶人得报应 | 被亏待的一方觉醒、反击、离开 | 激化家庭矛盾，渲染对立 |
| 职场 | 都市年轻人 | 专业能力被认可，打败「坏上司」 | 新人受压 → 用专业解决问题 → 升职 | 写得不专业会被吐槽 |
| 古风（宫斗 / 宅斗） | 女频 | 智斗、身份翻转、步步为营 | 庶女 / 弃妃一步步在规则里取胜 | 服化道成本高（实拍）；歪曲历史 |
| 玄幻修仙 | 男频为主 | 变强、升级、越级挑战 | 废柴 → 奇遇 → 修炼 → 宗门大比 | 设定太多讲不清 |
| 都市异能 / 系统 | 男频 | 规则外挂带来的碾压感 | 获得系统 / 异能，接任务，逆袭 | 同质化严重 |
| 重生 / 穿越 | 女频偏多 | 信息差：我知道结局 | 带着前世记忆回来改命 | 「复仇」写过头 |
| 年代 | 中年观众 | 勤劳致富、家人和解 | 回到某个年代，靠双手过上好日子 | 时代细节要准 |
| 萌宝 | 女频 | 孩子的聪明和可爱、家庭团圆 | 萌宝帮妈妈找回公道 | 涉未成年人的内容要特别小心 |

### 爽点到底是什么

「爽点」不是一个玄学词。它是**观众期待已久的一个情绪被兑现的时刻**。几种最常见的兑现：

| 爽点类型 | 观众期待 | 兑现时刻 |
|---|---|---|
| 打脸 | 看轻主角的人被证明错了 | 主角当众展示实力 / 身份 |
| 身份揭晓 | 隐藏的身份被知道 | 「原来他就是……」 |
| 被宠 | 受委屈的主角被人坚定站队 | 有人当众维护她 |
| 真相 | 谜底揭开 | 关键证据出现 |
| 恶有恶报 | 反派付出代价 | 反派被依法依规处理、众叛亲离 |
| 成长 | 主角克服了自己的弱点 | 主角第一次做到以前做不到的事 |

爽点必须先「压」后「扬」：没有委屈就没有打脸，没有误会就没有和解。第 6 章讲情绪曲线时会细讲压和扬的比例。

## 哪些题材适合 AI 漫剧

AI 漫剧（用图像、视频生成模型做画面，加配音和剪辑）和真人实拍的成本结构完全不同。实拍贵的东西（特效、古装大场面、怪物、飞天）在 AI 里相对便宜；实拍便宜的东西（演员细腻的表情、多人对话、真实的生活质感）在 AI 里反而难。

| 对 AI 友好 | 原因 |
|---|---|
| 玄幻修仙、仙侠 | 特效、法术、异兽、宗门场景，实拍成本高，AI 生成相对容易 |
| 末世、科幻 | 废墟、怪物、机甲，同上 |
| 古风奇幻 | 古装和宫殿场景可以复用一套设定图 |
| 系统、异能 | 「系统面板」「技能特效」本来就是画面元素 |
| 萌宠、奇幻动物 | 非人角色的一致性比真人脸容易保持 |

| 对 AI 不友好 | 原因 |
|---|---|
| 大量群戏 | 同一画面里多个角色要同时保持一致，难度和返工量成倍增加 |
| 依赖微表情的感情戏 | 眼神、停顿、哽咽这类表演，AI 目前很难稳定做好 |
| 复杂连续动作 | 打斗、追逐的动作连贯性难控制，可以用但成本高 |
| 现实题材的生活质感 | 观众对写实画面的「假」非常敏感 |

行业里也在出现「AI 仿真人」漫剧（用 AI 生成接近真人观感的画面）。有报道引用 DataEye 统计称，2026 年 1 月番茄、抖音等平台漫剧综合榜 Top 100 中，AI 真人模拟类占比约 38%，一年前约 7%（中国国际广播电台 Panda Shorts 2026-01-23 报道）。这类作品的题材选择更接近真人短剧，但上面「不友好」的几条仍然适用。

对编剧的直接影响是：**写 AI 漫剧时，同一场戏里的有台词角色尽量控制在 2–3 个，主要角色控制在 5–8 个，场景尽量复用**（行业经验）。第 7 章讲剧本格式时会讲怎样把这些信息写进剧本。

## 选题材：题材分析表

新手最容易犯的错是选自己喜欢但没有观众的题材，或者跟风一个已经饱和的题材。用一张表强迫自己把理由写出来：

```text
候选题材：
1. 目标受众（男频 / 女频 / 全年龄；年龄段；平台）：
2. 核心爽点（从上面的爽点类型里选 1–2 个）：
3. 同题材热门剧 3 部（剧名 / 集数 / 卡点位置）：
4. 这些剧的共同骨架：
5. 我的新意（新外壳 / 新职业 / 新设定 / 新关系）：
6. AI 制作难度（1–5 分，5 最难）及原因：
7. 合规风险（1–5 分，5 最高）及原因：
8. 我对这个题材的熟悉程度（1–5 分）：
9. 一句话故事（第 4 章讲写法）：
```

几个候选题材都填完以后，按下面的权重粗算一个分（权重是本书的建议，按你的情况调）：

| 维度 | 权重 | 说明 |
|---|---|---|
| 受众规模 | 25% | 同题材热门剧多不多，播放量高不高 |
| 新意 | 25% | 骨架可以老，外壳要新 |
| 制作难度（反向） | 20% | 自己做 AI 漫剧时尤其重要 |
| 合规风险（反向） | 15% | 风险高的直接排除 |
| 熟悉程度 | 15% | 熟悉的行业、职业更容易写出细节 |

### 骨架老，外壳新

短剧观众要的是熟悉的情绪，不是陌生的结构。最常见的成功路径是：**用一个被验证过的骨架，换一层新外壳**。

| 骨架 | 旧外壳 | 新外壳的思路 |
|---|---|---|
| 隐藏实力的人被看不起，最后揭晓 | 战神、赘婿 | 换成一个冷门职业：古籍修复师、调律师、老药工 |
| 带着前世记忆改变命运 | 豪门千金重生 | 换成职场、行业变迁 |
| 契约关系里慢慢动心 | 契约婚姻 | 换成搭档、师徒、同事 |

开发者的天然优势在这里：你熟悉的技术、行业、职场，都可以成为新外壳。本书完整示例（第 9、10 章）就是把「废柴逆袭」骨架套在「在藏经阁给功法改错字」这个外壳上，主角的能力很像一个程序员在找 bug。

## 内容红线

题材选对了，还要保证写出来能播。短剧的审核规则这几年密集出台，编剧要了解的是**导向层面的要求**，备案和发行流程见《短剧发行、投流与备案》，广告、肖像、AI 标识等合规见《自媒体与短剧合规财税》。

### 监管怎么分层

国家广电总局《关于进一步统筹发展和安全促进网络微短剧行业健康繁荣发展的通知》（据新华社 2025-02-05 报道）把微短剧分三类管理：

- **重点微短剧**：涉及特殊题材，或总投资 100 万元及以上，或被平台招商主推、首页首屏推荐，需报省级以上广电部门规划备案和成片审查
- **普通微短剧**：总投资 30 万–100 万元，同样报省级以上广电部门备案和审查
- **其他微短剧**：总投资不足 30 万元，由播出或引流的平台负责内容审核和版权核定

小成本 AI 漫剧多数落在第三类，但「平台审核」不等于宽松：平台要对内容负责，会按同一套导向标准审。

### 写作层面的红线清单

把上面的要求翻译成编剧动笔时的检查项：

| 红线 | 典型写法 | 可以怎么改 |
|---|---|---|
| 拜金炫富 | 主角亮出黑卡、豪车、天价礼物让对方下跪 | 爽点改成能力、品格被认可；钱只是背景，不是爽点本身 |
| 攀附权贵的婚恋观 | 灰姑娘靠嫁入豪门改变命运 | 两个人各自有事业和追求，感情建立在互相尊重上 |
| 暴力复仇 | 主角私刑报复，越狠越爽 | 反派因自己的行为付出代价：证据曝光、依法处理、众叛亲离 |
| 软色情擦边 | 暧昧镜头、衣着暴露、性暗示台词 | 感情戏靠关系和台词推进，镜头克制 |
| 涉儿童有害 | 儿童被虐待的细节画面、儿童模仿危险行为 | 萌宝题材里孩子聪明可爱，不让孩子身处被渲染的危险和暴力里 |
| 封建糟粕 | 宣扬迷信、宿命论、愚孝 | 古风、玄幻题材的设定要明确是虚构世界，不把迷信当真理宣扬 |
| 歪曲历史 | 戏说真实历史人物和事件 | 用架空朝代、虚构人物；涉及真实历史要尊重史实 |
| 低俗片名 | 用擦边、猎奇字眼当片名 | 片名点出题材和看点即可 |
| 畸形婚恋观 | 控制、虐待被包装成爱 | 强势可以，不尊重、不平等的行为要被剧情否定 |
| 侵权盗版 | 照搬热门剧情节、改编未授权网文 | 原创；改编先拿授权（第 8 章） |

一个实用的判断：**把爽点那场戏单独剪出来，当成一条短视频发出去，它在宣扬什么？** 如果答案是「有钱就能为所欲为」「打得越狠越解气」，就要改。

### 红线不等于不能写冲突

很多新人知道红线以后不敢写反派、不敢写冲突。其实审核要求的是**导向**：反派可以坏，但剧情要否定他；主角可以受委屈，但翻盘要靠正当手段；可以有打斗，但不渲染血腥细节。好故事从来不靠这些「捷径」，被限制的恰恰是低质量的写法。

## 本章要点

- 男频的核心欲望偏「变强、赢」，女频偏「被爱、被尊重」，这决定了主角欲望和情绪兑现的方式
- 爽点是期待已久的情绪被兑现的时刻，必须先压后扬
- AI 漫剧适合玄幻、仙侠、末世、古风奇幻、系统类题材；控制同场有台词角色数和场景数
- 用题材分析表比较候选题材；骨架可以老，外壳要新，开发者熟悉的行业是好外壳
- 广电对微短剧分三类审核，小成本作品由平台审，但标准一样；拜金炫富、暴力复仇、软色情擦边等是明确点名的问题
- 检查爽点的办法：把那场戏单独拿出来看它在宣扬什么

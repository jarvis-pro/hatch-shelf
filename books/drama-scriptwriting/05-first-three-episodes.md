# 开篇前三集

前三集决定一部短剧的生死。投稿时编辑先看前几集决定评级；上线后投流素材大多从前几集剪；观众在前三集里决定要不要追。这一章讲前三集各自的任务、黄金开场的几种写法、怎么把冲突前置，并用一段反面示例演示怎么改。完整的前三集剧本见第 10 章。

## 前三集各自的任务

| 集 | 核心任务 | 观众看完应该知道 | 情绪 |
|---|---|---|---|
| 第 1 集 | 立人设、抛冲突、亮出反差的苗头 | 主角是谁，正在受什么委屈，他身上有什么不一样 | 压，结尾转悬 |
| 第 2 集 | 第一次小反击（小爽点） | 主角不是任人欺负的，他的能力是真的 | 压→扬 |
| 第 3 集 | 确立主线，抛出更大的谜或威胁 | 这部剧真正要讲的事是什么，为什么值得追 | 扬→悬 |

三集合起来，完成一个最小闭环：**受压 → 小反击 → 发现更大的问题**。观众在第 3 集结尾既得到了一次满足，又被一个更大的钩子拉住。

一个常见错误是把三集的任务全塞进第 1 集，或者三集都在受压、迟迟不反击。前者信息过载，后者观众憋到第 3 集就划走了。

## 黄金开场：第一个画面和第一句台词

短剧的第一个画面要在 3–5 秒内让观众停下来。常用的开场方式：

| 开场方式 | 做法 | 适合的题材 |
|---|---|---|
| 冲突开场 | 第一个画面就是对抗：被羞辱、被退婚、被当众宣判 | 逆袭、家庭、古风 |
| 身份反差开场 | 先给一个反差画面：穿着保洁服的人在会议室里纠正 CEO | 逆袭、职场 |
| 危机开场 | 倒计时、悬崖边、即将发生的灾难 | 悬疑、末世 |
| 反常画面开场 | 一个违反常识的画面：书上的字在发光、死人睁开眼 | 玄幻、悬疑、系统 |
| 结局前置开场 | 先放后面最高潮的一个画面，再「三天前」倒叙 | 各类都可，适合铺垫较多的故事 |

第一句台词同样重要。好的第一句台词往往同时做到两件事：**交代处境，制造冲突**。

| 弱 | 强 |
|---|---|
| 「今天是宗门测灵的日子。」 | 「下品灵根，杂色——又是一个废物。」 |
| 「我叫林晚，今年二十五岁。」 | 「林晚，这婚，我们林家不结了。」 |
| 「公司最近效益不好。」 | 「陈工，你的工牌，交一下。」 |

左边是在「介绍」，右边是在「发生」。观众不需要被介绍，他们需要看到事情正在发生。

## 冲突前置

冲突前置是短剧开篇最重要的原则：**把冲突放到最前面，把背景交代藏进冲突里**。

### 背景不要单独交代

新手写开篇常常这样：先交代世界观，再交代主角的身世，再交代他现在的处境，最后冲突才来。在长剧里这可能只占几分钟；在短剧里，这已经是两集了。

正确的做法是**从冲突开始，背景在冲突里顺带说出来**：

- 不要旁白「照溪宗是一个没落三百年的宗门」，让测灵执事骂一句「宗门三百年没出过一个金丹，就是被你们这种人拖累的」
- 不要闪回主角父亲的故事，让反派踩住铜尺时说「你爹是个抄书的，你也就配抄书」
- 不要介绍主角很穷，让他捡起被踢翻的书箱时，镜头扫过磨破的鞋

### 观众比你想的聪明

开发者写剧本，容易把每件事都解释清楚。但短剧观众看过成百上千部剧，一个眼神、一句台词就能明白人物关系。**能让观众猜到的，就不要说出来**。留一点空白，观众反而更投入。

## 前三集的节拍表

下面是一个按秒排的参考节拍，按单集约 2 分钟计算。这是本书给出的写作参考，不是行业标准，实际时长看剧情。

### 第 1 集

| 时间 | 节拍 | 要做到 |
|---|---|---|
| 0–5 秒 | 开场画面 + 第一句台词 | 冲突已经在发生 |
| 5–30 秒 | 主角受压 | 观众知道主角是谁、处境多差 |
| 30–60 秒 | 压力升级 | 反派做了过分的事，主角在意的东西被威胁 |
| 60–100 秒 | 反差的苗头 | 主角身上出现了「不一样」的东西（能力、秘密、伏笔） |
| 100–120 秒 | 结尾钩子 | 停在一个让人想知道「然后呢」的瞬间 |

### 第 2 集

| 时间 | 节拍 | 要做到 |
|---|---|---|
| 0–10 秒 | 承接上集钩子 | 立刻给出「然后」，不能拖 |
| 10–60 秒 | 新的压力 | 反派再次逼迫，或者主角的秘密面临暴露 |
| 60–100 秒 | 小反击 | 主角第一次用出能力，反派吃瘪 |
| 100–120 秒 | 结尾钩子 | 反击带来新的麻烦 |

### 第 3 集

| 时间 | 节拍 | 要做到 |
|---|---|---|
| 0–10 秒 | 承接上集钩子 | 解决或转化上集留下的麻烦 |
| 10–70 秒 | 关系建立 | 主角和搭档 / 助攻角色建立关系，交换条件 |
| 70–100 秒 | 主线浮现 | 主角发现和自己真正目标有关的线索 |
| 100–120 秒 | 大钩子 | 抛出全剧的核心谜团或核心威胁 |

## 反面示例和改写

下面是一个典型的新人开篇，玄幻题材：

```text
【旁白】照溪宗，曾是天下七大宗门之一，三百年前一场大火之后，
宗门日渐衰落。如今，每年的测灵大典是宗门最重要的日子。

△ 晨光中的山门，弟子们排队走上测灵台。
△ 沈砚站在队伍末尾，手里握着一把铜尺。
沈砚（OS）：爹，我一定会进内门，查清你当年的事。
△ 轮到沈砚。他把手放在测灵石上，石头发出灰色的光。
测灵执事：下品灵根。去藏经阁做杂役吧。
△ 众人议论纷纷。沈砚低下头，默默离开。
```

问题：

1. 前 10 秒是旁白介绍世界观，观众还不知道为什么要关心这个宗门
2. 主角的目标在一句内心独白里直接说完了，没有悬念
3. 测灵结果出来以后，主角「默默离开」，没有冲突，没有压力升级
4. 铜尺出现了，但没人注意它，伏笔没有被「强调」

改写：

```text
△ 测灵石发出浑浊的灰光。台下一阵哄笑。
测灵执事：下品灵根，杂色——又是一个废物。
△ 沈砚收回手，脸色发白。
赵乾（台下）：执事，这种人还留着干什么？浪费宗门的米。
△ 哄笑声更大。
测灵执事：去藏经阁，扫地。
△ 沈砚弯腰去提书箱，赵乾一脚踢翻。书和纸散了一地，一把旧铜尺滚到台中央。
△ 赵乾踩住铜尺。
赵乾：哟，抄书匠的儿子，还带着吃饭的家伙？
沈砚：（抬头）把脚拿开。
```

改写后：

- 第一个画面就是结果，第一句台词就是羞辱
- 世界观（宗门、灵根）在台词里带出，不需要旁白
- 主角的身世（抄书匠的儿子）由反派说出，同时是羞辱
- 铜尺被反派踩住，成了冲突焦点，观众自然记住它
- 主角的第一句台词「把脚拿开」立住了性格：被看不起，但有骨气

至于「查清父亲当年的事」这个目标，不在第 1 集说，留到第 3 集作为大钩子揭开。

## 前三集和投流素材

付费短剧的投流素材大多从前几集剪辑（见《短剧发行、投流与备案》）。编剧可以在写作时就为素材留出「可剪段落」：

- **15–60 秒能独立看懂的冲突段**：不需要前情，一看就知道谁欺负谁、谁要翻盘
- **一句有记忆点的台词**：能当素材标题或封面文字
- **一个反差画面**：灰光的测灵石旁边，一个人一拳打灭了铜灯

写完前三集，试着自己剪一下：能不能从中找出三段各 30 秒、互相独立的素材？找不出来，说明冲突太分散或者太依赖前情。

## 前三集检查清单

```text
第 1 集
[ ] 前 5 秒有冲突在发生，不是介绍
[ ] 第一句台词同时交代处境、制造冲突
[ ] 30 秒内观众知道主角是谁、处境如何
[ ] 主角有一句立住性格的台词或一个动作
[ ] 反差的苗头已经出现（能力 / 秘密 / 伏笔道具）
[ ] 没有大段旁白和闪回
[ ] 结尾停在「然后呢」的瞬间

第 2 集
[ ] 开头 10 秒内承接了上集钩子
[ ] 主角第一次反击，观众出了一口气
[ ] 反击的方式和主角的特殊能力有关
[ ] 结尾的钩子和第 1 集类型不同

第 3 集
[ ] 主角和搭档 / 助攻角色建立了关系
[ ] 全剧主线（主角真正的目标）浮现
[ ] 结尾抛出全剧的核心谜团或威胁

三集整体
[ ] 主要角色出场不超过 5 个
[ ] 能剪出三段各 30 秒、独立看懂的素材
[ ] 没有触碰第 2 章的内容红线
```

## 前三集常见坑

| 坑 | 表现 | 办法 |
|---|---|---|
| 设定先行 | 第 1 集讲了一分钟世界观、门派、等级体系 | 设定只在冲突需要时用一句台词带出，其余放进设定文件 |
| 受压太久 | 三集都在挨欺负，主角一直不还手 | 第 2 集必须有一次小反击 |
| 反击太早太满 | 第 1 集就把身份全揭开、把反派打服 | 只露反差的苗头，揭晓分三四次 |
| 人物扎堆 | 前三集出场十几个有名有姓的角色 | 前三集主要角色不超过 5 个，其余用「众弟子」概括 |
| 主线迟到 | 第 3 集结束还看不出这部剧要讲什么 | 第 3 集结尾必须抛出全剧的核心谜团或目标 |
| 能力不可见 | 主角的特殊能力只在台词里说，没在画面里演 | 让观众亲眼看到能力起作用的瞬间，最好有前后对比 |
| 钩子雷同 | 三集结尾都是「有人来了」 | 三集用三种不同的钩子类型 |

## 本章要点

- 前三集的任务：第 1 集立人设抛冲突，第 2 集第一次小反击，第 3 集确立主线抛大钩子
- 第一个画面 3–5 秒内让人停下，第一句台词交代处境同时制造冲突
- 冲突前置：从冲突开始，把世界观和身世藏进台词里，不用旁白介绍
- 能让观众猜到的就不说出来；主角的核心目标留到第 3 集揭开
- 写作时就为投流素材留出 15–60 秒能独立看懂的冲突段
- 用检查清单逐集过一遍前三集

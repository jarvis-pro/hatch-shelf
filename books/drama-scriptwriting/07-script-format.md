# 剧本格式

剧本是给别人用的文件：审稿编辑读它判断质量，导演或 AI 制作团队照着它拆镜头，配音照着它录台词。格式统一，别人才能快速读懂、准确执行。这一章讲国内短剧剧本的常用格式，每一种元素怎么写，给一份标准样例；再讲 AI 漫剧的剧本要多写哪些信息。

国内短剧剧本没有一份强制的统一格式，各平台、各公司的模板略有差异。本章给的是行业里最常见的写法，投稿前以对方给的模板为准。

## 剧本的组成元素

| 元素 | 作用 | 写法示例 |
|---|---|---|
| 集号与集标题 | 标识这一集 | 第 2 集　报废单 |
| 场次标题 | 交代场景号、时间、内外景、地点 | 2-1　日　内　点心铺后厨 |
| 人物 | 列出本场出场人物 | 人物：老陈、王师傅 |
| 动作描述 | 写画面里看得见的动作和环境 | △ 老陈把一袋面粉倒进盆里，扬起一片白雾。 |
| 台词 | 人物说的话 | 王师傅：读书人，干不了这个。 |
| 情绪 / 动作提示 | 台词前的括号，提示语气或伴随动作 | 王师傅：（拍掉身上的面粉）读书人…… |
| 内心独白（OS） | 人物没说出口的想法，画外音 | 老陈（OS）：每天扔三成？ |
| 旁白（VO） | 画外的讲述者 | 旁白（VO）：三个月后。 |
| 字幕 / 特效 | 画面上的文字、特效提示 | 【字幕】一个月后　【特效】书页上的字泛起红光 |
| 镜头提示 | 必要时提示关键镜头 | 【特写】报废单上的数字 |
| 转场 | 场景切换方式（多数情况不写） | 【闪回】【闪回结束】【黑场】 |
| 钩子 / 卡点标注 | 给制作和投流团队的提示 | 【本集钩子】【付费卡点】 |

### 场次标题

场次标题是剧本最重要的结构标记。格式：

```text
集号-场号　时间　内/外　地点
```

- **集号-场号**：2-1 表示第 2 集第 1 场。场号在每集内重新编号
- **时间**：日、夜，必要时写晨、黄昏。它决定光线，对 AI 生成尤其重要
- **内/外**：内景（室内）、外景（室外）
- **地点**：具体到能拍的位置。不写「宗门」，写「照溪宗　藏经阁一楼」

**场景换了就换场**：地点或时间变了，就开一个新的场次标题。

### 动作描述

动作描述用「△」开头（也有模板不加符号，只空一行），写观众能看见、能听见的东西。

几条规则：

- **只写看得见的**：不写「他很难过」，写「他低下头，手指攥紧了衣角」
- **一个 △ 一件事**：一个动作或一个画面一行，方便拆镜头
- **用现在时，短句**：「门开了。一个人站在门口。」
- **少用形容词**：「一间破旧的、阴暗的、散发着霉味的小屋」改成「小屋。窗纸破了一角，桌上积着灰。」
- **重要的道具和细节第一次出现时写清楚**：铜尺、报废单、发簪，后面要用到的都要在第一次出现时交代

### 台词

台词格式：

```text
角色名：（提示）台词内容
```

短剧台词的写法：

- **短**：一句台词最好不超过 20 字（行业经验）。竖屏字幕一行就那么宽，台词太长观众来不及读
- **口语**：「你干什么？」而不是「你此举意欲何为？」。古风剧也要好懂，半文半白点到为止
- **有潜台词**：好台词不把话说满。「把脚拿开」比「你不要踩我父亲的遗物，这对我很重要」更有力
- **每句台词都有目的**：推进冲突、透露信息、立人设，三者至少占一个。纯寒暄删掉
- **区分人物**：遮住名字，能不能看出是谁说的？反派、主角、嘴替说话方式要不同

提示括号只在必要时写。演员和配音会根据上下文理解情绪，每句都加括号反而干扰。只在台词本身看不出语气、或者语气和字面意思相反时才写：

```text
林照微：（笑）你可真行。
```

这里不写「（笑）」，读的人可能以为是夸奖。

### 内心独白和旁白

- **OS（Off Screen，内心独白）**：人物在画面里，但没开口说，观众听到他的想法
- **VO（Voice Over，旁白）**：画外的声音，可以是叙述者，也可以是不在场人物的声音（比如信件内容）

短剧里 OS 用得比长剧多，因为没有时间用表演慢慢表达心理。但要克制：

- OS 用来表达**观众猜不到又必须知道**的信息，比如主角的计划、他发现的秘密
- 不要用 OS 解释画面已经表达的情绪：画面上他在发抖，就不用 OS「我好害怕」
- 旁白尽量少用，尤其不要用旁白开场介绍世界观（第 5 章）

### 镜头提示

编剧要不要写镜头？原则是：**只写影响剧情理解的关键镜头**，具体的景别、运镜交给分镜（见[《AI 短剧分镜与画面生成》](../ai-drama-storyboard/)）。

需要写镜头提示的情况：

- 观众必须看到的细节：「【特写】封印上的落款：沈明章　校」
- 视角本身是信息：「【主观镜头】沈砚眼中，书页上的一个字泛着红光」
- 时空切换：「【闪回】」「【闪回结束】」「【字幕】三天后」

## 标准样例

下面用第 4 章职场示例的第 2 集做一个标准格式样例（节选前两场）：

```text
第 2 集　报废单

2-1　日　内　点心铺后厨
人物：老陈、王师傅

△ 蒸笼冒着白汽。王师傅揉面，手法飞快。
△ 老陈系着不合身的围裙，抱着一袋面粉，往盆里倒。
△ 面粉扬起一片白雾，扑了王师傅一身。
王师傅：（拍掉身上的面粉）读书人，干不了这个。
老陈：我学。
王师傅：学？（指门口）先把垃圾倒了。

2-2　日　外　点心铺后门
人物：老陈

△ 老陈拎着垃圾桶推开后门，愣住。
△ 墙角的大筐里，堆满整整齐齐的点心，包装都没拆。
【特写】点心盒上的生产日期：今天。
老陈（OS）：没坏，全扔了？
△ 他蹲下，拿起一盒，翻过来看。
王师傅（画外）：每天都这样！做多了卖不完，做少了怕断货。
△ 老陈回头。王师傅叼着烟站在门口。
王师傅：凭经验，懂吗？
△ 王师傅转身进去。老陈看着那筐点心，没动。
```

注意样例里的几个细节：

- 每一行 △ 只写一件事
- 「特写」只用在观众必须看到的信息上（今天的日期 = 点心没坏）
- 第二场的 OS 只有一句，表达的是观众需要知道的判断
- 「画外」表示人物在说话但不在画面里，他随后才入画

## AI 漫剧的剧本要多写什么

真人短剧的剧本交给导演，导演和演员会补上大量没写的东西：演员的长相、场景的样子、灯光、表情的细节。AI 漫剧没有这些人，**剧本里没写的东西，下游就要有人重新去想**。所以 AI 漫剧的剧本通常要多写一些「生产信息」。

### 要多写的信息

| 信息 | 为什么需要 | 写法 |
|---|---|---|
| 角色 ID 与造型版本 | 保证同一角色在不同镜头里外形一致 | 沈砚【A1 杂役服】 |
| 场景 ID | 同一场景复用同一套设定图 | 【S03 藏经阁一楼】 |
| 时间与光线 | 生成画面时决定色调 | 夜，只有一盏铜灯，暖黄色光 |
| 表情和情绪强度 | AI 生成的表情需要明确指定 | （压着怒气，眼神冷） |
| 动作分解 | 复杂动作要拆成几个可生成的画面 | 抬手 → 出拳 → 铜灯熄灭 |
| 道具连续性 | 道具在哪只手、什么状态 | 铜尺别在腰间左侧 |
| 特效说明 | 特效是 AI 漫剧的常用表现手段 | 【特效】字迹泛起暗红色微光 |
| 配音提示 | 给配音或语音合成的音色与语气 | （少年音，压低声音） |
| 时长估计 | 帮助控制单集总时长 | 本场约 25 秒 |

这些信息不需要每一句都写，原则是**第一次出现时写全，之后只在变化时写**。

### 配套的设定文件

除了剧本正文，AI 漫剧项目通常还要有几份设定文件，编剧至少要提供文字版：

- **角色设定表**：每个角色的 ID、年龄感、体型、发型发色、五官特征、标志服装（每个造型版本）、标志道具、常用表情、音色描述
- **场景设定表**：每个场景的 ID、空间描述、关键陈设、光线（日 / 夜各一版）
- **道具设定表**：剧情关键道具的样子（铜尺长多少、什么颜色、上面刻了什么）

示例剧的角色设定见第 9 章。设定文件怎么变成图像模型的提示词，见《AI 短剧分镜与画面生成》。

### AI 制作版样例

把第 10 章示例第 1 集的一场戏写成 AI 制作版：

```text
1-3　夜　内　藏经阁一楼【S03】
人物：沈砚【A1 杂役服】
时间光线：深夜，一盏铜灯，暖黄光只照亮一张书案，书架隐在黑暗里
本场约 30 秒

△ 沈砚跪坐在书案前，用布擦一本旧书的封皮。铜尺别在腰间左侧。
【特写】封皮：《照溪拳谱》。
△ 他翻开书。腰间的铜尺碰到书页边缘。
【特效】书页上「左」字泛起暗红色微光，旁边浮出一个淡淡的「右」字，一闪即逝。
沈砚：（愣住，压低声音）什么东西？
△ 他揉眼睛，再看。红光还在。
△ 他把铜尺拿开，红光消失；贴回去，红光又亮起。
沈砚（OS）：（少年音，轻）爹的尺子……
```

和普通版本相比，多了场景 ID、角色造型、光线、道具位置、特效描述、时长估计。分镜师或者你自己做分镜时，就不用再去猜「这场戏是什么光、铜尺在哪」。

## 交付规范

剧本写完要交出去，几条格式上的规范：

- **文件格式**：多数平台和片方收 Word（.docx）或在线文档。正文用宋体或黑体小四到五号，场次标题加粗
- **一集一个标题，集与集之间分页**，方便审稿时跳转
- **文件命名**：《剧名》_第1-30集_剧本_v2_日期.docx。版本号和日期必写，改稿时最容易混
- **字数统计**：投稿时注明总字数和每集平均字数
- **配套文件**：一句话故事、梗概、人物小传、分集大纲放在剧本前面，或者单独一个文件

## 剧本格式自检

```text
[ ] 每一场都有场次标题：集号-场号、时间、内外、地点
[ ] 地点或时间变了就开新场
[ ] 动作描述只写看得见、听得见的，一个 △ 一件事
[ ] 重要道具第一次出现时写清楚
[ ] 台词短、口语、有目的；遮住名字能分辨是谁在说
[ ] 情绪提示只在必要时写
[ ] OS 只表达观众必须知道又猜不到的信息
[ ] 没有用旁白开场介绍世界观
[ ] 镜头提示只用在影响剧情理解的地方
[ ] 每集结尾标注了钩子，卡点集标注了【付费卡点】
[ ] AI 漫剧：角色造型、场景 ID、光线、特效、配音提示在首次出现时写全
[ ] 文件命名带剧名、集数、版本号、日期
```

## 本章要点

- 场次标题 = 集号-场号、时间、内外、地点，场景变了就换场
- 动作描述只写看得见的，一个 △ 一件事，少用形容词
- 台词短、口语、有目的、有潜台词，一句最好不超过 20 字；情绪提示只在必要时写
- OS 克制使用，旁白尽量不用；镜头提示只写影响剧情理解的关键镜头
- AI 漫剧剧本要多写角色造型、场景 ID、光线、表情、动作分解、道具、特效、配音提示，首次出现写全
- 交付时统一格式、带版本号，并附上一句话故事、梗概、人物小传、分集大纲

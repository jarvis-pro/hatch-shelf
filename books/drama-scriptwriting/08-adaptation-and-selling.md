# 改编、版权与卖剧本

写剧本有两种来源：原创，或者改编已有作品（最常见的是网文）。写完以后有两种用法：自己做成 AI 漫剧，或者卖给平台和片方。这一章讲这几件事里绕不开的版权和交易问题：改编网文要拿什么授权，原创剧本怎么保护，有哪些投稿渠道，报价和分成怎么谈，合同里要看哪些条款。

本章涉及的法律条文以《中华人民共和国著作权法》（2020 年修正）为准。涉及具体合同时请找律师，本章只帮你知道该问什么。更完整的版权、肖像、音乐合规见《自媒体与短剧合规财税》。

## 原创还是改编

| | 原创 | 改编网文 |
|---|---|---|
| 优点 | 版权完全在自己手里，没有授权成本 | 故事经过读者验证，有现成的粉丝和数据 |
| 缺点 | 故事没被验证，要靠自己判断 | 要拿授权，要付费或分成，改编空间受合同约束 |
| 适合 | 想长期做编剧、建立自己作品库的人 | 片方主导的项目、已经谈好 IP 的项目 |

对新人来说，**先写原创**更现实：网文改编授权通常由片方或平台去谈，个人很难拿到热门 IP；原创剧本则能直接投稿，也能自己做。

## 改编网文要拿什么授权

### 为什么必须授权

著作权法第十条规定的著作权人权利里，有两项和短剧改编直接相关：

- **改编权**：改变作品，创作出具有独创性的新作品的权利。把小说写成剧本，就是在行使改编权
- **摄制权**：以摄制视听作品的方法将作品固定在载体上的权利。把剧本拍成或生成为短剧，涉及这项权利

第十三条规定，改编已有作品产生的作品，著作权由改编者享有，但**行使著作权时不得侵犯原作品的著作权**。也就是说，你改编出来的剧本，著作权确实是你的，但没有原作授权，你不能发表、不能卖、不能拍。

没有授权就改编网文拍成短剧，属于侵权。2026 年 6 月广电总局的专项治理就把「侵权盗版」列为 8 类重点问题之一（第 2 章）。

### 授权找谁

网文的版权归属取决于作者和网文平台的签约合同。常见情况：

- **作者和平台签了独家合同**：影视改编权往往由平台代理或持有，要找平台的版权部门谈
- **作者保留了影视改编权**：直接找作者谈
- **作品没有签约平台**：直接找作者，但要确认作者本人确实享有完整权利

不清楚权利在谁手里时，先要求对方出示权属证明（签约合同的相关条款、授权链文件）。

### 网文平台的做法

网文平台已经深度参与短剧。据行业媒体报道：

- 番茄小说一般不一次性卖断网文 IP 的短剧改编权，而是在版权费之外拿后端分成，通常为制作方净利润的 10%，流水高的可能到 15%（剁椒娱投报道，经澎湃等转载）
- 番茄、中文在线、掌阅、七猫等网文平台会以版权入股、现金投资、主控出品的方式参与短剧开发（同上）
- 番茄小说 2026 年宣布短剧专项计划，对优质短剧改编版权给予最高单书 60 万元奖励（投资界 2026-05 报道）

这些是平台和片方之间的商务条件，个人编剧一般作为受托改编方参与。

### 授权合同要点

如果你（或你的团队）直接拿改编授权，合同里至少要看清：

| 条款 | 要问的问题 |
|---|---|
| 授权范围 | 是改编权 + 摄制权，还是只有其中一项？包不包括「微短剧」「动态漫画 / 漫剧」「AI 生成」这些形式？ |
| 独家性 | 独家还是非独家？独家的话，原作者还能不能授权别人做短剧？ |
| 期限 | 授权多少年？期满后已经上线的作品还能不能继续播？ |
| 地域与语种 | 只限中国大陆，还是包括海外、包括翻译配音版本？ |
| 改编空间 | 能不能改人物、改结局、改书名？要不要原作方审核剧本？ |
| 转授权 | 你能不能把权利转给制作方、平台？ |
| 费用 | 一次性买断，还是版权费 + 分成？分成基数是流水、收入还是净利润？怎么核算？ |
| 署名 | 原著作者怎么署名（「改编自某某作品」） |
| 权利担保 | 对方保证自己有权授权，出了侵权纠纷由谁负责 |

形式条款尤其要注意。早年签的影视改编合同可能只写了「电影、电视剧」，没写「网络微短剧」和「漫剧」，拿这样的授权去做短剧可能有争议。

## 原创剧本怎么保护

### 版权是自动产生的

在中国，作品创作完成就自动享有著作权，不需要登记。但发生纠纷时，你需要**证明作品是你的、在什么时间完成的**。

几种留证办法：

- **保留创作过程**：大纲、初稿、修改稿的版本，带时间戳。用 Git 管理剧本是开发者的天然优势：每次提交都有时间记录
- **作品登记**：可以向中国版权保护中心或各省版权局办理作品自愿登记，拿到登记证书。登记不是产生版权的条件，但是很有力的权属证明
- **投稿留痕**：通过平台官方渠道投稿，保留投稿记录、邮件往来

### 什么受保护、什么不受

著作权保护的是**具体表达**，不保护思想、套路和题材：

| 不受保护（可以借鉴） | 受保护（不能抄） |
|---|---|
| 「废柴逆袭」「契约婚姻」这类题材和套路 | 具体的情节安排、人物关系的独特组合 |
| 「身份反差」「打脸」这类结构手法 | 具体的台词、场景描写 |
| 一个创意点子（「主角能看见错字」） | 把点子展开后的完整故事 |

这就是第 1 章说「拉片只学结构，不搬情节」的原因。判断是否抄袭时，法院会看两部作品在具体情节、人物关系、事件顺序上的实质性相似。借鉴骨架、自己填血肉是正常创作；把别人的情节顺序和人物关系整体搬过来换个名字，就是侵权。

### 不要用 AI 洗稿

把别人的剧本或小说喂给大模型，让它「换个说法」「换个背景」，产出的东西和原作在情节和人物上仍然高度相似，这就是洗稿，同样构成侵权。AI 可以用来发散你自己的点子、检查你自己的大纲，不能用来改写别人的作品。

## 卖剧本：渠道

### 平台的编剧征集

主要短剧平台都有面向编剧的投稿或征集渠道。以下是本书写作时能查到的公开信息，规则变化很快，投稿前以平台最新公告为准：

**抖音集团短剧创作者中心（剧本撮合）**

据抖音集团短剧创作者中心 2026 年 8 月公告（DataEye 短剧观察转载）：

- 编剧创建剧本时选择是否已有投资出品方；没有的，经平台审核通过后进入剧本库，平台和投资出品方都可以邀约
- 被平台选中，签《剧本委托创作协议》；被投资出品方选中，签《编剧方分账协议》
- 剧本评级分 S、A+、A 三档；平台保底和投资方保底可以叠加；编剧分成只抵扣平台保底，不抵扣投资方保底
- 进入剧本库但未被平台签约的剧本，建议分成比例不低于 10%（建议值，以双方约定为准）
- 首次投稿提交 30 集；最终完稿长篇不少于 80 集、中短篇不少于 60 集；须为原创或经授权改编，投稿前不得在其他平台推进或公开发布
- 同期还有「千部计划」（每本保底 2 万元，建议 40–50 集，成片上线后超保底分账比例 10%）、系列剧激励、AI 结合真人剧本激励等活动

**红果短剧（剧本新政）**

据蓝鲸新闻 2025 年 8 月报道，红果当月发布的剧本新政按评级分档：

| 评级 | 保底 | 分成 |
|---|---|---|
| A- | 4 万元 | 10% |
| A | 6 万元 | 12% |
| S- | 8 万元 | 15% |
| S | 12 万元 | 20% |
| S+ | 20 万元 | 25% |
| S++ | 20 万元 | 40% |

同时 30 集定金的最低档从 2 万元降到 1 万元。这是 2025 年 8 月的规则，之后可能已经调整。

### 其他渠道

- **短剧制作公司 / 承制方**：很多公司常年收剧本，通过招聘网站、行业社群、公众号发征稿信息
- **编剧工作室**：先加入工作室接活，积累作品和行业关系
- **剧本比赛和创投**：平台、地方政府、行业协会举办的短剧剧本大赛，获奖作品常有孵化机会
- **自己做**：AI 漫剧的制作门槛低，一个人可以把剧本做成样片，用样片去谈合作（制作见《AI 短剧分镜与画面生成》《AI 短剧后期》）

### 投稿材料

不同渠道要求不同，一套完整的投稿材料通常包括：

```text
1. 项目信息：剧名、题材、男女频、总集数、单集时长、目标平台
2. 一句话故事
3. 故事梗概（800–1500 字，含结局）
4. 人物小传（主要人物）
5. 分集大纲（全剧一句话大纲 + 前 N 集详纲）
6. 前 N 集剧本（按平台要求，常见 10 集、30 集）
7. 卖点说明：核心爽点、付费卡点设计、和同类作品的差异
8. 编剧简介：已有作品、相关经历（新人可以写行业背景和样片）
```

## 卖剧本：报价和收入

### 常见的收入结构

| 方式 | 说明 | 适合 |
|---|---|---|
| 买断 | 一次性付稿费，版权归买方，之后的收益和编剧无关 | 新人起步、片方急需剧本 |
| 保底 + 分成 | 先拿一笔保底稿费，剧上线后按约定比例分成，分成先抵扣保底 | 平台征稿的主流方式 |
| 定金 + 尾款 | 按交稿节点分期付款（如交 30 集付定金，完稿付尾款） | 和保底、买断结合使用 |
| 纯分成 | 没有保底，只按收益分成 | 风险高，慎重 |

### 收入水平

公开数据很分散，口径不一：

- 《2025 微短剧行业生态洞察报告》称，行业常见「高薪 + 分成」模式，普通编剧单部剧本收入约 2 万元，头部编剧保底 5–10 万元（新华网 2025-12-05 转载央视网报道）
- 较早的报道引用巨量引擎数据称，上游编剧收入是一部剧 1–5 万元保底加 1%–2% 的收入分成（这个数据较早，可能已过时）
- 平台征稿的保底和分成见上面两个平台的规则

对新人来说，这些数字只是参考。第一部剧本能卖出去、拿到评级反馈，比价格更重要。

### 分成条款要问清楚

分成是最容易出纠纷的地方：

- **分成基数**：按流水（总充值）、平台分账后收入、还是扣除投流成本后的净利润？差别可能是几倍到几十倍。付费短剧的投流成本往往占流水的大头，按「净利润」分成时，编剧可能分不到什么
- **抵扣规则**：分成是否先抵扣保底？抵扣哪一笔保底？
- **结算周期和查账权**：多久结算一次？编剧能不能看到后台数据或结算明细？
- **分成期限**：剧上线后分多久？

## 署名

署名权是著作权里的人身权（第十条），不能转让。即使剧本买断，编剧仍然有权署名，除非你自己同意不署名。

合同里要写清楚：

- 署名方式：「编剧：某某」，还是「原创编剧」「改编编剧」
- 署名位置：片头、片尾、平台详情页
- 多人合作时的排序

著作权法第十九条规定，受委托创作的作品，著作权归属由委托人和受托人通过合同约定；没有约定或没有合同的，著作权属于受托人。平台《剧本委托创作协议》一般会约定著作权（除署名权等人身权外）归平台或委托方，签之前看清楚。

## 编剧合同检查清单

```text
权利
[ ] 著作权（财产权）归谁？是全部转让还是授权使用？
[ ] 授权的话：范围、期限、地域、是否独家？
[ ] 我还能不能用这个剧本的人物和世界观写续作、做其他形式？
[ ] 署名方式和位置写清楚了吗？

钱
[ ] 稿费 / 保底多少？分几期？每期对应什么交付节点？
[ ] 分成比例、分成基数、抵扣规则、结算周期写清楚了吗？
[ ] 有没有查账权或数据查看权？
[ ] 项目取消（不拍了）的话，已交付部分怎么付钱？版权是否退回？

交付
[ ] 交付标准：多少集、每集字数、交付时间？
[ ] 修改次数有没有上限？超出怎么算？
[ ] 「验收通过」由谁判断、以什么为准？

风险
[ ] 我要保证原创，对方要保证什么？
[ ] 违约责任是否对等？
[ ] 有没有保密条款？保密到什么时候？
```

## 防坑

- **试写不付钱**：「先写 10 集看看」，写完说不合适，过几个月出了一部很像的剧。试写可以，但要约定试写稿费，至少保留投稿记录和时间证明
- **收费培训包签约**：「交钱学编剧，结业保证签约」，大多是割韭菜
- **口头约定**：所有关于钱、版权、署名的约定都要落在合同或至少是书面消息里
- **一稿多投**：平台通常要求投稿前未在其他平台推进。一稿多投被发现可能被取消合作，投稿前看清规则
- **AI 生成内容的权属**：如果剧本大量依赖 AI 生成，要了解平台对 AI 创作的要求；作为编剧，保留自己主导创作的过程记录

## 本章要点

- 改编网文必须拿到改编权和摄制权授权，并确认授权形式包含微短剧、漫剧
- 授权合同看范围、独家性、期限、地域、改编空间、转授权、费用、署名、权利担保
- 原创作品自动有版权；用版本记录、作品登记、投稿留痕证明权属
- 套路和题材不受保护，具体情节和表达受保护；不要用 AI 洗稿
- 平台征稿多为「保底 + 分成」，评级决定价格；分成基数、抵扣规则、结算和查账权要问清
- 署名权不能转让；委托创作的版权归属看合同约定

# 完整示例（下）：前三集剧本与自检

这一章先把第 9 章分集大纲里的卡点和伏笔理清楚，然后给出《藏经阁里改错字》前三集的完整剧本，按第 7 章的 AI 制作版格式写：场次标题后标场景 ID，角色第一次出场标造型版本，写明光线、特效和时长估计。每集后面有一段批注，说明这样写的理由。最后用全书的检查清单把这三集过一遍，并汇总常见坑。

角色、场景、道具的 ID 见第 9 章的设定表。剧本里的「△」是动作描述，「OS」是内心独白，「【】」是给制作的提示。

## 开写之前：卡点与伏笔

**付费卡点**：第 10 集。观众刚看到沈砚在小比上打败赵乾（第一段的大爽点），祁玄就认出了铜尺，主角身世这个全剧最大的问题第一次被摆上台面。按第 6 章的原则，它是「满足 + 最大问题」。

**备用卡点**：第 20 集（第二段中点的打脸 + 祁玄第一次正面注意到沈砚）、第 30 集（第三段的危机升级）。片方如果投放测试显示观众在第 10 集付费率低，可以前后调整。

## 第 1 集　下品灵根

**1-1　日　外　测灵台【S01】**

人物：沈砚【A1】、测灵执事、赵乾【E1】、赵乾跟班二人、众弟子

时间光线：上午，晴，阳光直射石台。本场约 50 秒

△ 测灵石发出浑浊的灰光，光里夹着杂色，一闪一闪。

△ 台下一阵哄笑。

测灵执事：下品灵根，杂色——又是一个废物。

△ 沈砚收回手。手心通红，脸色发白。

赵乾：（台下，大声）执事，这种人还留着干什么？浪费宗门的米。

△ 哄笑声更大。

测灵执事：（不抬头，在名册上划了一笔）去藏经阁，扫地。

△ 沈砚弯腰去提台边的书箱。赵乾抢先一步，一脚踢翻。

△ 书和纸散了一地。一把旧铜尺【P1】从书箱里滚出来，滚到石台中央。

【特写】铜尺。暗铜色，边缘磨得发亮。

△ 赵乾走上台，一脚踩住铜尺。

赵乾：哟，抄书匠的儿子，还带着吃饭的家伙？

沈砚：（抬头，声音不大）把脚拿开。

赵乾：（笑，脚下碾了碾）我要是不拿呢？

△ 沈砚伸手按住赵乾的鞋面，一点一点把他的脚推开。

△ 赵乾一愣，随即一把将沈砚推倒在地。

测灵执事：（皱眉）要闹去别处闹。下一个！

△ 沈砚从地上捡起铜尺，用袖子擦掉上面的鞋印，收进怀里。

赵乾：藏经阁好啊，你就在那儿闻一辈子墨臭吧。

**1-2　夜　内　藏经阁一楼【S03】**

人物：沈砚、周伯【F1】

时间光线：入夜，书案上一盏铜灯【P3】，暖黄光，书架隐在黑暗里。本场约 20 秒

△ 周伯拄着木拐，一瘸一拐地领沈砚进门，把一把扫帚塞给他。

周伯：（沙哑）这儿的规矩就一条：只许扫，不许看。

沈砚：看了呢？

周伯：（回头看他一眼）上一个看了的，现在不在宗门了。

△ 周伯的目光扫过沈砚腰间露出的半截铜尺，停了一下。

△ 他没说什么，转身出门。门关上。

**1-3　夜　内　藏经阁一楼【S03】**

人物：沈砚

时间光线：同上，深夜。本场约 50 秒

△ 沈砚跪坐在书案前，用布擦一本旧书的封皮。铜尺别在腰间左侧。

【特写】封皮：《照溪拳谱》【P2】。

△ 他翻开书。腰间的铜尺碰到书页边缘。

【特效】书页上一个「左」字泛起暗红色微光，旁边浮出一个淡淡的「右」字，一闪即逝。

沈砚：（愣住，压低声音）什么东西？

△ 他揉眼睛，再看。红光还在。

△ 他把铜尺拿开，红光消失；贴回去，红光又亮起。

沈砚（OS）：（少年音，轻）爹的尺子……

【特写】书页：第三式　气走左肋，力发右肩。「左」字泛红。

△ 沈砚站起来，照着书上的姿势比画。抬手，出拳。

△ 拳头软绵绵地停在半空，他的手臂一阵发麻，捂着肋下弯下腰。

沈砚（OS）：左肋不通……如果是右边呢？

△ 他深吸一口气，换了个起势。

△ 抬手。出拳。

【特效】拳风带起一道极淡的气流，书页哗啦翻动。

△ 三步外，书案上的铜灯火苗猛地一歪——灭了。

△ 一片漆黑。

△ 沈砚僵在原地，看着自己的拳头。

【本集钩子】

女声：（画外，冷）谁在里面？

### 第 1 集批注

| 设计 | 理由 |
|---|---|
| 第一个画面是测灵石的灰光，第一句是「又是一个废物」 | 冲突开场，前 5 秒观众就知道主角在受辱（第 5 章） |
| 宗门、灵根、主角身世都由台词带出 | 不用旁白介绍世界观 |
| 铜尺被踩住 | 让关键道具在冲突中第一次出现，观众自然记住 |
| 沈砚「一点一点把他的脚推开」 | 立住性格：隐忍但有骨气；没有打斗，不渲染暴力 |
| 周伯看铜尺「停了一下」 | 第 4 集「你爹走的那天，我也在」的伏笔 |
| 先打错的一拳，再打对的一拳 | 观众亲眼看到「改一个字」的效果，能力被证实 |
| 钩子只有一个声音，不露脸 | 悬念型钩子；下一集开场立刻兑现 |

全集三场，两个场景，有台词角色四个（沈砚、执事、赵乾、周伯），最后的女声算第五个。1-1 结尾到 1-3 的打灯段落都可以单独剪成投流素材。

## 第 2 集　他没有偷学

**2-1　夜　内　藏经阁一楼【S03】**

人物：沈砚、林照微【B1】

时间光线：黑暗中，一点青白色的光亮起。本场约 45 秒

【特效】一张符纸在半空燃起青白色的光，照亮楼梯口。

△ 楼梯上站着一个少女，手指间夹着符纸。墨绿长衫，黑发半束，眼尾微挑。

△ 光照到沈砚，和他手里摊开的拳谱。

林照微：杂役，夜里偷看拳谱。

△ 她走下楼梯，一步一步。

林照微：按门规，逐出山门。

沈砚：（合上书）我在擦书。

△ 林照微没理他，径直走到书案前，看那盏灭掉的铜灯。

【特写】灯芯齐齐断开，切口平整。

△ 她伸手翻开沈砚刚合上的拳谱，翻到第三式那页。纸页上有新鲜的指印。

林照微：（笑）擦书，擦到第三式？

△ 沈砚不说话。

林照微：明天一早，我去执法堂。

△ 她把拳谱夹在臂弯里，转身上楼。符光跟着她远去，一楼重新陷入黑暗。

沈砚（OS）：她看到灯芯了……

**2-2　日　外　藏经阁门前【S03 外景】**

人物：沈砚、赵乾、赵乾跟班二人、林照微

时间光线：清晨，薄雾。本场约 45 秒

△ 沈砚在门前扫落叶。

△ 赵乾带着两个跟班晃过来。

赵乾：杂役，外门缺人挑水，跟我走。

△ 沈砚放下扫帚。赵乾的目光落在他腰间的铜尺上，一把抽走。

赵乾：（掂了掂）抄书匠的尺子，正好拿去垫桌脚。

沈砚：还我。

赵乾：来拿啊。

△ 沈砚上前。赵乾抬手就是一拳——照溪拳第三式的起势。

【特写】沈砚的眼睛。他看得出这一拳走的是左肋。

△ 沈砚侧身，用昨夜改过的那一式迎上去。

【特效】两拳相碰，一道气浪荡开，地上的落叶被卷起。

△ 赵乾连退五六步，后背撞上门柱，一屁股坐在地上。铜尺脱手，落在石阶上。

△ 两个跟班张着嘴，没人敢动。

△ 二楼窗口，林照微抱着手臂看着这一幕。

**2-3　日　外　藏经阁门前【S03 外景】**

人物：沈砚、赵乾、跟班二人、林照微

本场约 25 秒

△ 沈砚捡起铜尺，收回腰间。

△ 赵乾爬起来，脸涨得通红，指着沈砚。

赵乾：你用的是照溪拳！

赵乾：杂役偷学宗门武学——我这就去执法堂，逐你出山门！

跟班：（附和）对！逐出山门！

△ 沈砚握紧了拳头。

【本集钩子】

林照微：（画外）他没有偷学。

△ 所有人回头。林照微站在台阶最高处。

### 第 2 集批注

| 设计 | 理由 |
|---|---|
| 开场 3 秒内揭晓「谁在里面」 | 集首立刻兑现上集钩子（第 6 章） |
| 林照微靠灯芯切口和指印判断 | 用动作立住「缜密」的人设，不用台词说「她很聪明」 |
| 「（笑）擦书，擦到第三式？」 | 情绪提示用在语气和字面意思相反的地方（第 7 章） |
| 赵乾用的是错版第三式，沈砚用改正版 | 第一次反击直接来自主角的特殊能力 |
| 二楼窗口的林照微 | 让她「看见」，为本集钩子的反转做铺垫 |
| 钩子：她刚说要告发，现在却替他作保 | 反转型钩子，和第 1 集的悬念型不同 |

本集情绪从「压」（被抓）到「扬」（震飞赵乾）再到「悬」。2-2 的对拳段落是本集的核心素材段。

## 第 3 集　沈明章　校

**3-1　日　外　藏经阁门前【S03 外景】**

人物：沈砚、林照微、赵乾、跟班二人

本场约 30 秒

△ 林照微走下台阶，站到沈砚身边。

林照微：拳是我教的。我缺个打下手的，借他用几天。

赵乾：（一愣）林师姐，你……

林照微：有意见，去执法堂告我。

△ 赵乾咬牙，看看沈砚，又看看林照微，挥手带着跟班走。走出几步，他回头。

赵乾：林师姐，护着一个杂役，你师父可不会回来给你撑腰了。

△ 林照微的脸色变了一瞬。很快恢复。

**3-2　日　内　藏经阁一楼【S03】**

人物：沈砚、林照微

时间光线：白天，阳光从高窗斜照进来，灰尘在光里浮动。本场约 50 秒

△ 林照微把拳谱扔在书案上。

林照微：那一拳不是照溪拳。

林照微：比照溪拳更对。你怎么做到的？

△ 沈砚不说话。

△ 林照微从袖中取出一本薄薄的符书，一张空白符纸，拍在桌上。

林照微：这道符，我画了三年，一次都没成过。你看看。

△ 沈砚犹豫一下，把铜尺轻轻放在符书上。

【特效】符书上一个「止」字泛起暗红色微光，旁边浮出一个「上」字。

【特写】符诀：水止于坎。「止」字泛红。

沈砚：这个字，错了。应该是「上」。

林照微：（冷笑）照溪宗传了三百年的符书，你说错了？

△ 但她还是提起笔，蘸墨，照着改过的符诀一笔画下去。

【特效】最后一笔落下，符纸上的纹路亮起清光，一缕水汽从符纸上升起。

△ 林照微盯着符纸，半天没说话。

林照微：（轻声）成了。

**3-3　日　内　藏经阁一楼【S03】**

人物：沈砚、林照微

本场约 25 秒

△ 林照微收起符纸，抬头看沈砚。眼神变了。

林照微：做个交易。我保你在藏经阁待着，没人敢动你。

沈砚：条件？

林照微：帮我找一本书。我师父失踪前，最后看的那本。

沈砚：你师父？

林照微：守阁长老，闻素。三年前闭关，再没出来。

沈砚：书在哪？

△ 林照微抬起手，指了指头顶。

林照微：三楼。禁区。

**3-4　夜　内　藏经阁三楼禁区门前【S04】**

人物：沈砚、林照微

时间光线：深夜，只有林照微手里的符光，青白色，照亮窄窄的楼梯和一扇木门。本场约 30 秒

△ 狭窄的楼梯尽头，一扇木门上贴满了一层叠一层的封条。

△ 林照微举起符光。

林照微：这封印我试过一百次，打不开。

△ 沈砚走上前，取下铜尺，轻轻贴上最外面一张封条。

【特效】封条上的字一个接一个泛起暗红色的光，像被点燃的线。

△ 沈砚的目光顺着红光往下移，停在封条最末尾。

【特写】封条落款，墨迹已经褪色：沈明章　校。

△ 沈砚的手僵住了。

林照微：怎么了？

【本集钩子】

沈砚：（声音发紧）这是我爹的字。

### 第 3 集批注

| 设计 | 理由 |
|---|---|
| 赵乾临走那句「你师父可不会回来了」 | 由反派之口带出闻素失踪的暗线，不用旁白 |
| 林照微的符成了 | 主角能力第二次被验证，且这次是在「符」上，说明能力不只适用于拳谱 |
| 交易而不是友情 | 两个人的关系从互相利用开始，给感情线留出成长空间（第 3 章） |
| 「水止于坎」改成「水上于坎」 | 一字之差，画面上一个泛红一个浮现，观众一眼能看懂 |
| 封条落款「沈明章　校」 | 第 3 集确立全剧主线：父亲（第 5 章「主线浮现」） |
| 沈砚的目标留到此刻才揭开 | 前两集没说他想查父亲，这里由一个画面自然引出 |

前三集合起来完成了「受压 → 小反击 → 发现更大的问题」的闭环。用到的场景只有三个（S01、S03 内外、S04），主要角色五个。

## 前三集自检

用第 5 章的前三集清单过一遍：

| 检查项 | 结果 |
|---|---|
| 第 1 集前 5 秒有冲突在发生 | 是：测灵结果 + 「又是一个废物」 |
| 第一句台词交代处境、制造冲突 | 是 |
| 主角有一句立住性格的台词 | 是：「把脚拿开」 |
| 反差的苗头出现 | 是：错字泛红，一拳打灭铜灯 |
| 没有大段旁白和闪回 | 是：全三集没有旁白 |
| 第 2 集开头 10 秒承接上集钩子 | 是：符光亮起，林照微现身 |
| 第 2 集主角第一次反击，且来自特殊能力 | 是：用改正的第三式 |
| 钩子类型不重复 | 是：悬念 → 反转 → 揭晓 |
| 第 3 集主线浮现、建立搭档关系 | 是：交易；封条落款 |
| 主要角色不超过 5 个 | 是：沈砚、林照微、赵乾、周伯，加一个测灵执事 |
| 能剪出三段独立素材 | 是：测灵受辱、对拳震飞、改字成符 |
| 没有触碰内容红线 | 是：冲突靠能力解决，没有炫富、血腥、擦边 |

## 常见坑总表

| 阶段 | 坑 | 后果 | 办法 |
|---|---|---|---|
| 选题 | 写自己喜欢但没人看的题材 | 投稿没反馈 | 先拉片，用题材分析表 |
| 选题 | 跟风饱和题材，没有新外壳 | 评级低 | 骨架老，外壳新 |
| 人物 | 主角没有欲望，被剧情推着走 | 观众不关心他 | 主角三问 |
| 人物 | 反派降智 | 胜利不值钱 | 反派的失败来自性格弱点 |
| 结构 | 不写大纲直接写剧本 | 中段塌、结局对不上 | 先写设计文件 |
| 开篇 | 用旁白介绍世界观 | 前 10 秒流失 | 冲突前置 |
| 钩子 | 同一种钩子反复用 | 观众麻木 | 轮换类型 |
| 卡点 | 卡点停在低谷 | 付费率低 | 满足 + 最大问题 |
| 格式 | 写心理活动、写长台词 | 没法拍，字幕读不完 | 只写看得见的，台词不超过 20 字 |
| AI 制作 | 角色和场景太多 | 一致性崩，成本暴涨 | 控制角色数，场景复用 |
| 导向 | 爽点靠炫富、暴力 | 过不了审或被下架 | 把爽点那场戏单独拿出来看 |
| 版权 | 未授权改编、AI 洗稿 | 侵权 | 原创或先拿授权 |
| 交易 | 口头约定、分成基数不清 | 拿不到钱 | 合同检查清单 |

## 本章要点

- AI 制作版剧本：场景 ID、角色造型、光线、特效、时长估计都写进去，下游不用再猜
- 第 1 集冲突开场、道具在冲突中出现、能力在结尾被验证；第 2 集集首兑现钩子、第一次反击；第 3 集建立搭档关系、揭开主线
- 开写前先定主卡点、备用卡点和伏笔表，确保每条线都有回收
- 每集写完都可以用批注表问自己「为什么这样写」
- 用全书检查清单和常见坑总表收尾，再交给制作或投稿

# 带货内容怎么做

选好了货、算清了账，接下来是让人愿意买。带货内容和普通内容的差别在于：普通内容的目标是让人看完、点赞、关注；带货内容的目标是让**对的人**点进商品、下单、而且**不退货**。最后这一条经常被忽略。一条靠夸大和刺激冲动换来的高转化视频，退货率可能高到让你白干。

本章给三套模板：短视频挂车、种草图文笔记、商品卡（橱窗里的商品标题和卖点）。通用的选题方法、钩子、脚本格式，分别见《选题与爆款结构》和《短视频脚本与分镜》，这里只讲带货特有的部分。

## 带货内容的三条原则

1. **先有用，再卖货**。观众先觉得这条内容对他有用或有意思，然后才愿意看你推荐什么。整条都在吆喝的视频，平台会判为低质营销内容，流量也给得少
2. **讲场景，不讲参数**。「这个支架承重 9 公斤」没人记得住；「我的 27 寸显示器加笔记本一起架上去，桌面空出一整块放键盘和咖啡」大家一下就懂了
3. **讲缺点，劝退不适合的人**。每劝退一个不适合的人，就少一个退货。主动讲缺点也是观众判断你是否可信的最强信号

## 模板一：短视频挂车

### 结构

带货短视频的常见结构可以拆成五段，总长 30–90 秒：

| 段落 | 时长 | 要做的事 | 示例（显示器支架） |
|---|---|---|---|
| 钩子 | 0–3 秒 | 抛出观众有共鸣的问题或强对比画面 | 「颈椎疼了三年，最后是一个 129 块的东西救了我」+ 低头看屏幕的画面 |
| 痛点展开 | 3–15 秒 | 让观众代入自己的场景 | 「笔记本放桌上，屏幕太低，一天下来脖子僵；桌面又小，键盘没地方放」 |
| 解决方案 | 15–40 秒 | 展示商品怎么解决，**用画面而不是嘴** | 安装后前后对比；单手拉高、旋转的演示；桌面空间对比 |
| 真实细节和缺点 | 40–55 秒 | 说一两个只有用过的人才知道的细节和缺点 | 「装的时候自带扳手太短，建议自己备一个；32 寸以上的屏不建议」 |
| 引导 | 最后 5 秒 | 平静地说明在哪买、适合谁 | 「链接放在左下角了，桌面小、用外接屏的可以看看」 |

### 写成脚本

```text
【商品】xx 显示器支架  129 元  佣金 20%
【目标观众】用笔记本外接屏、桌面不大的上班族和程序员
【时长】约 50 秒

镜头 1（0–3 秒）  近景：我低头揉脖子，屏幕放在桌面上
  口播：颈椎疼了三年，最后是一个一百多块的东西救了我。

镜头 2（3–12 秒）  俯拍桌面：笔记本、显示器、键盘挤在一起
  口播：屏幕太低，一天低头八小时；桌子又小，键盘只能斜着放。

镜头 3（12–30 秒）  延时：装支架、把屏幕架上去；切到装好后的桌面
  口播：装上之后，屏幕到了眼睛的高度，桌面空出来一整块。
  字幕：安装约 15 分钟

镜头 4（30–40 秒）  手部特写：单手把屏幕拉高、转成竖屏
  口播：写代码的时候我会把它转成竖屏，一屏能多看几十行。

镜头 5（40–48 秒）  中景，对着镜头
  口播：说两个缺点：自带的扳手太短，最好自己备一个；
        屏幕超过 32 寸的就别买了，带不动。

镜头 6（48–52 秒）  桌面全景
  口播：链接在左下角，桌面小、用外接屏的可以看看。
```

注意最后的引导语是平静的「可以看看」，而不是「赶紧抢」「最后一波」。后者既容易被判为营销过度，在没有真实限时活动时也涉嫌虚假宣传。

### 几种带货视频类型

| 类型 | 适合的商品 | 要点 |
|---|---|---|
| 开箱测评 | 数码、家电、新奇小物 | 真实拆开，第一反应别剪掉 |
| 前后对比 | 收纳、清洁、桌面改造 | 同机位、同光线拍前后，对比才可信 |
| 使用场景 vlog | 日用品、食品、通勤装备 | 商品出现在真实生活里，不刻意 |
| 横向对比 | 同类多款 | 讲清各自适合谁，不要只挑一个往死里夸 |
| 清单合集 | 「程序员桌面 5 件好物」 | 每件都要有理由；只能挂一个链接时，其余放橱窗 |
| 避坑 / 不推荐 | 观众常买错的品类 | 信任度最高的内容之一，顺带推荐你认可的那款 |

拍摄和剪辑见《拍摄与剪辑实务》。

## 模板二：种草图文笔记

小红书和抖音图文都适用。图文的读者会仔细看、会收藏、会对比，所以**信息密度要高，结构要清楚**。

### 结构

```text
【封面】一张强对比图（前后对比 / 实拍效果），配 6–12 个字的大字标题
【标题】场景 + 结果 + 具体数字，不用绝对化词
        例：桌面小的打工人，这个支架让我多出半张桌子
【正文】
  第 1 段：我的情况（谁、什么场景、什么问题）
  第 2 段：为什么选这款（对比过哪几款、看重什么）
  第 3 段：用了多久、具体好在哪（2–3 点，每点一句话 + 一张图）
  第 4 段：缺点和不适合的人（必写）
  第 5 段：总结一句 + 链接位置
【图片】6–9 张：封面、全景、细节、安装、使用中、缺点特写、参数/尺寸图
【话题】3–5 个和内容相关的话题标签
```

### 示例正文

```text
桌面 100×60 的出租屋，外接一台 24 寸屏，笔记本只能斜着放，脖子天天酸。

挑支架时对比了三款：夹桌式、底座式、气弹簧单臂。我的桌子边缘有个挡板，
夹桌式装不上，最后选了这款底座气弹簧的，129 元。

用了两周，说三个变化：
1. 屏幕抬到眼睛高度，下午脖子不那么僵了（图 3）
2. 屏幕底下空出来，键盘和笔记本能平放（图 4）
3. 可以转竖屏，看文档和代码特别爽（图 5）

不好的地方也说一下：
- 自带扳手很短，拧最后两圈很费劲，建议自己备一把
- 转动的时候有一点点吱声，不影响用
- 32 寸以上、或者曲面屏就别考虑了

适合：桌面小、外接 27 寸以内的屏。链接放在笔记里了。
```

### 图文的合规提醒

- **合作内容要标注**。收了商家的钱、样品或佣金，按平台规则和广告法相关要求标注广告或合作。小红书对未报备的商业合作打击很严，商单要走蒲公英（见《广告商单与品牌合作》）
- **不写功效词**。尤其是食品、化妆品：「祛痘」「美白」「减肥」「治疗」这类词，非特殊用途或无对应资质的商品不能用
- **不用绝对化用语**：最好、第一、顶级、全网最低、100% 有效
- **对比要真实**：「比某品牌好」需要有依据，贬低其他品牌有风险

这些规则的细节和最新案例见《自媒体与短剧合规财税》。

## 模板三：商品卡

商品卡是商品在橱窗、商城、搜索里的展示形态。作为达人你改不了商家的商品标题和主图，但能决定在橱窗里放哪些、按什么顺序放；作为商家（第 7 章）则要自己优化。

### 商家视角：商品标题

```text
结构：品牌 + 核心品名 + 1–2 个关键属性 + 适用场景/人群
例：  xx 显示器支架 气弹簧单臂 承重 2–9kg 适用 17–32 英寸 办公电脑桌
```

- 用户会怎么搜就怎么写：「显示器支架」「电脑支架」都可能是搜索词，主名用搜索量大的那个
- 不堆砌无关热词，不写「爆款」「网红」「同款」，不蹭其他品牌名
- 属性写数字：尺寸、容量、承重、适用范围

### 主图

| 图位 | 内容 |
|---|---|
| 第 1 张 | 白底或简洁场景下的商品全貌，清楚看出是什么 |
| 第 2 张 | 使用中的场景图 |
| 第 3 张 | 核心卖点 1（配一句短文案） |
| 第 4 张 | 核心卖点 2 |
| 第 5 张 | 尺寸、规格、适用范围，**减少因为不合适而退货** |
| 详情页 | 安装说明、常见问题、售后政策 |

### 达人视角：橱窗管理

- **橱窗里的商品要和你的内容一致**。别人点进你的橱窗，看到的应该是「这个人推荐的东西」，而不是一堆杂货
- 把正在主推的放前面，下架卖不动和退货率高的
- 定期检查：商品下架、涨价、换了商家、库存不足，都会导致你视频里的链接失效或体验变差

## 发布后看什么

每条带货内容发布后 3 天、7 天各看一次，记进表格：

| 指标 | 看什么 |
|---|---|
| 播放 / 阅读量 | 内容本身有没有流量 |
| 商品曝光 → 点击 | 观众对商品感不感兴趣 |
| 点击 → 成交 | 商品页、价格、评价能不能接住 |
| 成交 → 退货 | 内容是否夸大、商品是否有问题 |
| 评论区高频问题 | 下一条内容要回答的问题；也可能是商品的隐患 |

**评论区是最好的选题来源**。「这个能放 34 寸吗」「和 xx 比哪个好」「装在玻璃桌上行不行」，每一个都可以成为下一条内容。

## 常见坑

| 坑 | 后果 |
|---|---|
| 整条都在吆喝 | 被判营销内容、限流；观众划走 |
| 照搬商家给的卖点文案 | 和几百个达人说的一模一样，没有说服力 |
| 夸大效果、制造焦虑 | 高退货、高投诉，严重的涉及虚假宣传 |
| 虚构限时、虚构原价 | 违反价格和广告相关规定 |
| 只拍好的一面 | 观众收到实物有落差，退货 + 差评 |
| 不标注合作 | 平台处罚，违反广告相关规定 |
| 一条视频挂了就不管 | 商品下架或换货你不知道，评论区全是「链接没了」 |

## 本章要点

- 带货内容的目标是让对的人下单且不退货：先有用再卖货、讲场景不讲参数、主动讲缺点
- 短视频挂车五段结构：钩子、痛点、解决方案（用画面）、真实细节和缺点、平静的引导
- 种草图文：强对比封面、场景加结果的标题、五段式正文，缺点必写，合作必标
- 商家写商品标题用「品牌 + 品名 + 属性 + 场景」，主图里放尺寸规格图来减少退货；达人管好橱窗，定期清理
- 发布后 3 天、7 天看曝光、点击、成交、退货四个数，评论区高频问题就是下一条选题

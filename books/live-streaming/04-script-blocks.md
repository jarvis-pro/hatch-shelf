# 话术模块：开场、留人、互动、讲解、转化、下播

直播话术不是背稿。观众随时进、随时走，你说的每一段都可能是某个人听到的第一句话。所以话术要拆成**可以随时插入的模块**：有人进来就能用开场模块，在线人数掉了就用留人模块，公屏冷了就用互动模块。本章给每个模块写好可以直接改的模板，第 5 章再把它们拼成两份完整的 60 分钟脚本。

先记住两条底线，后面所有模板都按它们写：

1. **只说你能证明的话**。功能、效果、价格、销量、评价，说出口之前问自己：有截图、有报告、有链接吗？
2. **不拿利益换互动**。「扣 1 抽奖」「点赞到多少就上福利」「关注才能领」这类话术，平台按诱导互动处理；《直播电商监督管理办法》也要求信息展示「不得设置强制关注、打赏等不合理限制」

## 模块一：开场（开播前 3 分钟 + 每次有一波新人）

开场要在 15 秒内说清三件事：**你是谁、今天播什么、待下去能得到什么**。

```text
【知识直播开场】
大家晚上好，我是老周，一个写了 8 年后端的程序员。
今天这场只干一件事：拿一个真实的开源老项目，现场用 AI 给它补 20 个单元测试。
我会一个一个跑给你看，哪些能直接用，哪些看着对其实什么都没测。
最后 15 分钟答疑，有问题现在就可以打在公屏上，我记下来。
```

```text
【带货直播开场】
大家晚上好，我是老周，写代码的。今天这场是桌搭专场，
一共 6 样东西，都是我自己桌上用了至少一个月的，
每一样我都会讲清楚适合谁、不适合谁，不适合你的千万别买。
价格和优惠以购物车里显示的为准，我讲到哪个会把哪个弹出来。
```

```text
【重开场：每隔 10–15 分钟，或者在线人数明显上涨时】
刚进来的朋友，我是老周，今天在现场用 AI 补单测，
现在已经补到第 8 个，刚才发现了一个 AI 很爱犯的错，
接下来这个我会讲怎么一眼看出来。
```

重开场的关键是**「现在进行到哪」+「接下来马上有什么」**，让刚进来的人不觉得自己错过了全部。

## 模块二：留人（在线人数下降时）

留人靠的是**预告接下来的价值**，而不是喊「别走」。

```text
【预告下一段】
接下来这个是今天最难的一个函数，它依赖时间和数据库，
大部分人让 AI 写测试都会在这里翻车，我们看看怎么处理。

【给一个即时可用的小东西】
先给大家一个马上能用的：让 AI 写测试的时候，提示词里加一句
「只测公开行为，不要 mock 被测函数本身」，就能少一半假测试。
后面我会演示为什么。

【告诉观众什么时候答疑】
有问题的先打在公屏上，我在讲完这一段（大概 5 分钟后）统一回答。
```

带货直播的留人：

```text
【预告下一个品】
讲完这个台灯，下一个是很多人问过的显示器支架，
我会现场把我自己的 27 寸屏装上去，看稳不稳、晃不晃。

【讲清规则，不制造假紧张】
这款的优惠价格是商家这场给的，具体价格和数量购物车里写着，
我不会说「最后几单」，库存是多少就是多少。
```

**不要用的留人话术**：「马上就要涨价了」（没涨价）、「只剩最后 3 单」（实际库存充足）、「下一秒就要下架」（不会下架）。这些属于虚构紧迫感，可能构成虚假或引人误解的宣传。

## 模块三：互动（公屏冷场时）

互动的目的是**让观众说出自己的情况**，你再根据情况讲。问开放但好回答的问题：

```text
【选择题】
你们平时写测试用的是哪个框架？Jest 打 J，pytest 打 P，Go 自带的打 G，
我看看今天哪个多，后面就多讲哪个。

【经验题】
你用 AI 写代码，遇到最离谱的一次错误是什么？打在公屏上，我挑两个现场分析。

【确认题】
刚才这个提示词我讲明白了吗？没明白的打「没懂」，我换个例子再讲一遍。
```

```text
【点名回应：有人提问时】
「小林同学问：AI 写的测试怎么判断有没有用？」
好问题，我直接演示：把被测函数故意改坏，看测试会不会挂。
不挂，就说明这个测试什么都没测。
```

点名时**只读昵称，不读对方可能暴露隐私的内容**（手机号、公司名、真名）。有人在公屏发了这类信息，提醒对方删除，必要时用场控工具隐藏。

互动的边界：

| 可以 | 不要 |
|---|---|
| 问观众的情况、经验、选择 | 「扣 1 领资料」「点赞到 1 万抽奖」 |
| 让观众投票决定下一段讲什么 | 「不关注不发资料」「关注后私信才能领」 |
| 用平台官方福袋、抽奖工具，并按工具规则写清参与条件 | 私下承诺奖励、规则不公开 |
| 回答公屏的问题 | 要求观众刷礼物换回答 |

## 模块四：讲解

### 知识讲解：问题 → 演示 → 原理 → 带走

```text
【知识讲解模板，每段 8–12 分钟】
1. 问题（1 分钟）：今天这段解决什么问题，为什么常见
   「很多人让 AI 写测试，测试全绿，但改坏代码它也是绿的。」
2. 演示（4–6 分钟）：现场操作，边做边说你在干什么、为什么
   「我先让它写，原样不改……跑一下，全过。现在我把这一行改坏……还是全过。」
3. 原理（2–3 分钟）：解释为什么会这样
   「因为它 mock 了被测函数自己依赖的计算，测的是 mock 不是代码。」
4. 带走（1 分钟）：一句话结论 + 一个可以抄的东西
   「判断方法：改坏代码，测试必须挂。提示词这样写：……」
```

讲解时的几个习惯：

- **每一步都说出来**。观众看不到你的思路，只能听到你的话。沉默超过 5 秒，就说一句你在看什么
- **出错了就当素材**。演示翻车很正常，说「这里出错了，正好看看为什么」，往往比顺利演示更有价值
- **不会就说不会**。「这个我不确定，下播查了在群里回你」，比现场编一个答案好得多

### 带货讲解：场景 → 问题 → 参数 → 实测 → 适合谁 → 价格与售后

```text
【带货讲解模板，每个品 5–8 分钟】
1. 场景（30 秒）：什么人在什么情况下需要它
   「每天对着屏幕 10 个小时，晚上关了顶灯写代码的人。」
2. 问题（30 秒）：不用它会怎样
   「只开屏幕，眼睛对着一块亮屏，周围一片黑，对比太强。」
3. 参数（1–2 分钟）：照着详情页和资质念准确的数字，说清来源
   「色温 2700 到 6500K 可调，显色指数商家标的是 95，检测报告在这里，我给大家看一下。」
4. 实测（2–3 分钟）：现场用给观众看
   「我把它夹在屏幕上，关掉顶灯，大家看屏幕上有没有反光。」
5. 适合谁 / 不适合谁（1 分钟）
   「曲面屏用不了这款的夹子，曲面屏的朋友别买。」
6. 价格与售后（1 分钟）：只说购物车里显示的价格和商家承诺的售后
   「价格以购物车为准，现在是 ××元。商家支持 7 天无理由，具体规则在商品页。」
```

**参数和功效只能说有依据的**。普通商品不能说有医疗功效（「护眼台灯能治近视」不能说；「减少屏幕反光」这类可以现场演示的效果可以说）。哪些词能说、哪些不能，下文有替换表，完整规则见[《自媒体与短剧合规财税》](../media-compliance/)。

## 模块五：转化

### 知识直播的转化：讲清产品，不施压

```text
【介绍付费社群，放在答疑前或答疑后，3 分钟】
最后说一下我的付费社群，不需要的朋友直接跳过就行。
群里有什么：每周一篇实战笔记，今天这种演示的完整代码和提示词，
还有我每周一次的文字答疑。
适合谁：已经在用 AI 编程工具、想用得更深的人。
不适合谁：完全没写过代码的朋友，这个群对你帮助不大。
价格是 ××元一年，入口在直播间的商品链接 / 主页，
进群 7 天内觉得不合适可以退（按你实际的退款规则说）。
```

知识产品怎么设计、定价、交付，见[《知识付费与私域变现》](../knowledge-products/)。

### 带货直播的转化：说清价格和规则

```text
【上链接】
现在把台灯的链接弹出来，就是购物车 3 号。
价格以页面显示为准，现在是 ××元；
这个价格是商家这场给的直播间价，比较的是商品页上标注的日常价 ××元。
有任何疑问，先问清楚再拍，不着急。
```

价格话术要特别小心：

- 《直播电商监督管理办法》第三十二条要求以显著方式展示品名、价格、计价单位，**使用价格比较、折价、减价的，要标明被比较价格或计算基准**
- 不要说「全网最低」「历史最低」，除非你真的能证明并且商家给了书面保证；即使能证明，也建议换成「这场直播间价是 ××元」
- 口播价格、购物车价格、商品页价格三者必须一致

## 模块六：下播

```text
【知识直播下播】
今天就到这里。回顾一下今天的三个点：
第一，改坏代码，测试必须挂；第二，提示词里写清「只测公开行为」；
第三，依赖时间的函数，把时间作为参数传进去。
没回答到的问题，我下播后在群里统一回。
下一场是周四晚上 9 点，讲 AI 帮你读一个陌生代码库，主页已经可以预约。
谢谢大家，晚安。
```

```text
【带货直播下播】
今天 6 样东西都讲完了。再提醒一下：
所有商品的发货和售后由商家负责，规则在商品页，
收到货有问题，先联系商家客服，处理不了可以在粉丝群找我，我帮你对接。
下一场带货是两周后，主题会提前在主页预告。谢谢大家。
```

下播要**准时**。说好 60 分钟就 60 分钟，观众才会形成「这个时间能看到他」的习惯；拖到 90 分钟，你第二天上班也受影响。

## 应急话术

| 场景 | 话术 |
|---|---|
| 冷场，没人说话 | 「我先讲一个昨天群里有人问的问题……」（用准备好的垫场问题） |
| 被质疑「你这个是广告吧」 | 「这几样是商家给了佣金的，我直接说。但每样我都用了一个月以上，不好的地方我也会讲。」 |
| 有人带节奏、骂人 | 不辩论，用场控工具禁言或踢出，说一句「我们继续讲」 |
| 被问到不会的 | 「这个我不确定，不乱说，下播查清楚在群里回你。」 |
| 口误说错了参数或价格 | 「纠正一下，刚才说的 ×× 不对，正确的是 ××，以页面为准。」（《直播电商监督管理办法》第三十一条要求发现口误、表述不当时现场纠正） |
| 演示翻车 | 「翻车了，正好，我们看看为什么。」 |
| 设备故障 | 切到备用场景或手机，说「设备出了点问题，马上回来」，2 分钟内恢复不了就说明原因下播 |

## 词语替换表

| 不要说 | 原因 | 换成 |
|---|---|---|
| 最好、第一、顶级、全网最低 | 《广告法》第九条禁止使用「国家级」「最高级」「最佳」等用语 | 「我用过的几款里我最常用这个」「这场直播间价是 ××元」 |
| 绝对不会坏、100% 有效 | 无法证明，属于绝对化承诺 | 「商家提供 × 年质保，规则在商品页」 |
| 护眼、治颈椎病、改善睡眠 | 普通商品宣称医疗功效 | 「减少屏幕反光」「支架能把屏幕抬到视线高度」（可现场演示的效果） |
| 只剩最后 × 单（实际库存充足） | 虚构紧迫感 | 「库存以页面为准」 |
| 原价 999 今天 99（无真实原价） | 虚构原价，违反明码标价规定 | 标明真实的被比较价格和依据 |
| 不买就亏了、错过等一年 | 制造焦虑，且多数时候不真实 | 「需要的再买，不需要的别买」 |
| 扣 1 抽奖、点赞到 1 万上福利 | 诱导互动 | 「你们用的什么键盘，打在公屏上」 |

## 本章要点

- 话术拆成开场、留人、互动、讲解、转化、下播六个模块，按直播间实时情况插入
- 开场 15 秒内说清你是谁、播什么、留下来能得到什么；每 10–15 分钟重开场一次
- 留人靠预告下一段的价值，不靠虚构紧迫感；互动是让观众说自己的情况，不拿利益换互动
- 知识讲解按「问题 → 演示 → 原理 → 带走」，带货讲解按「场景 → 问题 → 参数 → 实测 → 适合谁 → 价格与售后」
- 价格以购物车为准，使用比较价要标明被比较价格；口误当场纠正
- 极限词、医疗功效、虚构原价和库存都不能说，用替换表里的说法

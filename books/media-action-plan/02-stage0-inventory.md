# 阶段 0：盘点、选线与定位

阶段 0 不发任何内容，也不打开任何 AI 视频工具。它回答四个问题：我每周真正有多少时间、能花多少钱；做这件事会不会碰到雇主和法律的边界；走哪条线；这条线上我具体做什么。

很多人跳过这一步，直接注册账号开始发。结果通常是发到第 8 条发现自己其实不想露脸，或者发到第 20 条才意识到公司制度不允许员工以公司身份对外发言。阶段 0 花两三周，省掉的是后面几个月的返工。

## 进入条件与周期

- **进入条件**：无。想清楚「我想试试」就可以开始
- **周期**：2–3 周，每周 10–15 小时里大约一半就够
- **产出**：`numbers.md`、`boundaries.md`、`positioning.md`、`stages.md` 四个文件

## 第 1 周：算出你的数字

### 每周真正可用的时间

把下一周每个晚上和周末拆成时段，标出哪些确定能用：

```text
| 时段 | 能用吗 | 适合做什么 |
|---|---|---|
| 周一 20:30–22:30 | 不一定（常加班） | 只做轻活：回评论、整理数据 |
| 周二 20:30–22:30 | 能 | 写稿 / 剪辑 |
| 周三 | 不能（固定陪家人） | — |
| 周四 20:30–22:30 | 能 | 剪辑 / 生成画面 |
| 周六 09:00–13:00 | 能 | 拍摄 / 整块的生产 |
| 周日 20:00–20:40 | 能 | 周复盘和下周计划 |
```

数一数「能」的时段。少于 3 个整块时段（每块 2 小时以上），本书的周期要按比例拉长；少于 2 个，建议先只做账号线里最轻的形态（图文或口播），或者推迟开始。

两条线对时段的要求不一样：

| 工作 | 需要什么样的时段 |
|---|---|
| 拍摄（口播、实拍） | 整块、安静、光线稳定，通常只能放周末 |
| 剪辑 | 整块，中途被打断损失很大 |
| 写稿、写剧本 | 可以拆成 1 小时一块 |
| AI 生成画面、视频 | 可以「提交任务后去做别的」，适合碎片和夜间排队 |
| 回评论、看数据 | 碎片时间即可 |

### 预算上限

阶段 0 要写下的是**这一年最多花多少钱在这件事上**，不是计划买什么。建议按三类写：

```text
# numbers.md（预算部分）

一次性投入上限：____ 元
  （设备：麦克风、补光灯、支架；已有的手机和电脑不算）
每月工具订阅上限：____ 元
  （剪辑软件会员、AI 图像 / 视频 / 配音工具、素材库）
投流预算：0 元，直到 A2 退出条件达成后再议
总上限：____ 元，花到这个数之前要有第一笔收入，否则进入评审
```

为什么投流先写 0：冷启动期你还不知道什么内容有效，花钱放大的只是噪音。投流什么时候值得做、怎么算 ROI，见《投流与数据分析》。

具体买什么设备、每类工具怎么选，账号线见《拍摄与剪辑实务》，短剧线见《AI 内容生产工具链》。本书第 9 章有一张按阶段的预算参考表。

### 收入目标

先算你的「最低可行收入」：如果有一天全职做内容，每月最少需要多少净收入才能维持家庭开支、社保和储蓄。算法见《一人公司行动手册》阶段 0 一章和《一人公司方法论》第 1 章。

然后定一个**副业期的收入目标**，建议按最低可行收入的 30% 来定，作为 MA4 / MD4 的标准。30% 的意思是：这件事已经是一份认真的副业收入，但还远不到可以辞职的程度。辞职的判断在 A5 / D5 另算。

## 第 2 周：核对边界

这一周的事看起来和内容无关，但每一条都可能在半年后变成大麻烦。逐条核对，结果写进 `boundaries.md`。

| 核对项 | 去哪查 | 要得出的结论 |
|---|---|---|
| 劳动合同里的兼职、竞业、利益冲突条款 | 劳动合同、员工手册 | 能不能做有收入的副业；需不需要报备 |
| 公司对员工对外发言、自媒体的制度 | 员工手册、内部规章；互联网公司常见单独的「对外发言规范」 | 能不能提公司名、能不能讲行业内情、能不能出镜穿工牌 |
| 知识产权 | 劳动合同里的职务作品条款 | 内容不用公司代码、文档、内部数据；不在工作时间、用公司设备做 |
| 保密 | 保密协议 | 讲技术可以，讲公司的未公开业务、数据、客户不行 |
| 平台实名 | 各平台注册流程 | 账号用本人实名，收入进本人账户；不借别人的身份证注册 |
| 公开身份 | 自己和家人商量 | 露不露脸、用不用真名、家人和孩子会不会出镜 |
| 收入与纳税 | 《过渡期收入与个人保障》第 8 章 | 平台收入怎么算个税、要不要年度汇算 |

这张表的通用版本见《一人公司方法论》第 4 章「副业期间的边界」。内容副业有两条特别要注意：

- **内容是公开的，而且会一直在那里**。代码副业可以低调做几年，内容副业从第一条起就公开了。如果公司制度有疑问，先问 HR 或法务，拿到书面答复再开始；拿不到，就选一个和本职完全不相关、不露脸的方向
- **出镜的人、出声的人都要同意**。家人、同事、朋友出现在画面里，提前说好、最好留下书面同意。孩子出镜涉及未成年人保护的额外要求，见《自媒体与短剧合规财税》

## 第 2 周：盘点资产，然后选线

### 资产清单

技术人做内容的优势，在《自媒体与短剧一人公司全景》里有一章专门讲。这里只做盘点：

```text
# 资产清单

专业：后端开发 8 年，熟悉 Python、数据处理、自动化脚本
能讲清楚的事：____（你被同事问得最多的三类问题）
有的素材：工作之外的爱好（摄影、健身、做饭、带娃……）、读书笔记、写过的博客
表达方式：愿意露脸 / 只出声 / 只出手 / 都不愿意
审美和画面能力：会不会画画、懂不懂分镜、对影视有没有积累
人脉：认识的创作者、编剧、做短剧的人、做电商的人
设备：手机型号、电脑配置（AI 生成主要用云端，本地显卡不是必需）
```

### 选线判断表

两条线需要的能力和忍耐不同。下面每一行选一列，数一数哪边多：

| 问题 | 更适合账号线 | 更适合 AI 短剧线 |
|---|---|---|
| 你有没有一个能讲很久的专业或爱好 | 有 | 没有特别想讲的 |
| 你愿意以「自己」的身份出现吗（露脸或出声） | 愿意 | 不太愿意 |
| 你更喜欢哪种工作 | 讲述、解释、和人互动 | 编故事、调画面、做流水线 |
| 你能接受收入很慢吗 | 能，账号要攒 | 想尽快验证能不能接到单 |
| 你对平台政策变化的承受力 | 一般 | 能接受分账规则说变就变 |
| 你未来想做工具吗 | 想做创作者工具 | 想做短剧团队的工具 |

两边差不多时，建议**先走账号线**。原因是账号线的反馈更快、成本更低（几乎是零），而且一个能讲 AI 短剧制作的账号，本身就是短剧线后期获客的渠道。反过来，如果你对讲述没有兴趣、对编故事和调画面有兴趣，直接走短剧线。

两条线能不能一起做，第 9 章讲。阶段 0 只需要写下「先走哪条」。

## 第 3 周：写定位或题材方向

### 账号线：定位一页纸

定位怎么做、对标怎么找怎么拆，是《账号定位与对标拆解》的主题。阶段 0 只要求你写出第一版，并且找好 10 个对标账号的名单（拆解放在 A1 的第一周）。

```text
# positioning.md（第一版，2026-11-17）

一句话：给不写代码的职场人，讲怎么用 AI 工具把重复工作自动化

给谁看：25–40 岁、在办公室做表格和文档的人；不懂编程，但被重复工作烦
他们为什么看：每条能学会一个当天就能用的小方法
我凭什么讲：做了 8 年开发，天天在写自动化；能把技术翻译成人话
内容形式：竖屏口播 + 录屏演示，60–120 秒；同步一篇图文
主平台：小红书（图文 + 视频）；副平台：视频号
人设关键词：靠谱、不吹、有步骤
不做什么：不讲编程教程；不做 AI 新闻搬运；不卖课（至少 A3 之前）
将来可能的收入：工具类品牌商单、自己的小工具或模板、训练营

对标账号（10 个，A1 第 1 周拆）：
1. ____（同赛道头部）
2. ____（同赛道腰部，粉丝 1–10 万，最近半年才起来的）
...
```

几个判断标准：

- **「给谁看」要具体到能想象一个人**。「对 AI 感兴趣的人」不是定位，「做表格做到晚上九点的运营」是
- **对标里至少一半是腰部和新起来的号**。头部账号的成功往往依赖早期红利和长期积累，新号照抄学不到东西
- **主平台只选一个**。平台怎么选见《小红书、视频号与 B 站》《抖音与快手》。同步分发可以做，但复盘只看主平台
- **写「不做什么」**。它在后面会帮你拒绝很多诱惑：别人做 AI 新闻起号快，你不跟

### 短剧线：题材方向一页纸

短剧线在阶段 0 不需要决定讲什么故事，只需要定方向，让 D1 的学习有的放矢：

```text
# positioning.md（短剧线第一版）

形态：动态漫（2D 国漫风）  [备选：AI 仿真人]
题材方向：都市逆袭 / 古风甜宠 / 悬疑（选一个，写理由）
目标去向：先做作品集，D3 再决定上平台分账还是接定制
参考作品：10 部同形态、同题材、最近半年上线的作品，记下平台、集数、每集时长
风格参考：3–5 张能代表你想要画风的图（自己截图存档，只做参考，不直接使用）
不做什么：不改编没拿到授权的小说；不用真人明星的脸和声音
```

形态和题材的行业背景，见《微短剧行业全景》；题材赛道怎么选，见《短剧编剧》。AI 仿真人和动态漫在技术难度、审核尺度、分账政策上都有差别，2026 年部分平台对两者的政策已经分开（第 8 章细说），阶段 0 先选一个，不要两个都试。

## 第 3 周：写下阶段计划和止损线

把下一个阶段的进入日期、退出条件、止损线写进 `stages.md`：

```text
# stages.md

当前阶段：A1 前 30 条
进入日期：2026-11-24
计划节奏：每周 2 条（周二晚写稿，周六上午拍，周四、周日晚剪）
预计周期：15 周，评审日 2027-03-09

退出条件（建议值）：
- 主平台发满 30 条，每条都有 48 小时数据
- 至少 3 条的播放或互动 ≥ 账号中位数 3 倍

止损线：
- 评审日到了，发不满 20 条 → 评审节奏和时间预算
- 30 条发完，没有任何一条超过中位数 3 倍，且后 10 条的中位数不高于前 10 条 → 评审定位
- 总花费超过 numbers.md 里的一次性投入上限 → 停止采购

评审方式：周日晚 1 小时，对照本文件写评审记录
```

《一人公司方法论》第 6 章讲了为什么止损线要在开始时写好：一旦投入了，人就会不断找理由「再试试」。

### 账号注册的几件小事

- **一人一号起步**。矩阵是 A5 的事
- **实名用本人**。资料（头像、简介、背景图）按定位一页纸写好，简介里不留站外联系方式，各平台的导流规则见《国内私域与内容平台》第 9 章
- **不需要所谓的「养号」流程**。网上流传的「先刷几天同类视频再发」没有官方依据；正常完善资料、正常使用即可。真正影响新号的是内容本身
- **准备存稿**。A1 开始前先做好 2–3 条，让第一周不是从零开始

## 退出条件、止损线与常见的坑

**退出条件（M0）**：四个文件都写好了，并且你能对着 `stages.md` 说出下一阶段第一周的三件事。

**止损线**：阶段 0 超过 4 周还没写完，多半是在回避某个决定（通常是「露不露脸」或「公司允不允许」）。把这个决定单独拿出来，给自己一周，做不了决定就选更保守的那个选项先开始。

| 坑 | 表现 | 怎么办 |
|---|---|---|
| 先买设备 | 第一周就下单了几千元的相机和灯 | 用手机起步，A2 之后再按瓶颈买 |
| 定位写成口号 | 「分享有价值的内容」 | 写出具体的人、具体的收获 |
| 对标只找头部 | 十个百万粉账号 | 至少一半找腰部和新起来的号 |
| 跳过边界核对 | 发了半年被公司约谈 | 第 2 周就问清，拿书面答复 |
| 同时开多个平台 | 每个平台各发一半 | 主平台只选一个，其余只做同步 |
| 两条线同时开始 | 账号和短剧都在起步，都推不动 | 先选一条，另一条写进 `later.md` |

## 本章要点

- 阶段 0 不发内容，花 2–3 周写下时间、预算、边界、选线和定位，产出四个文件
- 时段按能不能用、适合做什么拆开；少于 3 个整块时段要拉长周期
- 预算写上限，投流先写 0；收入目标先定为最低可行收入的 30%
- 边界核对重点是公司的对外发言制度、保密和知识产权；内容一发就是公开的，有疑问先拿书面答复
- 两条线差不多时先走账号线：反馈快、成本低，还能为短剧线获客
- 定位一页纸写具体的人、具体的收获、主平台和「不做什么」；对标至少一半是腰部和新号
- 在开始前写好下一阶段的退出条件和止损线

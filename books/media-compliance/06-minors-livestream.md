# 未成年人保护与直播打赏

做程序员副业号，似乎和未成年人没什么关系。但只要你做直播、开打赏、拍家里孩子、做面向学生的编程课、或者内容可能被青少年看到，这一章就和你有关。未成年人相关的违规，平台处罚重、舆论敏感、法律责任明确，而且很多是**一次就封号**的红线。

直播间的搭建、话术、排品见《直播实战》，本章只讲未成年人和打赏相关的规则。

> 本章引用的《未成年人网络保护条例》条文核对的是中国政府网发布的文本（国务院令第 766 号，2024 年 1 月 1 日起施行）；《网络主播行为规范》核对的是国家广播电视总局网站发布的文本。

## 规则来源

| 规定 | 和创作者的关系 |
|---|---|
| 《未成年人保护法》（2020 年修订，设「网络保护」专章） | 总纲：网络产品和服务提供者、个人都不得危害未成年人身心健康（依据为已有知识，需核对原文） |
| 《未成年人网络保护条例》（国务院令第 766 号） | 内容提示、直播身份核验、消费限制、禁止应援集资等 |
| 《网络主播行为规范》 | 主播不得引诱未成年人打赏、不得利用未成年人博取商业利益等 |
| 《广告法》第三十八条 | 不得利用不满十周岁的未成年人作为广告代言人 |
| 文明办、文旅部、广电总局、网信办等关于网络直播打赏和未成年人保护的专门文件 | 禁止未成年人打赏、高峰时段限制等（依据为已有知识，需核对原文） |
| 平台规则 | 未成年人模式、直播准入、打赏退款流程 |

## 你的内容会被未成年人看到

### 显著提示义务

《未成年人网络保护条例》第二十三条第一款：网络产品和服务中含有可能**引发或者诱导未成年人模仿不安全行为、实施违反社会公德行为、产生极端情绪、养成不良嗜好**等可能影响未成年人身心健康的信息的，**制作、复制、发布、传播**该信息的组织和个人应当在信息展示前予以显著提示。

注意主语包括「制作、发布」的个人，也就是你。具体哪些信息属于这一类、怎么提示，条例授权国家网信部门会同有关部门确定。实务中常见的需要提示的内容：

| 内容 | 处理 |
|---|---|
| 危险动作、极限运动、改装电器、化学实验 | 片头提示「专业人员操作，请勿模仿」；危险过程不要详细教学 |
| 熬夜通宵、酗酒、吸烟镜头 | 尽量不拍；拍了要提示，不美化 |
| 恐怖、暴力、惊悚的 AI 短剧画面 | 片头提示；平台有分级或标签的按平台要求设置 |
| 极端情绪、自我伤害相关话题 | 非常谨慎；不展示方法；附求助渠道 |
| 「辍学创业」「不读书也能月入过万」 | 不鼓吹，避免引导未成年人 |

《网络主播行为规范》第十四条也把展示「易引发未成年人模仿的危险行为」、表现吸烟酗酒等诱导不良嗜好的内容列为禁止事项。

### 不要以未成年人为营销对象

- 《未成年人网络保护条例》第四十五条：网络游戏、网络直播、网络音视频、网络社交等网络服务提供者不得设置以**应援集资、投票打榜、刷量控评**等为主题的网络社区、群组、话题，不得诱导未成年人参与，并预防和制止其用户诱导未成年人实施上述行为
- 第二十四条还限制向未成年人进行商业营销（以条例原文为准）

对创作者来说：不组织粉丝为你「打榜」「集资」，尤其是粉丝中有学生的时候；带货内容不以学生为目标人群推销与其年龄不相称的商品。

## 让未成年人出镜

「晒娃」「亲子博主」「孩子学编程」类内容很常见，但规则越来越严。

| 情形 | 规则 | 建议 |
|---|---|---|
| 商业广告里让孩子代言 | 《广告法》第三十八条：不得利用**不满十周岁**的未成年人作为广告代言人 | 十岁以下的孩子不出现在任何商单的推荐、证明环节 |
| 非广告类的商业宣传 | 《网络主播行为规范》第十四条：不得利用未成年人或未成年人角色进行非广告类的商业宣传、表演或者作为噱头获取商业或不正当利益 | 不用孩子做流量噱头 |
| 孩子做主播 | 条例第三十一条：直播服务提供者对不符合法定条件的未成年人用户，**不得提供网络直播发布服务**；平台对十六周岁以下一般不允许开播，十六至十八周岁需监护人同意（依据为已有知识，以平台规则为准） | 不让孩子独立开播；不用大人的账号让孩子主播 |
| 日常记录中孩子出镜 | 监护人可以决定，但要考虑孩子的隐私和长期影响 | 不露正脸、不暴露学校、住址、全名等可识别信息 |
| 拍别人家的孩子 | 需要其监护人同意 | 不同意就打码或不拍 |
| 编程课、科普内容请学生出镜 | 取得监护人书面同意 | 授权书写明用途、期限（第 4 章模板加监护人签字） |

**儿童的个人信息**（不满十四周岁）属于敏感个人信息，处理要取得监护人同意（依据《个人信息保护法》，见《国内合规实务》第 6 章）。在视频里暴露孩子的学校、班级、日常路线，风险远大于流量收益。

## 直播打赏

### 你能从打赏里拿到什么

直播打赏的钱一般这样流动：观众充值买虚拟币 → 打赏礼物 → 平台按规则分成 → 主播（或主播所在的公会、MCN）获得收益 → 提现。分成比例、提现规则、结算周期以各平台和公会协议为准。打赏收入怎么交税见第 8 章；和公会的合同见第 7 章。

### 禁止的打赏诱导

《网络主播行为规范》第十四条把以下行为列为主播不得出现的行为：通过有组织炒作、雇佣水军刷礼物、宣传「刷礼物抽奖」等手段，暗示、诱惑、鼓励用户大额「打赏」，或者引诱未成年用户「打赏」、以虚假身份信息「打赏」。

落到话术上：

| 不能说 / 不能做 | 为什么 |
|---|---|
| 「刷个火箭我就……」「榜一大哥今晚送什么？」 | 诱导大额打赏 |
| 「刷礼物抽奖，抽中送 iPhone」 | 「刷礼物抽奖」被明确点名 |
| 找人或用小号在开播时刷礼物，带动气氛 | 雇佣水军刷礼物 |
| 「PK 输了要惩罚，大家帮帮我」反复催促 | 诱导打赏，平台重点治理 |
| 「小朋友也可以支持一下哥哥」 | 引诱未成年人打赏 |
| 发现观众说自己是学生，继续感谢他的礼物、点名互动 | 应该提醒对方不要打赏，并且可以通过平台功能处理 |

可以做的：正常感谢打赏；提醒「理性消费，未成年人请勿打赏」；知识直播靠内容获得打赏和转化。

### 未成年人打赏的后果

条例第四十四条要求直播等服务提供者合理限制不同年龄段未成年人的单次和单日累计消费额，**不得向未成年人提供与其民事行为能力不符的付费服务**。平台层面普遍禁止未成年人打赏，并设有未成年人消费退款通道。

对主播的影响：

- 未成年人用家长账号或自己的账号打赏，监护人可以向平台申请退款。根据《民法典》，限制民事行为能力人实施的与其年龄、智力不相适应的民事法律行为，需经法定代理人同意或追认；最高人民法院在相关司法文件中明确，限制民事行为能力人未经监护人同意参与网络付费游戏或网络直播打赏，监护人请求返还的，法院应予支持（依据为已有知识，需核对原文）
- 退款核实后，平台通常会从主播或公会的收益中**追回**对应分成
- 主播存在诱导未成年人打赏行为的，平台会处罚，严重的封禁

所以，不要把直播收入建立在「榜一大哥」上，也不要对可能是学生的观众放松警惕。

## 青少年模式和内容分级

大平台都有未成年人模式（青少年模式），条例第二十条要求影响力大的平台提供未成年人模式或者未成年人专区。进入未成年人模式的用户只能看到适合的内容池。

对创作者的影响：

- 你的内容是否进入未成年人内容池，由平台判断，创作者一般不能主动申请
- 部分平台提供「不适合未成年人」之类的作者自主标记，恐怖、暴力题材的 AI 短剧应主动设置
- 微短剧在广电系统有专门的审核和分级要求，见《短剧发行、投流与备案》

## 网络欺凌和评论区管理

条例第二十六条禁止通过网络以文字、图片、音视频等形式，对未成年人实施侮辱、诽谤、威胁或者恶意损害形象等网络欺凌行为。

创作者容易无意中卷入的情形：

- 拍了一个孩子的「搞笑瞬间」，评论区开始嘲讽、人肉 —— 下架视频，关闭评论
- 把学生的作业、作品拿出来「点评」时语气刻薄 —— 匿名化处理，评论就事论事
- 粉丝在评论区攻击某个未成年人 —— 删除评论、拉黑，必要时向平台举报

管理评论区是创作者的责任之一，平台一般提供关键词过滤、评论精选、关闭评论等工具。

## 自查清单

```text
【未成年人与直播自查】
内容
□ 是否有危险行为、不良嗜好、恐怖暴力、极端情绪内容？有 → 片头显著提示，不美化、不教学
□ 是否鼓吹辍学、超前消费、不读书致富？
□ 是否组织粉丝应援集资、投票打榜、刷量控评？
出镜
□ 画面中有没有未成年人？监护人是否同意？
□ 商单中是否让不满十岁的孩子推荐、证明？（禁止）
□ 是否暴露孩子的全名、学校、住址等信息？
□ 孩子是否在独立开播或「代播」？（禁止）
直播
□ 话术里有没有诱导大额打赏、刷礼物抽奖、PK 催刷？
□ 有没有找人刷礼物带气氛？
□ 是否定期提醒「理性消费，未成年人请勿打赏」？
□ 发现疑似未成年观众打赏，是否提醒并按平台流程处理？
□ 打赏收入是否预留了可能被追回的部分？
```

## 本章要点

- 发布可能影响未成年人身心健康的内容，制作和发布者要在展示前显著提示（条例第二十三条）
- 不得组织或诱导未成年人应援集资、投票打榜、刷量控评（条例第四十五条）
- 不满十周岁不得作广告代言人；不得利用未成年人作商业噱头；未成年人不能违规开播
- 主播不得诱导大额打赏、刷礼物抽奖、雇水军刷礼物、引诱未成年人打赏（《网络主播行为规范》第十四条）
- 未成年人打赏可被监护人追回，平台会从主播收益中扣回；不要把收入建立在大额打赏上
- 孩子的个人信息、隐私和网络欺凌风险，比流量收益重要

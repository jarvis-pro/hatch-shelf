# 赛道选择

「赛道」是这一行用得最多、也最含糊的词。有人说的是内容题材（美食、职场、AI），有人说的是变现方式（带货、知识付费），有人说的是短剧题材（都市、末世、重生）。这一章先把赛道拆成四个可以分别判断的要素，再给一套打分表和验证步骤，帮你在动手前把三五个候选比较清楚。

方向选择的通用方法见[《一人公司方法论》第 2 章](../opc-playbook/02-choosing-direction.md)「选方向」；这一章只讲内容和短剧行业里特有的判断点。具体到账号人设、找对标、拆解对标，见[《账号定位与对标拆解》](../account-positioning/)。

## 赛道 = 人群 × 需求 × 形态 × 变现

一个可以落地的赛道，要能用一句话同时说清四件事：

```text
给【谁】，解决【什么需求】，用【什么内容形态】，靠【哪种收入】赚钱。
```

对比两种说法：

| 含糊的说法 | 能落地的说法 |
|---|---|
| 我想做 AI 赛道 | 给不会写代码的运营和设计师，演示「一个 AI 工具解决一件具体的工作」，用 1–3 分钟竖屏实操视频，先靠 AI 产品的商单，再卖一套提示词模板 |
| 我想做程序员赛道 | 给工作 1–5 年、想做副业的程序员，讲「下班两小时做出一个能收钱的小产品」，用 B 站 10 分钟复盘视频，靠知识付费和工具 |
| 我想做 AI 短剧 | 给 25–40 岁女性用户，做「都市逆袭 + 轻喜剧」AI 漫剧，每集 1–2 分钟，在免费短剧平台拿分账 |

四个要素里，**人群和变现是最容易被忽略的**。很多人只想好了题材（「我做 AI」），却说不出看的人是谁、谁会付钱。

## 内容赛道速查

下面列出技术人常考虑的几类内容赛道，标出主要变现方式和需要注意的门槛。竞争程度、技术人适配度是作者的定性判断。

- **AI 工具实测与教程**
  - **典型人群**：职场人、运营、设计、学生
  - **主要变现**：商单（AI 产品推广需求旺）、知识付费、工具
  - **竞争**：高
  - **技术人适配**：高
  - **注意**：工具更新快，内容过时快；不要夸大效果
- **编程与技术教程**
  - **典型人群**：学生、初级开发者
  - **主要变现**：知识付费、商单（云厂商、开发工具）
  - **竞争**：中
  - **技术人适配**：很高
  - **注意**：制作成本高，适合 B 站中长视频
- **程序员职场与副业**
  - **典型人群**：在职开发者
  - **主要变现**：知识付费、私域咨询
  - **竞争**：中
  - **技术人适配**：高
  - **注意**：「月入过万」类承诺属虚假宣传风险
- **数码与效率测评**
  - **典型人群**：泛科技用户
  - **主要变现**：商单、带货
  - **竞争**：很高
  - **技术人适配**：中
  - **注意**：需要持续买设备或拿样，利益关系要披露
- **生活方式 vlog**
  - **典型人群**：泛人群
  - **主要变现**：商单、带货
  - **竞争**：很高
  - **技术人适配**：低
  - **注意**：依赖个人魅力和出镜
- **剧情短视频**
  - **典型人群**：泛人群
  - **主要变现**：商单、平台激励
  - **竞争**：很高
  - **技术人适配**：低到中
  - **注意**：需要演员、拍摄，一个人难做
- **财经、医疗、法律、教育**
  - **典型人群**：对应人群
  - **主要变现**：知识付费、商单
  - **竞争**：中
  - **技术人适配**：看专业背景
  - **注意**：**资质领域**：平台要求相应资质认证，无资质不要碰
- **AI 漫剧 / AI 短剧**
  - **典型人群**：短剧用户
  - **主要变现**：平台分账、承制
  - **竞争**：很高
  - **技术人适配**：高
  - **注意**：需要备案、AI 标识；题材有监管红线

关于资质领域：多个平台对涉及金融、医疗、法律、教育等专业领域的内容，要求创作者提供职业资格等资质认证，否则会被限流或处理。这既是平台规则，也和网信部门对「自媒体」管理的要求相关，具体以各平台规则和[《自媒体与短剧合规财税》](../media-compliance/)为准。**没有对应资质，就不要在这些领域给出专业建议**，即便你很懂。

## AI 短剧的题材赛道

短剧的「赛道」主要是题材。行业里常见的题材分类（都市、古装、玄幻、末世、重生、甜宠、家庭伦理等）本身没有好坏，判断时要看三件事：

1. **AI 能不能稳定做出来**：AI 生成擅长风格化画面（漫画、国风、科幻），对真人表演细节、复杂多人互动仍不稳定。题材要和你的生产能力匹配
2. **用户是谁、在哪个平台**：免费短剧平台和付费小程序的用户画像不同
3. **监管红线**：《微短剧发展管理办法》（2026 年 9 月 1 日起施行）和此前的系列管理要求，对低俗、暴力、宣扬不良价值观的内容有明确禁止；按投资额和题材分类分层审核，涉及政治、军事、外交、国家安全、司法公安等特殊题材的，不论投资多少都归入重点类，由广电总局审核。**一个人起步，避开特殊题材**

题材选择、人物设定、付费卡点的做法见[《短剧编剧》](../drama-scriptwriting/)；分类分层审核的流程见[《短剧发行、投流与备案》](../drama-distribution/)。

## 打分表

把候选赛道写成上面那句「给谁、解决什么、用什么形态、靠什么赚钱」，然后按下表打分。每项 1–5 分。

| 维度 | 权重 | 问自己 | 5 分是什么样 |
|---|---|---|---|
| 付费证据 | 3 | 这个赛道有人在为内容付钱吗？ | 同类账号有大量商单标识、橱窗销量、付费课程在卖 |
| 人群可触达 | 2 | 目标人群在你的主平台上大量存在吗？ | 搜 5 个关键词，结果和评论区都是目标人群 |
| 你的不公平优势 | 3 | 你有别人难以复制的经验、技能、资源吗？ | 你在这个领域工作多年，或有独家的生产工具 |
| 产出可持续 | 3 | 每周稳定产出 2–3 条，你能坚持一年吗？ | 素材取之不尽，单条耗时你扛得住 |
| 竞争空隙 | 1 | 头部是不是已经把位置占满了？ | 有需求，但现有内容质量一般或角度单一 |
| 合规风险（反向） | 2 | 资质、版权、题材风险大吗？ | 无资质要求、无版权依赖、题材安全 |
| 兴趣 | 1 | 一年后你还想做吗？ | 不给钱你也会研究这个 |

满分 75。为什么「付费证据」「不公平优势」「产出可持续」权重最高：内容这行最常见的三种死法正是「做了很久发现没人付钱」「做得不如别人」「做了两个月坚持不下去」。

一个可以反复用的打分脚本（Node 22.18 及以上可以直接运行这个只用了可擦除类型语法的 `.ts` 文件，更早的版本用 `npx tsx score-niche.ts`）：

```ts
// score-niche.ts
type Score = 1 | 2 | 3 | 4 | 5;

interface Niche {
  name: string;
  payEvidence: Score;   // 付费证据
  reach: Score;         // 人群可触达
  advantage: Score;     // 不公平优势
  sustainable: Score;   // 产出可持续
  gap: Score;           // 竞争空隙
  lowRisk: Score;       // 合规风险（越安全分越高）
  interest: Score;      // 兴趣
}

const weights: Record<Exclude<keyof Niche, "name">, number> = {
  payEvidence: 3,
  reach: 2,
  advantage: 3,
  sustainable: 3,
  gap: 1,
  lowRisk: 2,
  interest: 1,
};

const niches: Niche[] = [
  { name: "AI 工具实测（小红书 + B 站）", payEvidence: 5, reach: 4, advantage: 3, sustainable: 4, gap: 2, lowRisk: 4, interest: 4 },
  { name: "程序员下班做产品（B 站）", payEvidence: 3, reach: 4, advantage: 5, sustainable: 3, gap: 3, lowRisk: 4, interest: 5 },
  { name: "末世题材 AI 漫剧（免费分账）", payEvidence: 4, reach: 3, advantage: 3, sustainable: 3, gap: 2, lowRisk: 3, interest: 3 },
];

const max = Object.values(weights).reduce((a, b) => a + b, 0) * 5;

const rows = niches
  .map((n) => {
    const total = (Object.keys(weights) as (keyof typeof weights)[])
      .reduce((sum, k) => sum + n[k] * weights[k], 0);
    // 任何一项为 1 分都是硬伤，单独标出来
    const fatal = (Object.keys(weights) as (keyof typeof weights)[])
      .filter((k) => n[k] === 1);
    return { name: n.name, total, fatal };
  })
  .sort((a, b) => b.total - a.total);

for (const r of rows) {
  const flag = r.fatal.length ? `  硬伤: ${r.fatal.join(", ")}` : "";
  console.log(`${r.total}/${max}  ${r.name}${flag}`);
}
```

示例数据跑出来是：

```text
58/75  AI 工具实测（小红书 + B 站）
57/75  程序员下班做产品（B 站）
47/75  末世题材 AI 漫剧（免费分账）
```

前两名只差 1 分，这时候分数不再是决定因素，要看下面的验证结果。脚本里「任何一项 1 分是硬伤」这条规则很重要：**总分再高，只要有一项是 1 分（比如完全没有付费证据，或者题材踩红线），就不要选**。

## 打分前先做的四个验证

分数不能拍脑袋，每个维度都要有证据。下面四步，每个候选赛道花 1–2 小时：

### 1. 找 10 个同类账号

在主平台用目标人群会搜的词搜，找出 10 个同类账号，覆盖头部、腰部和近半年起来的新号。记录：

```text
| 账号 | 粉丝量级 | 近 30 天发布数 | 近 10 条平均互动 | 有无商单标识 | 有无橱窗/课程 | 开号时间 |
```

近半年起来的新号最有参考价值：说明这个赛道**现在**还有新人的位置。

### 2. 翻商单和橱窗

- 在这 10 个账号的近三个月内容里数一数带合作标识的有多少条，是哪些品牌
- 看橱窗里在卖什么、销量显示多少
- 看有没有人在卖课、卖资料、做社群

这一步直接给「付费证据」打分。**有人在付钱的赛道，才是赛道；没人付钱的，只是兴趣爱好**。

### 3. 读评论区

挑 3 条爆款，把评论区前 100 条读完。你要找的是：

- 用户在问什么还没被回答的问题（竞争空隙）
- 用户是不是你想要的那群人（人群可触达）
- 用户有没有表达「想买」「求链接」「求教程」（付费证据）

### 4. 做 3 条样稿，计时

不发布也可以，按你想做的形态真做 3 条，记录每条的耗时。乘以每周计划发布数，看你能不能长期扛住。这一步给「产出可持续」打分，也是最容易被跳过的一步。

## 一个完整示例

在职 Java 开发者，五年工作经验，做过 B 端 SaaS，每周能挤出 10 小时。三个候选的验证记录：

- **AI 工具实测**
  - **10 个账号里有商单的**：7 个，AI 产品居多
  - **新号情况**：近半年有多个新号起量
  - **评论区信号**：大量「求教程」「求链接」
  - **样稿耗时**：小红书图文 1.5 小时 / 条
  - **结论**：付费证据最强，但同质化严重，需要一个角度
- **程序员下班做产品**
  - **10 个账号里有商单的**：3 个，多为云厂商和开发工具
  - **新号情况**：新号较少，头部稳定
  - **评论区信号**：「求源码」「怎么收款」
  - **样稿耗时**：B 站视频 6 小时 / 条
  - **结论**：优势最大，但产出成本高
- **末世 AI 漫剧**
  - **10 个账号里有商单的**：不适用；查到同类剧有分账报道
  - **新号情况**：新剧极多
  - **评论区信号**：用户催更、吐槽画面不连贯
  - **样稿耗时**：1 集 1 分钟约 5 小时
  - **结论**：可做，但质量门槛在上升

最后的决定：**主线做「AI 工具实测」，角度收窄为「给 B 端 SaaS 团队用的 AI 工具」**，把自己五年 SaaS 经验变成不公平优势；内容以小红书图文为主（产出成本低），每月挑一个做 B 站长视频。AI 漫剧作为第二阶段的实验，先不开。

这个例子说明了打分表的正确用法：它不是自动给出答案，而是逼你把每个判断落到证据上，然后**把两个候选的优点组合起来**。

## 常见的坑

| 坑 | 表现 | 怎么避免 |
|---|---|---|
| 只看题材热度 | 「AI 很火，我做 AI」 | 回到那句话：给谁、解决什么、靠什么赚钱 |
| 选自己完全不懂的赛道 | 看到美妆赚钱就做美妆 | 不公平优势那一项给 1 分，直接淘汰 |
| 泛而不垂 | 今天 AI、明天健身、后天旅行 | 品牌按画像投放，泛账号很难接商单 |
| 盯着头部算收入 | 「他一条商单十几万」 | 看腰部和新号，头部的位置你拿不到 |
| 进入资质领域 | 没有资质讲理财、讲病 | 平台要求资质认证，无资质不碰 |
| 踩短剧红线题材 | 为了爆款做擦边、暴力 | 审核不通过、下架，账号受处罚 |
| 选题依赖搬运 | 把海外视频翻译过来发 | 侵权，平台按搬运处理 |

## 什么时候换赛道

选定以后不要频繁换。作者的经验标准是：在主平台按计划发满 30 条（或 90 天），并且做过至少一次基于数据的调整之后，如果数据仍然完全没有起色，再考虑换。微调角度（同一人群换个切入点）比整体换赛道代价小得多。具体的复盘方法和换方向判断，见《账号定位与对标拆解》。

## 本章要点

- 赛道要用一句话说清四件事：给谁、解决什么需求、用什么形态、靠什么收入
- 资质领域（金融、医疗、法律、教育）平台要求资质认证，无资质不碰；AI 短剧避开特殊题材
- 打分表七个维度中，付费证据、不公平优势、产出可持续权重最高；任何一项 1 分就是硬伤
- 打分前做四个验证：找 10 个同类账号、翻商单和橱窗、读评论区、做 3 条样稿并计时
- 有人在付钱的才是赛道；看腰部和新号，不要盯着头部算收入
- 发满 30 条或 90 天、并做过一次数据调整后仍无起色，再考虑换赛道；优先微调角度

# 附录：总清单与阅读对照

这一章把前面各章的清单、退出条件、止损线和阅读建议汇总在一起，方便随手查。每进入一个新阶段，把对应的清单复制进周计划，逐项勾掉。

## 一、各阶段总清单

### 阶段 0：盘点与准备（2–4 周）

- [ ] 导出过去 6–12 个月的账单，算出最低可行收入 M
- [ ] 列出单位现在承担、辞职后要自己出的项目
- [ ] 算出可动用储蓄、应急金、静态跑道，写进 `plan/numbers.md`
- [ ] 用 M 反推需要的付费客户数，判断量级是否现实
- [ ] 写出每周可用时段表（只算整块时间），和家人对一遍
- [ ] 翻出劳动合同、员工手册、保密和竞业协议，做边界核对
- [ ] 副业的电脑、仓库、云账号、域名、API 账号与公司彻底分开
- [ ] 列资产清单，按证据判断当前阶段
- [ ] 建公司仓库和 `plan/` 目录
- [ ] 写下一阶段的退出条件、止损线、评审日，以及项目总止损线

### 阶段 1：问题验证（4–8 周）

- [ ] 半天桌面调研，摘录目标用户的原话
- [ ] 30 家候选名单，标来源，熟人不超过三成
- [ ] 约访话术、访谈提纲、演示店准备好
- [ ] 访谈 8 家以上决策人，每次 24 小时内写笔记（化名）
- [ ] 第 4 周左右做中期汇总，调整提纲和样本
- [ ] 每次访谈结尾要转介绍
- [ ] 对愿意试用的门店约好具体时间
- [ ] 评审日对照退出条件做评审，写评审记录

### 阶段 2：前十个付费客户（2–4 个月）

- [ ] 定好收款身份、开票方式、早期价格和条件
- [ ] 用户协议、隐私政策、服务约定上线
- [ ] 每日备份和恢复演练做过一次；能在手机上收到故障告警
- [ ] 给激活下一个可判断的定义
- [ ] 每家开户计时、记卡点；3、7、13 天回访
- [ ] 客户台账：来源、耗时、激活、付费、第二期、反馈、下一步
- [ ] 反馈按挡付费 / 挡使用 / 锦上添花分类，只做前两类
- [ ] 开户时说清响应时间；FAQ 文档化
- [ ] 没续费的店逐家问原因
- [ ] 评审：10 家非熟人付费，至少 7 家续第二期

### 阶段 3：可重复的获客（4–9 个月）

- [ ] 建立三个数的月度统计：按渠道新增、单店获客时间、月流失率
- [ ] 转介绍机制上线
- [ ] 同时最多两个渠道实验，每个写卡片、跑满时间盒、写结果
- [ ] 至少试一个伙伴渠道（供应商、收银服务商）
- [ ] 按开户耗时数据，逐项压低最耗时的环节
- [ ] 用时间账决定是否做自助开户、在线续费
- [ ] 每家流失追原因，分闭店和可控流失
- [ ] 每月给门店发经营小结
- [ ] 季度评审；主渠道连续 3 个月稳定出客户后进入辞职评估

### 阶段 4：辞职决策与过渡（1–3 个月）

- [ ] 用真实数据跑收支交叉点，含保守场景
- [ ] 过辞职评分表，五条硬条件逐条判断
- [ ] 写出「全职后多出的时间用在哪、预计带来多少增长」
- [ ] 写决策记录：结论、关键数字、触线条件、回退方案
- [ ] 和家人确认跑道和最坏情况
- [ ] 社保医保续缴方案、公积金、商业保险问清并算进开支
- [ ] 有计划的贷款、信用卡在辞职前办完
- [ ] 主体是否注册定下方案
- [ ] 书面提出辞职，完整交接，确认竞业，不带走公司资料
- [ ] 正式离职后再对外公开

### 阶段 5：全职第一年（12 个月）

- [ ] 第一天按周模板工作，第一个月只定三个目标
- [ ] 每月跑道检查，和预测对比
- [ ] 第一季度验证「时间是瓶颈」
- [ ] 第二季度建公司仓库、第一个岗位、注意力预算
- [ ] 第三季度调定价、客户结构、渠道组合，砍掉没用的
- [ ] 第四季度年度复盘
- [ ] 每周至少休一天，每季度一周低负荷
- [ ] 休假模式和「如果我出事了」文档

## 二、里程碑、退出条件与止损线汇总

- **阶段 0**
  - 退出条件（建议值）：`plan/` 下的数字、时段、边界核对、下一阶段计划都写好
  - 止损线（任一成立即评审）：超过 6 周未完成：先解决时间问题
- **阶段 1**
  - 退出条件（建议值）：访谈 ≥ 8 家决策人，非熟人 ≥ 5；≥ 5 家正为该问题花时间或钱；≥ 3 家同意试用且没有否定价格
  - 止损线（任一成立即评审）：约到的访谈 < 4；认为问题严重的不到一半；连续 3 周未推进
- **阶段 2**
  - 退出条件（建议值）：10 家非熟人付费；≥ 7 家付第二期；开户耗时可接受且知道怎么压
  - 止损线（任一成立即评审）：3 个月付费 < 5 家；续费不到一半；开户耗时降不下来
- **阶段 3**
  - 退出条件（建议值）：主渠道连续 3 个月每月 ≥ 5 家新付费门店；付费门店 ≥ 40；可控月流失 ≤ 3%；单店获客时间约 2 小时或更低
  - 止损线（任一成立即评审）：6 个月没有连续两月稳定出客户的渠道；门店数不升反降；获客时间价值超过一年毛利
- **阶段 4**
  - 退出条件（建议值）：决策记录写好，硬条件全部满足，已提出辞职并交接，保障安排落实
  - 止损线（任一成立即评审）：硬条件不满足：不辞，回阶段 3，定下次评估日
- **阶段 5**
  - 退出条件（建议值）：连续 3 个月净收入 ≥ M，不靠单笔大单，工作量可持续
  - 止损线（任一成立即评审）：跑道触线：执行回退方案；连续两季度低于保守场景；连续两季度不想继续

这些数字按 hatch-counter 这类低客单价门店 SaaS 估算，换成你的产品时要重新定；但要在进入阶段时定好，评审日之前不改。

## 六、最后几句

这本书给的是一条路线，不是一份保证。阶段的周期、退出条件里的数字，都只是起点，你的产品、你的行业、你的生活状况都会让它们变形。但有几件事在任何变形下都成立：

- 按证据判断自己在哪，不按产品完成度
- 每个阶段事先写下退出条件和止损线，到了评审日再判断，评审之前不改
- 阶段 1–3 的瓶颈都不在代码
- 节奏要能持续，用结果衡量，不用时长衡量
- 判断和决定留给自己，执行尽量交给系统

## 本章要点

- 六个阶段各有一份可勾选的清单，进入阶段时复制到周计划里
- 退出条件和止损线汇总成一张表，数字按门店 SaaS 估算，换产品要重定，但要事先定、评审前不改
- 各章模板都有固定的存放位置，构成公司仓库里的 `plan/` 目录
- 阅读对照按阶段列出已完成系列的具体章节，同批新书按主题对照

# 常见亏钱方式与复盘

前面九章讲的是怎么投。这一章反过来：把副业投流最常见的亏钱方式列出来，每一种说清楚症状、原因和对策；然后给一套月度复盘的方法，让你每个月都能回答「投流这件事，到底该不该继续」。

## 亏钱方式清单

按出现频率大致排序。

### 1. 没算保本线就投

**症状**：后台 ROI 看着不错（比如 2.5），月底一算总账是亏的。

**原因**：平台 ROI 是营收回报，不是利润回报（第 2 章）。利润率 30% 的商品保本 ROI 是 3.33，ROI 2.5 每卖 1 元亏 0.1 元。

**对策**：每个 SKU 开投前按第 2 章的表算保本 CPA 和保本 ROI，写进看板的单位经济表。

### 2. 口径混用

**症状**：按支付 ROI 设目标，平台用净成交 ROI 结算；或者反过来。

**原因**：退款率 15% 时，两种口径的保本 ROI 差了约 0.35（第 2 章算例）。

**对策**：先确认后台出价和报表用的是哪种口径，保本线按同口径算。

### 3. 把自然成交当成投流效果

**症状**：开了全域 / 全站推广，ROI 很高，加了预算后店铺总利润没涨。

**原因**：全域 / 全站 ROI 的分子包含自然成交（第 4、7 章）。真正的增量可能只有一半甚至更少。

**对策**：用增量 ROI 判断；按第 8 章做开关对比。

### 4. 给差内容投钱

**症状**：每条内容都投一点，付费数据普遍平平，自然流量也没有起色。

**原因**：投流放大内容质量（第 1 章）。完播和互动不过线的内容，买来的流量同样划走。

**对策**：只投自然数据 ≥ 账号近 30 条中位数的内容。

### 5. 目标选错

**症状**：买了大量播放，涨粉很少；或者买了很多点赞收藏，没有任何私信和成交。

**原因**：系统按你选的目标找人。买播放找到的是「爱看不爱关注」的人。

**对策**：目标选你真正想要的那个动作（第 3 章）。有成交需求就用电商广告，不用内容加热。

### 6. 样本太少就下结论

**症状**：「这条素材 ROI 4，那条 ROI 1.5」，于是全押前者，结果第二周就掉到 2。

**原因**：几个转化算出的 CPA 波动极大，10 个转化的真实 CPA 在观察值的 0.54–2.09 倍之间（第 8 章）。

**对策**：放量前至少 20–30 个转化；转化太少时用 CTR、商品点击率这类样本多的指标先筛。

### 7. 零转化一直等

**症状**：「再等等，说不定下午就出单了。」

**原因**：沉没成本心理。花到 3 倍保本 CPA 还零转化，真实 CPA 不超过保本的概率只有约 5%（第 8 章）。

**对策**：开计划前写好零转化止损线，到线就停，不讨论。

### 8. 加预算看平均不看边际

**症状**：预算翻倍后平均 CPA 只涨了一点，但总利润反而下降。

**原因**：新增预算买到的是更贵、更不精准的流量（第 8 章边际 CPA 例子）。

**对策**：加预算后单独算边际 CPA，超过保本就退回上一档。

### 9. 冷启动期频繁调整

**症状**：每天改好几次出价、预算、定向，数据始终不稳定。

**原因**：每次修改系统都要重新探索，小样本波动又被误认为趋势。

**对策**：冷启动期按平台建议少改（第 4、7 章），每次小幅，看 3 天以上的累计数据。

### 10. 承接漏水

**症状**：CTR 正常，进来的人很多，成交很少。

**原因**：问题不在投流，而在价格、详情页、评价、直播间话术、私信回复速度。

**对策**：按漏斗逐步看转化率（展现 → 点击 → 商品点击 → 下单 → 支付），找掉得最厉害的那一步（漏斗方法见[《数据分析与埋点》第 5 章](../product-analytics/05-funnels.md)）。私信线索要保证及时回复。

### 11. 退款率被低估

**症状**：投放当周看着赚钱，一个月后退款回来，变成亏钱。

**原因**：退款滞后；用的是当天或当周的退款率。

**对策**：退款率用 30 天以前的成熟批次；看板按订单日期回填退款（第 9 章）。

### 12. 素材断档

**症状**：一条素材跑得很好，几周后量和 ROI 一起掉，没有替补。

**原因**：素材会衰减，同一人群看多了 CTR 下降。

**对策**：保持每周补新素材的节奏，用小额测试持续筛选候选素材。

### 13. 低毛利商品硬投

**症状**：怎么优化都在保本线附近徘徊。

**原因**：利润率 20% 的商品保本 ROI 是 5，需要非常好的素材和承接才能做到。

**对策**：换商品，或者只做自然流量。投流适合利润率高的商品和课程（第 2 章曲线）。

### 14. 被「投流服务」收割

**症状**：交了代投费、买了投流课、开了「低门槛代开户」，钱花了，效果没有。

**原因**：常见的几类：

- 承诺「保证上热门」「保证 ROI」的代投——官方投流工具不承诺效果（视频号的官方 FAQ 就明确写了不对加热效果作出承诺），承诺保证结果的第三方大概率在用刷量等违规手段
- 卖「卡审核」「黑科技起号」的课——教的是规避平台规则，账号和账户风险由你承担
- 「低门槛代开户」——开户资质是平台硬要求，可能使用不实资料

**对策**：官方工具都是自助的，副业阶段不需要代投。真要找服务商，选平台官方认证的服务商，合同里写清楚费用和交付物，不接受效果保证类承诺。

### 15. 违规素材

**症状**：审核不通过、计划被拒、账户被处罚，严重时账号受影响。

**原因**：夸大功效、虚假对比、「全网最低」等绝对化用语、无资质的医疗健康内容、未授权的音乐和画面、商业内容伪装成个人分享。

**对策**：按广告法和平台规则做素材（见[《自媒体与短剧合规财税》](../media-compliance/)）。审核不过时改内容，不要尝试准备「过审版」和「投放版」两套素材——那是规避审核。

## 月度复盘

每月初花一个小时，用第 9 章的看板做复盘。

### 第一步：算总账

看板上的「贡献利润」只扣了广告费。月度要算真实的投流盈亏：

| 项 | 本月金额 | 说明 |
|---|---|---|
| A. 投流带来的贡献 | | 成交目标：转化数 × 单位贡献；全域 / 全站类按增量估算 |
| B. 投流消耗 | | 各平台实付人民币合计 |
| C. 投流直接利润 = A − B | | |
| D. 为投流额外产生的成本 | | 素材外包、样品、投流相关的工具订阅等 |
| E. 投流净利润 = C − D | | |
| F. 花在投流上的时间 | | 小时数，包括抄数据、调计划、复盘 |
| G. 时薪 = E ÷ F | | 和你的主业时薪或其他副业比较 |

涨粉、测内容这类没有直接收入的投放，单列一行「投入预算」，和预算上限比，不放进 A。

G 这一行很重要：投流赚了 800 元，但花了 20 个小时，时薪 40 元。对很多在职开发者，这比不上把这 20 小时拿去做内容。**投流是放大器，不是替代品**；时薪太低时，减少投流、多做内容往往更划算。

税的问题（这部分收入怎么报税）不在本书范围，见《自媒体与短剧合规财税》。

### 第二步：按平台 × 工具看

| 平台 / 工具 | 消耗 | 直接利润 | 过线计划数 / 总计划数 | 下月动作 |
|---|---|---|---|---|
| 抖音 / 随心推 | | | | 加 / 维持 / 减 / 停 |
| 小红书 / 薯条 | | | | |
| … | | | | |

下月动作的规则：

- **直接利润为正，且过线比例 ≥ 一半**：在过线的计划上按第 8 章放量规则加预算
- **直接利润为正，但过线比例低**：利润来自少数计划，砍掉不过线的，维持总预算
- **直接利润为负，但有过线的计划**：只保留过线的，总预算降下来
- **直接利润为负，没有过线计划**：停投这个工具，回到内容和承接

### 第三步：回看测试

把本月所有测试计划表（第 8 章）拉出来：

- 每个测试有没有按事先写好的判断规则下结论？
- 哪些结论被后来的数据推翻了？（推翻的原因多半是样本太少）
- 下个月要测什么？按「影响最大的变量优先」排序，列 2–3 个

### 第四步：写一段投放日志

用几句话记下本月的关键事实和决定，三个月后回头看，比任何表格都有用：

```text
2026-11 投放日志

总账：消耗 1,860 元，直接利润 +420 元，额外成本 150 元（剪辑外包），
净利润 +270 元，投入约 9 小时，时薪 30 元。

赚钱的：随心推推 SKU-A，增量 ROI 约 3.1（保本 2.36），23 单。
亏钱的：薯条涨粉，单粉成本 1.6 元，超过上限 0.8 元，已停。
测试：T-11-01 新开头 vs 旧开头，CTR 2.9% vs 1.8%，每组 4,100 曝光，
      显著，后续素材统一用新开头。
疑问：千川全域 ROI 3.8，但开关对比只有 2.4，自然成交占比比想象中高。

下月：随心推预算从每天 60 元加到 100 元，看边际 CPA；
      停薯条涨粉，改为测封面；补 4 条新素材。
```

（日志里的数字是虚构的示例，用来展示写法。）

## 什么时候该停止投流

投流不是副业的必选项。出现下面任一情况，认真考虑停下来：

- 连续 3 个月投流净利润为负，而且没有任何一个工具过线
- 时薪持续低于你认为值得的水平
- 投流让你的注意力从内容上移开，内容质量在下降
- 投流带来的焦虑影响了主业和生活

停下来不等于失败。很多做得好的账号长期只靠自然流量，等内容和变现链路成熟了再投，效率反而更高。

## 本章要点

- 最常见的亏法：没算保本线、口径混用、把自然成交当投流效果、给差内容投钱、目标选错
- 小样本下结论、零转化一直等、加预算看平均不看边际，是统计上的三个坑
- 承接、退款、素材断档、低毛利是投流之外的问题，投流解决不了
- 不找承诺效果的代投，不学「卡审核」，不用违规素材
- 月度复盘算总账：直接利润 − 额外成本 = 净利润，再除以时间算时薪
- 按平台 × 工具决定加、减、停；连续亏损、时薪过低、影响内容时，考虑停止投流

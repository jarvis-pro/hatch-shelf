# 平台规则与封号风险

前面各章分散提到了各平台的导流限制。这一章把它们收拢起来：规则从哪来、哪些行为风险最高、怎么在发布前自查、账号出问题了怎么办，以及怎么把「一个账号被封就全完了」的风险降下来。

先说结论：**对一人公司，绕规则的技巧期望收益是负的**。你只有一个账号、一份精力，被封一次损失的是几个月的积累；而绕规则多带来的那几个加微，换一条更好的内容也能拿到。

## 规则的三层

| 层次 | 例子 | 违反的后果 |
|---|---|---|
| 法律法规 | 《广告法》《互联网广告管理办法》《个人信息保护法》《反不正当竞争法》 | 行政处罚、民事责任 |
| 平台总规则 | 小红书社区公约、抖音社区自律公约、B 站社区公约、微信个人账号使用规范、企业微信使用规范 | 限流、禁言、封号 |
| 平台专项细则 | 小红书《交易导流违规管理细则》、抖音行业公约 | 按细则处罚，通常比总规则更具体 |

平台规则一般都比法律严，而且会写「平台有权根据实际情况处理」。所以你不能只看法律允不允许，还要看平台允不允许。

规则在哪看：

- 小红书：App 内「设置 → 社区公约」，以及官方账号（如薯管家）发布的规则更新
- 抖音：抖音安全与信任中心（95152.douyin.com）
- 微信系：微信公众平台、视频号助手、企业微信管理后台里的「运营规范」「使用规范」
- B 站：创作中心和社区公约页

建议每季度花半小时把主平台的规则页过一遍，记录变化。平台规则的更新经常是先发公告、再改规则页，关注官方账号能早一点知道。

## 高风险行为清单

按平台整理，2026-11 查阅各平台规则和报道后的概括。

### 内容平台（小红书、抖音、B 站、视频号）

| 行为 | 风险 | 依据 |
|---|---|---|
| 在内容、评论、简介、私信里留微信号、手机号、二维码 | 高 | 小红书《交易导流违规管理细则》（2025-03-12 施行）明确禁止；抖音社区自律公约对站外引流有处置 |
| 用谐音、拆字、图片、水印藏联系方式 | 高 | 小红书细则明确把「变形」「嵌入」列为违规 |
| 多个账号互相评论、导流 | 高 | 小红书细则禁止多账号配合引离平台 |
| 小红书专业号自动回复里写微信、电话 | 高 | 2025-01-07 起禁止（界面新闻报道） |
| 批量私信陌生人 | 高 | 各平台普遍视为骚扰或营销 |
| 买粉、刷赞、刷评论 | 高 | 各平台规则；也可能涉及《反不正当竞争法》对虚假宣传、虚构交易的规定 |
| 搬运别人的内容 | 中高 | 侵权；平台原创保护机制 |
| 绝对化用语、效果承诺 | 中 | 《广告法》对「最佳」「第一」等用语的限制；平台广告规范 |
| 收了钱的推广不标注 | 中 | 《互联网广告管理办法》要求广告可识别（见下文） |
| 简介写品牌名和一句话定位 | 低 | — |
| 用平台官方的留资、名片、组件 | 低 | 按组件规则使用 |

### 个人微信

| 行为 | 风险 | 依据 |
|---|---|---|
| 使用群控、自动加人、自动群发等外挂 | 极高 | 微信安全中心明确外挂违规，「微营销」类群控工具是重点打击对象 |
| 短时间大量加好友 | 高 | 腾讯客服称频繁添加可能出现异常提示（IT 之家 2023-07 报道）；网传「1 小时超过 20 次」等具体数字来自二手转述，不可靠 |
| 群发营销消息给大量好友 | 中高 | 被举报后可能限制功能 |
| 好友数接近上限 | — | 公开报道称上限约 1 万（腾讯客服答复，2023-07） |

### 企业微信

企业微信的规则相对清楚，因为它本身就是给企业做客户联系的工具。风险主要在：

- 用第三方「企微外挂」做官方功能之外的自动化（如模拟点击批量加人）
- 被大量客户投诉骚扰
- 超出群发、朋友圈频次（系统会直接限制，第 6 章）

**用官方功能和官方 API 做的事，风险最低**。这也是第 6 章建议 To B 产品用企业微信的原因之一。

## 广告与推广的法律底线

### 《广告法》：说话的边界

即使是在个人账号上推广自己的产品，也是在发广告。几条最常踩的线：

- **绝对化用语**：「最好用」「第一」「顶级」「唯一」
- **效果承诺**：「用了保证每月多赚 5000」「100% 准确」
- **贬低竞品**：「xx 软件就是垃圾」
- **虚构用户评价**：自己写好评冒充客户

对 hatch-counter，说「每天自动算出赚了多少」是描述功能，没问题；说「用了掌柜眼，利润提升 30%」就是效果承诺，而且你也拿不出可靠证据。

### 《互联网广告管理办法》：推广要能被认出来

《互联网广告管理办法》（国家市场监督管理总局令第 72 号，2023-05-01 施行）要求互联网广告具有可识别性，对通过知识介绍、体验分享、消费测评等形式推销商品或服务并附加购买方式的，要求显著标明「广告」。具体条款以官方发布的原文为准。

一人公司常见的两种场景：

- **你自己发的内容里推荐自己的产品**：你本人的身份是公开的（「我是做这个软件的」），读者能识别这是推广。说清楚身份，比假装中立的测评安全得多
- **你找博主、KOL 推广**：要让对方按平台要求标注商业合作。小红书等平台有官方的商业合作通道，私下给钱不报备，在平台规则下同样违规

### 个人信息

私域运营天然涉及大量个人信息：手机号、微信、聊天记录、店铺经营数据。几条底线：

- 收集手机号要告知用途、取得同意
- 不买卖、不交换客户名单
- 不把客户的聊天记录和经营数据上传到不可信的服务
- 不在群里、朋友圈里发客户的店名、截图，除非对方明确同意

详细规定见《国内合规实务》第 6 章。用 AI 生成内容时的标识要求，见同书第 7 章。

## 发布前自查

每条内容发布前过一遍。可以贴在电脑旁边，或者让 agent 按这份清单检查草稿：

```text
发布前自查（小红书 / 抖音 / B 站 / 视频号）
[ ] 正文、图片、视频画面、字幕里没有微信号、手机号、二维码、外部链接
[ ] 没有谐音、拆字、表情拼出的联系方式；图片角落没有水印号码
[ ] 结尾引导是「评论区问」或「主页 / 品牌名」，不是「私我」「加我」
[ ] 没有「最」「第一」「唯一」「100%」「保证」
[ ] 数字有出处：是真实数据（经同意、已脱敏）还是示例数据，写清楚
[ ] 用到的客户案例，对方同意过，店名和个人信息已隐去
[ ] 图片、音乐、字体有使用权
[ ] 如果是付费合作，按平台要求标注

发布前自查（公众号 / 企业微信群发）
[ ] 群发对象对吗（全部客户 / 某个标签）
[ ] 本月给全部客户的群发是否已超过 2 次
[ ] 有没有发给不该收到的人（例如流失客户收到「续费优惠」）
```

## 账号出问题了怎么办

### 先分清是什么问题

| 现象 | 可能的原因 | 怎么确认 |
|---|---|---|
| 某一条内容数据突然很低 | 正常波动，或该条被限流 | 看后台有没有违规提示、站内信 |
| 连续多条数据都很低 | 账号被限流，或内容方向出了问题 | 看站内信；平台一般会通知明确的处罚 |
| 收到违规通知 | 某条内容或行为违规 | 通知里会写具体原因 |
| 功能被限制（不能私信、不能评论） | 处罚 | 站内信 |
| 账号被封 | 严重违规或累计违规 | 登录时提示 |

很多「我被限流了」其实是内容本身不行。没有收到任何通知的时候，先回头看内容，而不是去找「解限流」的方法。

### 申诉

- 只通过平台官方的申诉入口申诉，保存好违规通知的截图
- 申诉写清楚：哪条内容、你认为不违规的理由、相关证据。语气平和，不要情绪化
- **不要找任何「解封」「代申诉」的中介**。这类服务大多是诈骗，还可能骗走你的账号和身份信息。B 站公告里就提到过「付费代认证」衍生诈骗的情况，「付费解封」同理

### 被封以后

如果主平台账号被永久封禁：

1. 不要立刻用同一身份注册新号，多数平台会关联处罚，新号可能也会被封
2. 通知私域里的客户（企业微信、公众号）：服务不受影响，只是某个平台的账号没了
3. 复盘违规原因，确认不会再犯，再决定是否在该平台重来，或换主平台

这就是为什么前面反复强调**私域容器要独立于内容平台**：内容平台的号没了，客户还在企业微信里、名单还在你自己的系统里。

## 降低单点风险

| 风险 | 降低的方法 |
|---|---|
| 内容平台账号被封，积累清零 | 内容同时备份在本地（原稿、图片、视频工程）；重要内容在公众号或官网有长期版本 |
| 企业微信 / 个人微信出问题，客户全丢 | 付费客户的关键信息存在自己的系统里；公众号作为第二联系渠道 |
| 账号归属不清 | 公众号、企业微信、小程序绑定在你自己的主体下，管理员是你本人；不要用朋友的身份证或公司注册 |
| 代运营或外包登录你的账号 | 尽量不用；必须用时给子账号或运营者权限，不给主账号密码 |
| 买来的账号 | 不买。买卖账号违反各平台规则，账号的历史违规也会跟着来 |

## 判断一个「技巧」能不能用

网上有大量「私域引流技巧」。判断能不能用，问三个问题：

1. **平台官方提供了这个功能吗**？官方提供的（留资组件、联系我二维码、文章内放二维码），可以用
2. **它是不是在隐藏什么**？需要谐音、水印、小号配合才能实现的，一定是规则禁止的
3. **如果被平台的审核人员看到全过程，他会怎么判断**？如果你自己都觉得「这样做有点擦边」，那就是擦边

三个问题里只要有一个答案不对，就不用。

## 本章要点

- 规则分三层：法律法规、平台总规则、平台专项细则；平台规则通常比法律严，每季度过一遍主平台规则页
- 内容平台的高风险行为：留联系方式及其变体、多账号配合、批量私信、刷量、搬运；个人微信最高风险是外挂
- 用官方功能和官方 API 做的事风险最低，企业微信是 To B 私域最稳的容器
- 推广不用绝对化用语和效果承诺；《互联网广告管理办法》（2023-05-01 施行）要求广告可识别；找博主推广要走平台的商业合作通道
- 发布前用清单自查；没收到通知时，先怀疑内容而不是怀疑限流
- 只走官方申诉，不找解封中介；被封后不急着用同一身份注册新号
- 内容备份在本地，客户名单落在自己的系统里，账号绑在自己的主体下
- 判断技巧能不能用：官方提供吗、是否在隐藏什么、审核人员看到会怎么判断

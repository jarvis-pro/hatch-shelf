# 设备：够用就好

这本书写给没学过摄影、下班才有时间做内容的开发者。第一章先解决一个最容易花冤枉钱的问题：**到底要买什么**。

结论先放在前面：观众对画质的容忍度远高于你以为的程度，但对**声音难听**和**画面忽明忽暗**几乎零容忍。所以预算的优先级是：

1. 收音（一支几十到几百元的领夹麦，提升最明显）
2. 光线（一盏像样的补光灯，或者学会用窗户）
3. 稳定（一个三脚架或支架，让画面不晃）
4. 机身（手机够用很久，相机最后再考虑）

很多人的顺序正好反过来：先买相机，再发现声音全是回声、脸一半黑一半白，相机的画质优势一点也体现不出来。

## 手机还是相机

| 维度 | 手机（近两三年的中高端机型） | 相机（微单 / Vlog 相机） |
|---|---|---|
| 画质 | 光线充足时足够好，暗光下涂抹感明显 | 暗光、背景虚化、肤色过渡明显更好 |
| 上手难度 | 打开就能拍，自动模式可靠 | 要懂曝光三要素，设置项多 |
| 工作流 | 拍完直接进剪映，可以全程在手机上完成 | 要导卡、要电脑，流程更长 |
| 持续录制 | 发热降频、存储满了会停 | 部分机型有过热或单段时长限制，要查清楚 |
| 收音接口 | USB-C / Lightning，接无线麦接收器即可 | 3.5mm 口或热靴，接法更多样 |
| 成本 | 已有，零新增 | 机身加镜头数千到上万元 |

判断标准很简单：

- **口播、知识类、桌面开箱、屏幕录制为主**：手机完全够用。决定成败的是选题和表达，不是画质
- **需要强烈背景虚化、暗光环境多、产品要拍出质感（美妆、数码细节、美食）**：相机值得考虑
- **还没发满 30 条**：不要买相机。先用手机验证自己能不能持续更新，再决定是否加码

> 一个实用的检验：把你最想对标的三个账号的视频截图放大看。如果你分辨不出是手机还是相机拍的，那你现在也不需要相机。

## 三档预算配置

下表的价格**截至 2026 年 11 月**，以品牌官方公布的首发价或建议零售价为准；查不到官方价的品类只给量级区间，实际价格随促销波动很大，买之前请以官方渠道当时的报价为准。

### 第一档：500 元以内，先跑起来

| 物品 | 作用 | 参考价 |
|---|---|---|
| 现有手机 | 主摄像头拍摄 | 0 |
| 手机三脚架（带手机夹，最高能升到 1.6m 以上） | 固定机位，镜头和眼睛平齐 | 几十到一百多元 |
| 有线领夹麦（USB-C 或 Lightning 直插） | 让声音贴近嘴边，最大提升 | 几十到两百元 |
| 小型 LED 补光灯或环形灯（可调色温） | 晚上拍摄时补正面光 | 一百到两百元 |
| 白色泡沫板或 KT 板（A2 左右） | 反光板，补阴影面 | 十几元 |

这一档的核心是**白天靠窗户、晚上靠一盏灯**。第二章会讲窗光怎么用。

有线领夹麦的缺点是线会限制走动，而且线拖在画面里不好看。坐着口播完全没问题。

### 第二档：1500–3000 元，稳定日更

| 物品 | 作用 | 参考价 |
|---|---|---|
| 现有手机 | 同上 | 0 |
| 无线领夹麦（一拖一或一拖二） | 走动自如，可以两人对谈 | DJI Mic 3 国行首发价 1299 元起；入门款更便宜 |
| 60W 左右 COB 补光灯 + 柔光箱 + 灯架 | 主光，脸部光线柔和均匀 | 每套几百元 |
| 第二盏小灯或反光板 | 补光 / 轮廓光 | 一两百元 |
| 落地三脚架 | 同上 | 一两百元 |
| 手机云台（可选，需要走动拍 vlog 时） | 防抖、跟拍 | 大疆 Osmo Mobile 8 发布价 898 元 |

这一档能支撑绝大多数口播、知识、测评类账号长期日更。**买到这一档后，画面质量的瓶颈就不在设备上了**，而在布光、构图和剪辑。

### 第三档：8000–12000 元，追求质感

| 物品 | 作用 | 参考价 |
|---|---|---|
| Vlog 相机或 APS-C 微单套机 | 更好的暗光表现和虚化 | 大疆 Osmo Pocket 4 标准版 2999 元（2026 年 4 月发布）；索尼 ZV-E10 II 套机国行建议零售价 7499 元（2024 年发布） |
| 无线麦（一拖二） | 同上 | 1299 元起 |
| 两到三盏灯 + 柔光箱 / 柔光球 | 完整三点布光 | 一千到两千元 |
| 存储卡（V30 及以上）+ 读卡器 | 录 4K 不掉帧 | 一两百元起 |
| 假电池 / 外接电源 | 长时间录制不断电 | 几十到一百多元 |

几点说明：

- 列出的型号只是为了让你对价位有概念，不是推荐。同价位的其他品牌也都能用，挑选标准见下文
- 微单的套机镜头光圈一般是 f/3.5–5.6，虚化效果有限。真想要背景虚化，往往还要另买一支大光圈定焦镜头，预算要预留
- **第三档不是必经之路**。很多做到几十万粉丝的知识账号一直在用第二档

## 挑选标准：买的时候看什么

### 麦克风

- **接口和你的设备匹配**：手机是 USB-C 还是 Lightning，相机是 3.5mm 还是需要专用热靴接口
- **有没有机内录音备份**：发射器自带存储，无线信号断了也能从发射器里找回干净的音轨。DJI Mic 3 等较新的型号还支持 32-bit 浮点录音，后期调音量时不容易出现爆音削波
- **一拖二**：如果以后要做两人对谈、采访，一次买齐比后补便宜

### 补光灯

- **显色指数 CRI ≥ 95**（有的标 TLCI，同样看 95 以上）。显色差的灯会让肤色发绿或发灰，后期很难调回来
- **可调色温**（双色温 2700–6500K 左右）：可以和窗外自然光或室内暖光匹配
- **功率**：口播主光 60W 左右的 COB 灯加柔光箱足够；20W 以下的小平板灯只适合补光
- **有没有频闪**：用手机慢动作模式对着灯拍几秒，画面出现滚动的明暗条纹就是频闪，退掉
- **风扇噪音**：灯离麦克风只有一两米，风扇声会被录进去。买前看评测，或选有静音模式的

### 三脚架

- 最高能升到**你坐着或站着时眼睛的高度**。坐姿口播一般要 1.2–1.4m，站姿要 1.6m 以上
- 中轴能锁紧，不会慢慢往下滑
- 手机夹要能横竖切换

### 相机（如果真要买）

- **有翻转屏**：自己拍自己时能看到画面
- **没有严重的过热问题**：在评测里搜「过热」「录制时长」
- **自动对焦能稳定跟住人脸**：口播时一旦跑焦，整条素材作废
- **有 10-bit 和 Log**：现在不用也没关系，第九章讲调色时会说到

## 手机拍摄的设置

手机自带相机打开就能拍，但有几项设置不改，后期会很痛苦。

### 用后置主摄，不要用前置

前置摄像头画质明显差，而且多是广角，离脸近时会让鼻子变大、脸变形。用后置主摄（1x）或 2x 档拍口播，五官比例更自然。

后置摄像头看不到自己怎么办：

- 用手机投屏或另一台设备监看（部分无线麦、云台的 App 支持）
- 用带监看功能的第三方拍摄 App
- 最朴素的办法：先拍 10 秒试拍，回放确认构图，然后在地上和墙上贴胶带标记位置

### 分辨率和帧率

| 设置 | 建议 | 原因 |
|---|---|---|
| 分辨率 | 4K（存储紧张时 1080p） | 4K 横拍可以裁出竖屏，还能后期放大做「推镜」效果，第四章细讲 |
| 帧率 | 25 或 30 fps，**同一个账号固定一个** | 口播不需要 60 fps；混用帧率会让剪辑时出现卡顿 |
| HDR 视频 | 关闭 | 部分手机默认录 HDR，上传后在不同设备上亮度和颜色不一致，剪辑时也容易过曝 |
| 格式 | 高效（HEVC）即可 | 省空间；剪映都能识别 |

### 关于 25 还是 30 fps

国内电网是 50Hz，普通灯光每秒闪烁 100 次。如果快门速度和这个频率不匹配，画面里会出现缓慢滚动的明暗条纹。

- 在室内灯光下拍摄，用 **25 fps 配合 1/50 秒快门**最稳妥
- 手机自带相机通常不能手动设快门，出现条纹时可以换成 25 fps 试试，或者用能手动控制快门的拍摄 App（例如 Blackmagic Camera，免费，iOS 和 Android 都有）
- 纯户外日光下，25 和 30 都没问题

### 锁定对焦和曝光

手机的自动曝光会随着你挥手、转身不断调整亮度，画面一闪一闪。拍口播前：

1. 构好图，人坐到位
2. 在屏幕上长按自己的脸，出现「自动曝光 / 自动对焦锁定」之类的提示（不同品牌叫法不同）
3. 上下拖动曝光滑块，让脸的亮度合适而不过曝
4. 开始录

用第三方拍摄 App 时，把白平衡、ISO、快门都设成手动并锁定，效果最稳。第九章讲白平衡时会再说明为什么要锁。

### 其他准备

- 打开**飞行模式**或勿扰模式，防止来电打断录制
- 清理存储空间：4K 30fps 每分钟大约占 300–400MB（HEVC），一次拍摄预留 20GB 以上
- 擦镜头：手机镜头沾了指纹会让画面发雾、灯周围出现光晕，这是最常见也最容易忽略的问题

## 相机拍摄的基本设置

如果你已经有相机，口播场景用下面的起点设置，然后再根据现场微调：

| 参数 | 起点值 | 说明 |
|---|---|---|
| 拍摄模式 | 手动（M）或光圈优先（A） | 新手先用 A 档，熟悉后换 M |
| 帧率 | 25p（或 30p） | 与手机同理 |
| 快门 | 1/50（25p）或 1/60（30p） | 经验规则：快门约等于帧率的两倍分之一，动作模糊自然 |
| 光圈 | f/2.8–f/4 | 人脸都在焦内，背景适度虚化；太大光圈（f/1.8）时稍微前后晃动就跑焦 |
| ISO | 尽量低，在 100–800 之间 | 画面太暗先加灯，而不是先拉 ISO |
| 白平衡 | 手动，按灯的色温设置（例如 5600K） | 不要用自动白平衡 |
| 对焦 | 连续自动对焦 + 人脸 / 眼部识别 | |
| 图片配置文件 | 先用标准 | Log 需要调色，第九章再讲 |

快门和帧率的关系可以写成：

$$
\text{快门} \approx \frac{1}{2 \times \text{帧率}}
$$

25 fps 对应 1/50 秒，30 fps 对应 1/60 秒。这就是常说的「180 度快门」。

## 常见的冤枉钱

| 买了什么 | 为什么不值 |
|---|---|
| 一上来买全画幅相机 + 大三元镜头 | 选题和表达还没验证，设备吃灰的概率很高 |
| 只买相机，不买麦和灯 | 画质的提升被糟糕的声音和光线完全抵消 |
| 环形灯当主光 | 光源小、直射，脸发平、眼镜反光明显，眼睛里有一圈环形反光；适合补光不适合当主光 |
| 便宜的 RGB 氛围灯套装 | 显色差，放在背景里做氛围可以，打在脸上肤色会怪 |
| 绿幕 | 抠像需要大面积均匀打光，家里很难打好；真需要换背景，用 AI 抠像工具更省事 |
| 带「美颜」的补光灯 | 所谓美颜就是把光变得更平更亮，可以用柔光箱和后期达成 |
| 二手市场的「破解版」剪辑软件、来路不明的插件 | 安全和版权风险，账号被判侵权或电脑中毒得不偿失 |

## 本章要点

- 预算优先级：收音 > 光线 > 稳定 > 机身。观众能容忍一般画质，不能容忍难听的声音
- 三档配置：500 元内（手机 + 三脚架 + 有线领夹 + 一盏灯）、1500–3000 元（无线麦 + COB 灯 + 柔光箱）、8000 元以上才考虑相机
- 还没发满 30 条之前不要买相机
- 补光灯看显色指数（≥95）、可调色温、无频闪、风扇噪音
- 手机拍摄：后置主摄、4K、固定 25 或 30 fps、关 HDR、锁定对焦和曝光、开飞行模式、擦镜头
- 室内灯光下用 25 fps + 1/50 秒快门避免频闪条纹；快门约等于帧率两倍分之一

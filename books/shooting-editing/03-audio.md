# 收音：声音比画面重要

做过几期视频就会发现：画面糊一点，观众照样看完；声音嗡嗡的、有回声、忽大忽小，观众三秒内就划走。原因很简单，短视频大多数时候是**「听」完的**，画面只是辅助。

本章讲麦克风怎么选、怎么戴、房间怎么处理、录完怎么检查，以及后期降噪的边界。

## 收音的三个敌人

| 敌人 | 听起来像 | 根源 |
|---|---|---|
| 距离 | 声音发空、发远，像在大厅里讲话 | 麦克风离嘴太远，录进了大量房间反射声 |
| 混响 | 每个字后面拖着尾巴 | 房间空旷、墙面硬，声音来回反射 |
| 底噪 | 持续的「嘶——」或「嗡——」 | 空调、冰箱、电脑风扇、窗外车流、灯的风扇 |

三者里**距离是最关键的**。麦克风离嘴近一倍，人声相对于环境声的比例就大幅提升，混响和底噪都会同时变小。这也是为什么第一章说「一支几十元的领夹麦，比几千元的相机提升更大」：手机内置麦克风离你一米多，领夹麦离你二十厘米。

## 麦克风类型

| 类型 | 适合场景 | 优点 | 缺点 |
|---|---|---|---|
| 手机 / 相机内置麦 | 应急、环境声 | 零成本 | 离得远，混响和底噪重 |
| 有线领夹麦 | 坐姿口播 | 便宜、稳定、无需充电 | 线限制走动，线入画不好看 |
| 无线领夹麦 | 口播、vlog、采访、两人对谈 | 自由走动，可多人 | 要充电；可能有无线干扰；价格高 |
| 机顶枪麦（指向性麦） | 相机上，拍环境、街采 | 不用往身上夹 | 离人还是远，室内混响大时效果一般 |
| USB 桌面麦（电容 / 动圈） | 配音、录屏讲解、播客 | 音质好，直接接电脑 | 要放在嘴前 10–20 厘米，入画时不好看 |

对口播账号来说，**领夹麦是默认答案**。只做配音和录屏的知识账号，桌面麦更合适。

### 电容还是动圈

桌面麦分这两种，选错了会很难受：

- **电容麦**：灵敏，细节丰富，但也会把房间的回声、键盘声、空调声一起收进来。适合处理过的安静房间
- **动圈麦**：灵敏度低，只收嘴前近处的声音，对房间要求低。**在普通卧室或客厅录配音，动圈麦通常比电容麦效果好**

### 指向性

| 指向 | 收音范围 | 场景 |
|---|---|---|
| 全指向 | 四面八方 | 大多数领夹麦。离嘴很近，所以没关系 |
| 心形 | 主要收正前方 | 大多数桌面麦。要对着嘴，背后的噪音收得少 |
| 超心形 / 枪型 | 前方很窄的范围 | 枪麦。要精确对准声源 |

## 领夹麦怎么戴

- **位置**：胸口正中，衣领下方，离嘴约 15–20 厘米（一个手掌多一点）
- **朝向**：麦克风头朝上对着嘴
- **别夹在衣领边缘**：转头时一侧声音会忽大忽小
- **远离摩擦**：头发、项链、围巾、外套拉链蹭到麦克风，会有很响的「沙沙」声。羽绒服、冲锋衣的面料摩擦声特别大
- **户外加防风毛套**：有风时没有防风套，声音会被「噗噗」的风噪盖住
- **两个人对谈**：各戴一个，后期分轨处理，比共用一个麦好得多

想隐藏麦克风时，可以藏在衣服里面，但会损失高频、增加摩擦声。新手建议直接夹在外面，观众早已习惯在画面里看到领夹麦。

## 收音设置

### 电平：不要爆，也不要太小

录音电平用 dBFS 表示，0 dBFS 是数字录音的上限，超过就会**削波**（俗称爆音），听起来像破音，后期无法修复。

| 位置 | 判断 |
|---|---|
| 正常说话的峰值在 -12 到 -6 dBFS 之间 | 合适 |
| 大声笑、激动时峰值偶尔到 -3 dBFS | 可以接受 |
| 峰值碰到 0 dBFS，表头变红 | 太大，降低增益 |
| 峰值一直在 -24 dBFS 以下 | 太小，后期拉大时底噪会一起被放大 |

宁可稍微小一点也不要爆。小了能拉，爆了救不回来。

有些较新的无线麦支持 **32-bit 浮点录音**（例如 DJI Mic 3 的机内录音），这种格式的动态范围极大，录得太大或太小都能在后期无损拉回来，对新手非常友好。但它只对**发射器内部存储的录音文件**有效，通过无线传到手机的那一路仍然会削波，所以开了浮点录音也要记得导出发射器里的文件备用。

### 自动增益、降噪开不开

许多无线麦和手机 App 带「自动增益」「降噪」开关：

- **降噪**：在空调、风扇这类稳定噪音的环境里打开有帮助；但降噪强度高时人声会变闷、发「水声」。**有条件让环境变安静时，宁可关掉降噪、靠环境解决**
- **自动增益**：适合说话音量变化很大的场景（街采、vlog）；坐着口播时音量稳定，用固定增益更自然
- **原则**：先关掉所有处理录一段，再打开录一段，戴耳机对比，选听起来更自然的那个

### 机内录音备份

无线麦信号偶尔会断，尤其在 Wi-Fi 密集、有人走动遮挡的环境里。**每次都打开发射器的机内录音**，出了问题可以从发射器里找回干净的音轨，在剪辑软件里按波形对齐替换上去。

## 房间处理

不用装吸音棉。家里现成的东西就能明显改善混响：

- **软的东西越多越好**：沙发、床、地毯、厚窗帘、挂满衣服的衣柜都能吸收反射声
- **最好的录音地点通常是卧室**：有床、有衣柜、有窗帘。最差的是空旷的客厅、卫生间、厨房
- **靠近软的东西坐**：背后是衣柜或书架（书架上的书能打散声音）比背后是光墙好
- **临时措施**：在画面外的地上铺一条毯子；在镜头后面挂一条厚被子
- **拍手测试**：站在拍摄位置用力拍一下手，听回声的尾巴。尾巴越短越好。每加一样软东西，再拍一次对比

### 去掉噪声源

开录前在房间里安静站 10 秒，仔细听，逐个排除：

```text
[ ] 空调、暖风机、加湿器、空气净化器 → 关掉（录完再开）
[ ] 冰箱压缩机 → 关上房门；实在不行录制时临时拔电（记得插回去）
[ ] 电脑风扇 → 电脑离麦克风远一点，或关掉高负载程序
[ ] 补光灯风扇 → 打开静音模式，或调低功率
[ ] 手机、手表通知 → 静音
[ ] 窗外车流、施工 → 关窗；避开高峰时段
[ ] 椅子吱呀声 → 换椅子或不坐转椅
[ ] 宠物 → 请出房间
```

## 录音检查清单

每次开拍前，用 1 分钟录一段测试，**戴耳机**回放：

```text
[ ] 发射器、接收器电量充足（至少够录制时长的两倍）
[ ] 接收器已连接手机或相机，录制 App 选中了外接麦克风作为音源
[ ] 发射器机内录音已打开（如果支持）
[ ] 测试录音：正常音量说一段，峰值在 -12 到 -6 dBFS
[ ] 大声说一句，没有爆音
[ ] 回放听：没有沙沙摩擦声、没有嗡嗡底噪
[ ] 回放听：声音不发空、回声尾巴短
[ ] 左右声道都有声音（有些单声道麦只录到一侧，后期要处理）
[ ] 手机已开飞行模式或勿扰（来电会中断外接麦录音）
```

**「录音 App 选中了外接麦」这一条最常出错**。有的手机插上麦克风后仍然用内置麦录音，有的第三方 App 需要手动切换音源。录完一条才发现用的是内置麦，整段只能重录。

## 后期：能修什么，不能修什么

| 问题 | 能修吗 | 怎么修 |
|---|---|---|
| 音量整体偏小 | 能 | 提高增益或做响度标准化 |
| 稳定的底噪（空调声、嘶嘶声） | 基本能 | 剪映里的「音频降噪」，或专业软件的降噪工具；强度适中，否则人声变闷 |
| 偶尔的杂音（咳嗽、关门声） | 能 | 剪掉；或单独降低那一小段音量 |
| 轻微混响 | 部分能 | AI 人声增强类工具效果不错，但会改变音色，听起来可能「假」 |
| 削波爆音 | 基本不能 | 只能重录或剪掉 |
| 严重混响、离得太远 | 基本不能 | 重录 |
| 人声被背景音乐、人声盖住 | 很难 | 重录 |

所以收音的原则和光线一样：**在现场解决问题，后期只做微调**。

### 响度

多条视频之间音量要一致，观众才不用来回调音量。专业做法是统一**响度**（单位 LUFS），而不是峰值：

- 国内短视频平台没有公开统一的响度标准。很多创作者以 **-14 LUFS 左右**作为人声成片的目标值，这是参考了国外流媒体的常见做法，属于经验值
- 剪映里可以用「响度统一」类功能（具体名称以当前版本为准），或者凭耳朵对比：打开你上一条视频，切过来对比新视频，音量差不多即可
- 背景音乐要明显低于人声，具体比例见第七章

## 配音与录屏讲解

不出镜、只做配音或录屏的账号，收音的要求反而更高，因为声音就是全部。

- **用动圈 USB 麦或领夹麦**，嘴离麦 10–15 厘米
- **加防喷罩**：「p」「b」这类爆破音会产生一股气流冲击麦克风，听起来像「噗」
- **对着稿子录，但别「念」**：先读两遍顺口，再录。语速比平时聊天稍慢一点
- **一句话录坏了，停顿两秒，从这句开头重读**。剪辑时在波形上很容易找到停顿（第五章讲 NG 管理）
- 配音时手机或电脑通知全部关掉

## 本章要点

- 收音三个敌人：距离、混响、底噪；缩短麦克风到嘴的距离是最有效的改善
- 口播默认用领夹麦，夹在胸口正中离嘴 15–20 厘米，远离衣物摩擦；户外加防风毛套
- 配音在普通房间用动圈麦通常比电容麦效果好
- 电平峰值控制在 -12 到 -6 dBFS，宁小勿爆；32-bit 浮点录音只对机内录音文件有效
- 每次开机内录音备份；最常见的翻车是录制 App 没选中外接麦
- 房间用软的东西吸收混响，开录前逐个关掉噪声源
- 能在现场解决的不要留给后期：削波和严重混响后期修不了

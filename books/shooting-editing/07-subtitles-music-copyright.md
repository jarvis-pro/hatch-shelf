# 字幕、BGM、音效与版权

字幕、背景音乐和音效是剪辑里「包装」的部分。做好了，视频的完播率和专业感都会提升；做错了，轻则观众看着累，重则被平台判侵权、作品下架、商单作废。

本章前半部分讲怎么做，后半部分讲版权。**版权部分请认真读完**：「网上大家都在用」「剪映里能直接选」都不等于你可以随便用。法律层面的详细分析见[《自媒体与短剧合规财税》](../media-compliance/)，本章只讲剪辑时的操作规则。

## 字幕

### 为什么一定要加字幕

- 很多人在地铁、办公室里刷视频时是静音的
- 口音、语速、背景噪音会让部分内容听不清
- 字幕里的关键词强调能帮观众抓住重点
- 平台的内容理解也会参考画面中的文字（具体权重平台没有公开，这只是业内普遍的判断）

### 字幕规范

| 项目 | 建议 | 原因 |
|---|---|---|
| 每屏字数 | 竖屏一行，不超过 12–16 个字 | 一屏两行以上，观众来不及读 |
| 断句 | 按意思断，不要把一个词拆到两屏 | 「我们今天要讲的是 / 副业」比「我们今天要讲 / 的是副业」好读 |
| 标点 | 去掉句末的逗号、句号；保留问号、感叹号、引号 | 屏幕上的句号显得多余，问号和感叹号表达语气 |
| 字号 | 在手机上一眼能看清，通常占画面宽度的 70% 左右 | 导出后在手机上检查 |
| 字体 | 无衬线黑体类，粗一点 | 宋体等衬线体在小屏上笔画细，看不清 |
| 颜色 | 白字 + 黑色描边或半透明黑底 | 在任何背景上都能看清 |
| 位置 | 画面高度的 60%–75% 之间，避开底部遮挡区 | 见第四章的遮挡区示意 |
| 时间 | 与语音同步，每屏至少停留约 1 秒 | 太快一闪而过读不完 |

**全片字幕位置、字号、样式必须统一**。在剪映里调好一条字幕的样式后，应用到全部字幕，并保存为「预设」，下次直接调用。

### 关键词强调

在字幕中给关键词换个颜色或加大，帮观众抓重点：

- **每屏最多强调一个词**，全屏都是彩色等于没有强调
- 强调色固定一两种，例如黄色表示重点、红色表示警告
- 强调的是**数字、结论、反常识的词**，不是每个形容词

### 校对

自动识别的字幕必须逐句校对，最容易错的地方：

| 类型 | 例子 |
|---|---|
| 同音字 | 「权利 / 权力」「做 / 作」「的 / 得 / 地」 |
| 专有名词 | 技术术语、产品名、人名，例如把「Kubernetes」识别成别的词 |
| 数字 | 「两千五」识别成「2005」 |
| 中英混排 | 英文单词被拆开或识别成中文 |
| 口头禅 | 「那个」「就是」要不要出现在字幕里，全片统一 |

开发者可以维护一张**常错词替换表**，每次识别后先批量替换一遍，再逐句校对。

### 花字和动态字幕

剪映有大量花字、动态字幕模板。使用原则：

- 普通字幕用朴素统一的样式，**花字只用在少数需要强调的地方**（标题、关键数字、转折）
- 动画效果太多会分散注意力，口播类视频尤其如此

## 背景音乐

### 音乐的作用

- 填补人声间的空白，让视频不「干」
- 定基调：轻快、紧张、温暖
- 剪辑节奏的参考：切点可以落在节拍上（第八章）

### 怎么选

| 视频类型 | 音乐风格 | 注意 |
|---|---|---|
| 知识口播 | 轻柔的钢琴、Lo-fi、轻电子，**无人声** | 带歌词的音乐会和你的人声打架 |
| 测评、开箱 | 节奏明快、有律动 | |
| 生活 vlog | 轻快的民谣、流行器乐 | |
| 故事、情感 | 情绪起伏明显的配乐 | 情绪转折点要和音乐转折点对上 |

**口播类视频背景音乐一律选纯音乐（无歌词）**，这是最常被忽略的一点。

### 音量

人声是主角，音乐是配角：

- 背景音乐比人声低很多。经验做法：人声在 -6 dBFS 左右峰值时，音乐的峰值大约在 -20 到 -25 dBFS 之间
- 判断方法：**闭上眼睛听，能清楚听到每一个字，同时隐约感觉到音乐在**，就对了
- 人声停顿处（开头、结尾、长停顿）音乐可以适当升高，人声开始时再降下来。剪映里用关键帧调音量，或用「自动闪避」类功能（人声出现时自动压低音乐，具体名称以当前版本为准）
- 开头 1–2 秒淡入，结尾 2–3 秒淡出，不要戛然而止

### 一条视频用一首

一条 1 分钟的视频不要换三四首背景音乐。中途换音乐只在内容明确转折时（例如从「问题」转到「解决方案」）。

## 音效

音效是短视频节奏感的重要来源，用得好观众几乎察觉不到，但会觉得「这条剪得很顺」。

| 音效 | 用在哪里 |
|---|---|
| 「嗖」「呼」（转场声） | 画面切换、B-roll 进出、文字飞入 |
| 「叮」「咚」 | 关键数字、重点词出现 |
| 「咔嚓」（快门声） | 定格画面、截图展示 |
| 「打字声」「点击声」 | 录屏画面中的操作 |
| 「错误音」「嗡」 | 说到错误做法、反面案例 |
| 环境音（雨声、咖啡馆） | vlog 里补充氛围 |

使用原则：

- **音量比背景音乐更低或相近**，点到为止
- 同一种音效全片固定一个版本，形成「你的账号的声音」
- 一条 1 分钟的视频，音效通常不超过十来个，太密会显得吵

## 版权：先搞清楚三个概念

### 「免费」「免版税」「可商用」不是一回事

| 说法 | 实际含义 | 常见误解 |
|---|---|---|
| 免费下载 | 可以不花钱拿到文件 | 不等于可以用在你的视频里，更不等于可以商用 |
| 免版税（Royalty-Free） | 一次性付费或订阅后，使用时不再按次数、播放量付版税 | 不等于免费；授权范围仍有限制 |
| 可商用 | 授权允许用于商业目的 | 「商业目的」的范围各家定义不同，要看条款 |

### 你的视频算不算「商用」

在你以为是「个人分享」的场景里，很多其实算商用：

- 账号开通了任何变现（广告分成、橱窗、带货、知识付费）
- 接了品牌商单、广告
- 视频是为你的产品、公司、服务做宣传
- 企业号、蓝 V 账号发布的内容

保守起见，**做副业、以变现为目标的账号，都按「商用」来要求素材授权**。

### 授权范围是有边界的

一份授权通常限定：

- **平台**：只能在某个平台使用
- **用途**：个人创作、商业广告、线下播放是不同的授权
- **期限**：订阅制的授权可能在你停止订阅后对新作品失效（已发布的作品是否继续有效，要看条款）
- **改编**：能不能剪辑、变速、混音

## 背景音乐的可用来源

下面按类别列出可用的来源，并说明各自的边界。**具体条款以授权方当时的协议为准**，每次使用前都要看一眼。

### 一、平台内置曲库

抖音、剪映、小红书、快手等平台都有内置曲库，在 App 里直接添加。

- **适合**：在该平台发布的普通内容
- **边界**：据第三方整理的资料，平台曲库的授权一般**只覆盖在该平台发布的内容**。同一条视频同步到其他平台、用于商业广告、线下播放，都可能超出授权范围
- **商单要特别小心**：品牌合作视频的音乐使用通常需要单独确认。部分平台曲库会标注某首歌是否可用于商业推广，没有明确标注时，问清平台规则或改用有商用授权的音乐
- **剪映的版权检测**：剪映在部分场景（例如模板同步到抖音）会对背景音乐做版权检测，未通过时会推荐替换。通过检测只说明这首歌在该场景下可用，不代表在其他平台、其他用途下可用

### 二、商用音乐库（订阅或单曲购买）

国内外都有提供商用授权的音乐库，按年订阅或单曲购买。

- **适合**：多平台分发、接商单、企业号
- **注意**：订阅前看清授权覆盖的平台和用途（个人订阅和商业订阅往往是两个价位）；保存好授权证书或下载记录；停止订阅后已发布作品的授权状态要看条款

### 三、知识共享（CC）协议音乐

一些音乐人以 CC 协议发布作品，常见几种：

| 协议 | 能否商用 | 要求 |
|---|---|---|
| CC0 | 能 | 几乎没有要求，相当于放弃权利 |
| CC BY | 能 | 必须署名（在视频简介或片尾写明作者和出处） |
| CC BY-SA | 能 | 署名，且你的作品要以相同协议发布，通常不适合商业视频 |
| CC BY-NC | **不能** | 非商业用途 |
| CC BY-ND | 能，但**不能改编** | 剪辑、变速可能构成改编 |

带 NC 的不能用于变现账号；带 ND 的不能剪辑。用 CC BY 音乐时，**把署名写进视频简介**。

### 四、公有领域

作者去世超过保护期的古典音乐作品，**乐谱本身**可以自由使用。但是：

- 每一个**录音版本**都有录制者、表演者的权利。贝多芬的作品没有版权，但某个乐团录制的那张专辑有
- 能自由使用的是你自己演奏、或者明确以公有领域 / CC0 发布的录音

### 五、自己做、请人做、AI 生成

- 自己或请人原创：授权最干净，请人做要在合同里写清版权归属
- AI 音乐生成工具：**看清工具的服务条款**——免费版生成的作品往往不允许商用，付费版才有商用授权；部分平台要求标注 AI 生成内容。AI 生成内容的规则详见[《AI 内容生产工具链》](../ai-content-pipeline/)和《自媒体与短剧合规财税》

### 绝对不要做的

- 从音乐 App 里录屏、扒下热门歌曲当背景音乐
- 把别人的歌变速、变调、截一小段「以为不会被识别」
- 「片段不超过 15 秒就不侵权」——**没有这条规则**
- 在视频里写「音乐来源网络，侵删」——这句话不能免除侵权责任

## 音效、字体、视频素材的版权

### 音效

和音乐同理：用平台内置音效库（注意平台范围）、商用音效库、CC0 音效，或自己录。自己录音效其实很简单：手机录一下敲键盘、关门、倒水的声音，比到处找更快，而且完全归你。

### 字体

字体是最容易被忽视的侵权点，**商业字体侵权的索赔案例并不少见**。

- **剪映、系统里能选到的字体，不等于你能商用**：软件内置字体的授权范围由软件方和字体方约定，有的限定只能在该软件内用于特定用途。使用前在剪映的字体说明或会员协议里确认
- **电脑里装的字体，不等于你有授权**：很多是随其他软件附带或从网上下载的
- 封面、视频里的文字都算使用了字体

可以放心商用的字体（以各自发布方的最新授权说明为准）：

| 字体 | 授权说明 |
|---|---|
| 思源黑体、思源宋体 | SIL 开源字体许可（OFL），可商用，不能单独售卖字体文件 |
| 阿里巴巴普惠体 | 阿里巴巴发布，声明免费商用 |
| HarmonyOS Sans | 华为发布，可免费商用，需遵守其授权协议 |
| 站酷系列免费字体（如站酷快乐体等） | 站酷发布，声明免费商用 |
| 抖音美好体 | 据 2023 年的报道由抖音与方正合作发布、声明免费商用，授权细节请到官方页面确认 |

使用前到发布方的官方页面**下载授权协议并截图保存**，以备日后需要证明。

### 视频和图片素材（B-roll）

- **免费素材网站**：有些国外素材站提供可商用、免署名的视频和图片，但条款里通常有禁止项（例如不能把素材原样转售、不能用于暗示人物为某品牌代言、可识别的人物和商标需要额外注意）。用之前读一遍许可页
- **影视剧、综艺、他人短视频的片段**：不要直接用作 B-roll。「二创」「解说」的合理使用边界在法律上很模糊，平台也在持续收紧，对新账号来说风险远高于收益
- **新闻图片、网图**：不要用。图片的作者和来源很难核实
- **最安全的 B-roll 是你自己拍的**：录屏、桌面空镜、街景、手的操作。第八章会讲怎么批量拍

## 建一张授权台账

每用一个非自制素材，在台账里记一行。台账可以是一个表格，放在素材库的 `_shared/` 目录。下面是示例（第一行的曲名和来源是虚构的占位）：

| 素材 | 类型 | 来源 | 授权方式 | 适用平台 / 用途 | 署名要求 | 凭证位置 | 首次使用 |
|---|---|---|---|---|---|---|---|
| Morning Lo-fi 03 | BGM | 某商用音乐库 | 年度订阅 | 全平台，含商用 | 无 | `licenses/music-2026.pdf` | 20261103_T042 |
| 思源黑体 Bold | 字体 | Adobe / Google 官方 | SIL OFL | 不限 | 无 | `licenses/ofl.txt` | 全部 |
| 键盘音效 | 音效 | 自己录 | 自有 | 不限 | 无 | — | 20261103_T042 |

台账的价值在于：被投诉或被品牌方问到时，几分钟就能拿出证明；停止订阅某个音乐库时，能查到哪些作品用了它。

## 本章要点

- 字幕：竖屏一行 12–16 字以内、按意思断句、去句末标点、白字黑描边、全片样式统一并存为预设
- 自动字幕必须逐句校对，维护一张常错词替换表
- 口播类背景音乐选纯音乐，音量远低于人声，闭眼能听清每个字为准
- 音效固定一套、点到为止
- 「免费下载」「免版税」「可商用」是三回事；变现账号按商用要求素材授权
- 平台曲库一般只覆盖在本平台发布的内容；多平台分发和商单用商用音乐库
- CC 协议：NC 不能商用，ND 不能改编，BY 要署名；公有领域的曲子不等于录音版本也可用
- 软件里能选到的字体不等于能商用；用开源或明确声明免费商用的字体，保存授权凭证
- 最安全的 B-roll 是自己拍的；不要用影视剧片段和网图
- 建授权台账，每个非自制素材记一行

# 口播稿

口播是成本最低的短视频形式：一个人、一部手机、一面干净的墙就能拍。但口播也最依赖文字稿，因为观众能抓住的只有你的声音和脸。这一章讲怎么把一段「写出来的文字」改成「念出来好听、听得懂」的口播稿，以及怎么在稿子上标出断句、重音和节奏，让你对着提词器也能念出说话的感觉。

## 写的和说的是两种语言

开发者写口播稿，最常见的问题是写成了技术文档或公众号文章。读文章时，读者可以回头看、可以放慢、可以看括号里的补充；听视频时，观众只能跟着你的语速往前走，一句没听懂就划走了。

| 维度 | 书面语 | 口语 |
|---|---|---|
| 句子长度 | 一句可以三四十个字，带多层从句 | 一句尽量不超过 15–20 个字，一口气能说完 |
| 结构 | 先铺垫后结论，也可以 | 结论先说，因为没有标题帮你 |
| 词汇 | 「进行优化」「予以关注」「该功能」 | 「改一下」「留意」「这个功能」 |
| 指代 | 「上述三点」「前者」 | 重复名词，或者用「第一个」「刚才说的那个」 |
| 数字 | 「约 37.5%」 | 「三分之一多一点」，或者配字幕给精确数 |
| 括号和补充 | 常用 | 不存在。要么展开说，要么删 |
| 英文缩写 | 「CPU 占用」 | 第一次出现时说清是什么，「CPU，也就是处理器」 |

## 改写七条规则

下面七条按「最常犯」排序。每条都给改写前后对照。

### 1. 拆长句

一句话只说一件事。判断方法：念的时候中间要换气，就拆。

```text
改前：
在开机速度明显变慢的情况下，建议优先检查系统的启动项设置，因为很多软件在安装时会默认将自己添加为开机自启动，从而导致开机时间被大幅拉长。

改后：
开机变慢，先查启动项。
很多软件装的时候，会偷偷把自己设成开机就跑。
装得越多，开机越慢。
```

### 2. 结论放前面

```text
改前：
我用这个键盘用了三个月，期间打了大概二十万字的代码，也换过几次键帽，总体来说，我觉得它不值这个价。

改后：
这个键盘，我觉得不值这个价。
我用了三个月，打了二十来万字代码，说三个原因。
```

### 3. 把书面词换成嘴里的词

| 书面 | 口语 |
|---|---|
| 进行清理 | 清一下 |
| 具有较高的性价比 | 挺划算 |
| 用户可以通过以下方式 | 你可以这么做 |
| 该产品 | 这个东西 / 它 |
| 显著提升 | 快了不少 / 快了一倍 |
| 综上所述 | 所以 / 总之 |
| 首先、其次、最后 | 第一、第二、第三，或者「先……再……最后……」 |

一个简单的检验：这个词你跟朋友吃饭时会不会说。不会，就换。

### 4. 用「你」而不是「用户」「大家」

```text
改前：大家在使用过程中可能会遇到卡顿的问题。
改后：你是不是也遇到过，开个浏览器都卡？
```

对着镜头说话就是一对一，观众是一个人在看。「大家」会让人感觉在听讲座。

### 5. 数字要能听懂

耳朵记不住精确数字，尤其是小数和长串数字。

```text
改前：内存占用从 7.82 GB 降到了 4.31 GB，降低了 44.9%。
改后：内存占用从将近 8 个 G，降到 4 个 G 出头，差不多少了一半。
（字幕：7.82 GB → 4.31 GB）
```

精确数字放字幕，嘴里说约数。这是口播稿和字幕分工的典型例子。

### 6. 删掉对镜头没用的话

口播的每一秒都在消耗观众的耐心。下面这些话在文章里是礼貌，在视频里是流失点：

- 自我介绍：「大家好，我是某某，一个在大厂写了八年代码的程序员」——放到账号简介里，或者等内容讲完再说
- 预告结构：「今天这期视频我会从三个方面来讲」——直接讲第一个
- 客套：「希望对你有帮助」「如果觉得有用的话」——结尾的引导动作说具体，比如「评论区说你的电脑型号」
- 重复：「也就是说」「换句话说」后面跟着同样的意思

### 7. 每 10–15 秒给一个钩子

观众在任何一秒都可能离开。长段落中间加一些让人想听下去的小句子：

```text
- 「但这一步，大部分人都做错了。」
- 「第三个最简单，也最有用。」
- 「说到这你可能会问……」
- 「我一开始也以为是这样，后来发现不是。」
```

不要每句都是钩子，那就成了标题党。一条 60 秒的口播，开头一个、中段一两个就够。开头的「黄金 3 秒」怎么设计，见[《选题与爆款结构》](../topic-and-hooks/)。

## 一份完整的改写对照

原文是一段公众号文章的开头：

```text
随着使用年限的增长，许多 Windows 笔记本电脑会出现开机缓慢、运行卡顿等问题。很多用户的第一反应是更换新设备，但实际上，在大多数情况下，通过对启动项、磁盘空间和浏览器扩展进行合理的管理和优化，可以在不增加任何成本的前提下显著改善设备的使用体验，延长其使用寿命。本文将分别从这三个方面进行详细介绍。
```

改成口播稿：

```text
你的电脑是不是开机要两分钟，开个网页都卡？
先别急着换。
做完这三件事，不花一分钱，大部分旧电脑还能再用两年。
第一件，也是最管用的一件：关掉开机自己跑的软件。
```

对比一下改了什么：

| 位置 | 改法 |
|---|---|
| 「随着使用年限的增长……出现开机缓慢」 | 换成一个观众能对号入座的问题 |
| 「很多用户的第一反应是更换新设备」 | 变成「先别急着换」，四个字 |
| 「在不增加任何成本的前提下显著改善……」 | 拆成「不花一分钱」「还能再用两年」，具体 |
| 「本文将分别从三个方面进行详细介绍」 | 删掉，直接开讲第一件 |
| 原文 140 字左右 | 口播稿 70 字左右，信息没少 |

## 在稿子上标记：断句、重音、节奏

改好的文字稿还只是文字。念出来好不好听，取决于你在哪里停、哪个字重、哪里快哪里慢。播音行业有一套完整的标记符号，对新手来说太复杂；下面是一套够用的简化版，用纯文本就能写，提词器上也能显示：

| 标记 | 含义 | 例子 |
|---|---|---|
| `/` | 短停顿，约半拍，不换气 | 先别急着换 / 做完这三件事 |
| `//` | 长停顿，约一拍，可以换气 | 开个网页都卡？// 先别急着换 |
| `**字**` | 重音，这个词说重一点、慢一点 | 不花**一分钱** |
| `↑` | 语调上扬，用于提问、制造悬念 | 开机要两分钟↑ |
| `→` | 加快语速，一带而过 | → 设置、应用、启动 |
| `（动作）` | 表情、手势、看向哪里 | （伸出三根手指） |
| `[插]` | 这里切到插入画面，人声继续 | [插：任务管理器录屏] |

标记后的稿子：

```text
你的电脑 / 是不是开机要**两分钟**↑ / 开个网页都卡↑ //
先别急着换。//
做完这**三件事**（伸出三根手指）/ 不花**一分钱** / 大部分旧电脑 / 还能再用**两年**。//
第一件 / 也是**最管用**的一件：/ 关掉开机自己跑的软件。
[插：任务管理器录屏]
→ 右键开始菜单 / 任务管理器 / 点「启动」。
```

### 重音放在哪

一句话通常只有一个最重要的词，重音就落在它上面。找重音的方法：问自己「这句话如果只能让观众记住一个词，是哪个」。

- 数字：两分钟、三件事、一分钱
- 对比的两端：不是**硬件**的问题，是**软件**的问题
- 新信息：观众第一次听到的那个概念

重音太多等于没有重音。一句最多一个，一段最多两三个。

### 停顿放在哪

- 句号处长停顿，给观众消化的时间，也给剪辑留剪切点
- 主语很长时，主语后面短停顿：「大部分用了三年以上的旧电脑 / 还能再用两年」
- 重音词前面短停顿，制造期待：「不花 / **一分钱**」
- 问句后面长停顿，让观众在心里回答

留停顿还有一个实际好处：**剪辑时好剪**。一口气连着说的话，中间没有空隙，想删一句都没法下刀。

## 时长估算

口播稿的时长主要由字数决定。中文自然口播的语速因人而异，大多数人在每秒 3–4 个字之间；知识类偏慢，情绪类、带货类偏快。不要用别人的数字，**用你自己的**：

1. 拿一段 200 字的稿子，按正常语速念一遍，用手机秒表计时
2. 算出你的语速：200 ÷ 秒数 = 每秒字数
3. 之后写稿时，目标时长 × 你的语速 = 稿子字数上限

例如你念 200 字用了 57 秒，语速约 3.5 字 / 秒。目标 60 秒的视频，扣掉开头 2 秒的画面、结尾 3 秒的引导画面，剩下约 55 秒说话，稿子应在 190 字左右。

写完后要真的念一遍掐表，因为停顿会吃掉时间。一般会比估算长 10%–20%。

## 口播稿模板

适合知识类、观点类口播，60–90 秒：

```text
【选题】一句话
【目标时长】__ 秒，我的语速 __ 字/秒，字数上限 __ 字

【钩子 0–3s】
一个观众能对号入座的问题，或一个反常识的结论。

【承诺 3–8s】
看完能得到什么。具体、可衡量：「三件事」「不花钱」「五分钟」。

【正文 8–50s】
第一点：一句结论 + 一句为什么 + 一句怎么做   [插：____]
（钩子句）
第二点：……   [插：____]
第三点：……   [插：____]

【收尾 50–60s】
一句总结（可选） + 一个具体的互动动作。
不要「希望对你有帮助」。
```

### 提词器怎么用

一个人拍口播几乎都要用提词器，手机上的剪映、各种提词器 App 都有这个功能。几个实用的点：

- **提词器里放标记后的稿子**，不要放干净的原文。看到 `//` 就知道该停
- **字号调大、每行字数少**，眼睛移动幅度小，镜头里看不出在读
- **滚动速度略慢于你的语速**，宁可自己等它，也不要追它
- **不要一口气录完**。按段录，一段 10–20 秒，错了只重录这一段。每段开头留一秒空白再开口，结尾说完停一秒再停止，方便剪辑

## 自检清单

写完口播稿，逐条过一遍：

| 检查项 | 怎么查 |
|---|---|
| 第一句是钩子，不是自我介绍 | 看第一行 |
| 每句一口气能念完 | 出声念，中间换气的句子拆开 |
| 没有「该」「进行」「予以」「综上」 | 搜索这些词 |
| 精确数字只在字幕里 | 搜索小数点和百分号 |
| 每 10–15 秒有画面变化或钩子 | 看 `[插]` 和钩子句的间隔 |
| 结尾是具体动作 | 看最后一行 |
| 字数不超过上限，念一遍时长对 | 掐表 |

## 常见坑

- **念稿腔**：字都对，但听起来像在读课文。原因通常是稿子里还有书面语，或者没标停顿。改稿比练念更有效
- **全程同一个语速**：60 秒都是匀速，听着犯困。要点处放慢，过程描述加快
- **改稿时只删不改**：删字数是对的，但删完要重新念一遍，删掉的可能是承上启下的那句
- **背稿**：新手背稿会把注意力全放在「下一句是什么」上，表情僵硬。用提词器，分段录
- **一个人演独角戏，眼神乱飘**：提词器尽量贴近镜头，眼睛看镜头附近；需要看稿时，在稿子里标「（低头看手机）」把它变成动作的一部分

## 本章要点

- 口播稿是给耳朵的：短句、结论先行、口语词、用「你」、数字说约数并配字幕
- 删掉自我介绍、结构预告、客套话；每 10–15 秒给一个钩子或画面变化
- 用 `/` `//` `**重音**` `↑` `→` `（动作）` `[插]` 标记稿子，提词器里放标记后的版本
- 每句只有一个重音；句号处留长停顿，方便观众消化也方便剪辑
- 用自己的语速估算字数，写完必须念一遍掐表
- 分段录，每段前后留一秒空白

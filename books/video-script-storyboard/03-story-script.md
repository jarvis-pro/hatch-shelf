# 剧情类脚本

剧情类短视频是指有人物、有冲突、有结局的一两分钟小故事：职场段子、情侣日常、反转小剧场、带一点产品的情景短片。它比口播难，因为你要同时管故事、表演和画面；但它的传播力往往更强，因为人天生爱看故事。

这一章讲单条剧情短片（通常 30 秒到 3 分钟）的写法：人物怎么立、冲突怎么搭、反转怎么埋、台词怎么写、场景怎么设计成「一个人下班也拍得出来」。多集连续、付费卡点的短剧剧本是另一门手艺，见[《短剧编剧》](../drama-scriptwriting/)。

## 一条剧情短片的骨架

再短的剧情也有四个部分：

```mermaid
flowchart LR
  A["建立：谁、在哪、想要什么"] --> B["冲突：遇到阻碍"]
  B --> C["升级：阻碍变大或出现意外"]
  C --> D["结局：反转、解决或留悬念"]
```

在 60 秒里，这四段的时间分配大致是：

| 段落 | 60 秒视频 | 任务 | 常见错误 |
|---|---|---|---|
| 建立 | 0–8s | 一个画面交代人物和处境 | 铺垫太长，观众还没看到冲突就走了 |
| 冲突 | 8–25s | 抛出问题 | 冲突不清楚，观众不知道主角想要什么 |
| 升级 | 25–45s | 让事情变得更糟或更荒诞 | 没有升级，平铺直叙 |
| 结局 | 45–60s | 反转或解决 | 结局在意料之中；或者反转没有铺垫，显得硬 |

和长剧不同，短视频的「建立」要极度压缩。最好的办法是**直接从冲突的前一秒开始**：不要拍主角起床、出门、到公司，而是从老板把文件甩到桌上那一刻开始。

## 人物：一句话立住

短视频没有时间塑造复杂人物。每个角色用一句话定义，而且这句话要能**通过画面和第一句台词**传达出来：

```text
角色卡
- 名字 / 称呼：小林
- 一句话：刚入职三个月的前端，什么需求都接，从不说不
- 他想要：按时下班去赴约
- 他怕：被说态度不好
- 第一眼识别：工牌、双肩包、桌上的待办便利贴贴满了显示器
- 说话方式：「好的好的」「没问题」，句尾带「哈」
```

几个要点：

- **「想要」和「怕」是冲突的来源**。小林想下班，又怕说不，冲突就有了
- **用视觉标签代替介绍**。便利贴贴满显示器，比旁白说「他很忙」有效十倍
- **说话方式要有辨识度**。口头禅、句尾词、语速，演员（多半就是你自己）照着演就有人物感
- **角色数量越少越好**。一条 60 秒的剧情，两个角色最稳，三个是上限

如果你一人分饰两角（很多剧情号这么做），角色卡上的「第一眼识别」要特别明显：一个戴眼镜一个不戴、一个穿衬衫一个穿卫衣，剪辑时观众才不会混。

## 冲突：想要的东西被挡住

冲突不等于吵架。冲突是**角色想要某样东西，但有东西挡着**。阻碍可以来自：

| 阻碍来源 | 例子 | 适合的内容 |
|---|---|---|
| 另一个人 | 产品经理下班前改需求 | 职场、情侣、家庭 |
| 环境 / 规则 | 公司规定周五必须开周会 | 吐槽类、共鸣类 |
| 自己 | 想减肥但忍不住点外卖 | 自嘲类、成长类 |
| 物件 | 打印机永远在关键时刻卡纸 | 生活段子、产品植入 |

写冲突时问自己三个问题：

1. 主角想要的东西，观众能在 10 秒内明白吗
2. 阻碍是观众经历过的吗（共鸣决定转发）
3. 主角为什么不能直接放弃（不然就没戏了）

## 升级：让事情更糟

只有冲突没有升级，故事就是「遇到问题、解决问题」，很平。升级的常用手法：

- **加码**：改一个需求 → 改三个 → 「顺便把首页也改了吧」
- **时间压力**：离约会只剩 10 分钟
- **意外**：好不容易改完，电脑蓝屏了
- **误会**：女朋友打来电话，正好听到他说「今晚不走了」

升级一般一到两次就够。每一次升级都要比上一次更强，而且观众要能预感到「要坏事了」。

## 反转：埋在前面，翻在后面

反转是剧情短视频的核心卖点，但也是最容易写砸的地方。好反转有两个条件：

1. **意料之外**：观众没猜到
2. **情理之中**：回头一想，前面其实给过线索

只满足第一条的反转叫「硬反转」，观众会觉得被耍了。下面是几种常用反转结构：

| 类型 | 做法 | 例子 |
|---|---|---|
| 身份反转 | 某个角色的真实身份和看起来的不同 | 被刁难的实习生其实是老板的孩子（很俗，慎用） |
| 视角反转 | 换一个人的视角看同一件事 | 产品经理改需求，镜头一转：是老板凌晨 2 点给他发的消息 |
| 动机反转 | 角色做事的原因和观众以为的不同 | 小林加班不是因为不会拒绝，是因为他根本没有约会，只是不想回家 |
| 结果反转 | 以为会失败结果成功了，或反过来 | 小林终于说了「不」，产品经理说「好的，那这个需求就不做了」，小林愣住 |
| 规模反转 | 镜头拉远，发现情况比想的大或小 | 小林以为只有自己在加班，镜头拉开，全办公室的人都在 |

### 埋线索的方法

在前半段放一个**看起来无关紧要的细节**，结局时让它变得关键：

- 开场时，小林手机屏幕上闪过一条消息，只拍了 1 秒
- 产品经理桌上有一张和小林一样的约会电影票
- 小林说「好的好的」时，镜头扫过他手里攥紧的笔

写脚本时把线索和揭示成对写下来，避免拍的时候漏掉：

```text
线索表
| 线索 | 出现位置 | 揭示位置 | 画面要求 |
|---|---|---|---|
| 电影票 | 第 4 镜，产品经理桌面 | 第 14 镜 | 特写 1 秒，票上能看清片名和时间 |
```

## 台词

剧情台词和口播稿的规则大体相同：短、口语、一句一个意思。另外几条：

**台词要推动剧情或表现人物，不能只传递信息。**

```text
改前（只传递信息）：
产品经理：小林，这个需求需要修改一下，需要在今天下班前完成。
小林：好的，我知道了。

改后（推动剧情、表现人物）：
产品经理：小林，就改一个小地方哈。（把电脑转过来，屏幕上标了二十几个红圈）
小林：（盯着屏幕两秒）……好的好的，没问题哈。
```

**能用动作的地方不用台词。** 小林盯着屏幕两秒的沉默，比他说「这也太多了吧」更好笑。

**潜台词比明说好。** 人物很少直接说出真实想法。「没问题哈」背后是「问题大了」，观众看得懂，这就是喜剧感的来源。

**每句台词不超过两行字幕。** 竖屏字幕一行通常放 12–16 个字比较舒服，超过两行观众读不完。

## 场景设计：按你能拍的来

开发者做剧情号，最大的约束不是创意，是**场地和人手**。下班后能用的场景通常只有：家里（客厅、卧室、厨房、书桌）、小区楼下、公司（要征得同意）、咖啡馆（人少的时段，并且要事先问店家）。

写剧本前先列出你能用的场景，再在这个范围里写故事，而不是反过来。

### 场景卡

每个场景写一张卡：

```text
场景 1：办公室工位（实际：家里书桌）
- 时间：傍晚 6 点（窗帘拉上，开台灯，营造傍晚感）
- 需要的陈设：显示器、贴满便利贴、工牌、咖啡杯
- 出场人物：小林、产品经理
- 本场发生什么：产品经理来改需求，小林答应
- 预计时长：25 秒
- 注意：背后书架要清空私人物品；不要拍到窗外能认出小区的建筑
```

最后一行很重要。拍摄时要注意不暴露住址、工牌真名、真实公司 logo 等个人信息。

### 场景越少越好

| 场景数 | 一条 60 秒剧情 | 拍摄难度 |
|---|---|---|
| 1 个 | 最常见，靠台词和表演 | 低，一晚上能拍完 |
| 2 个 | 有空间变化，节奏更好 | 中，需要转场 |
| 3 个以上 | 像短片 | 高，一个人很难拍完 |

新手建议从「一个场景、两个人物」开始。

## 剧情脚本的写法格式

剧情脚本用「场景标题 + 动作 + 对白」的格式写，这是从影视剧本借来的通用格式，简化如下：

```text
第 1 场  办公室工位  傍晚  内景

（小林坐在工位前，显示器上贴满便利贴。他看了一眼手机：18:40，屏幕上消息「七点电影院门口见」。他开始收拾包。）

产品经理：（从画外走进来，笑着）小林——

（小林拉拉链的手停住。）

产品经理：就改一个小地方哈。
（把笔记本转过来，屏幕上二十几个红圈。）

小林：（盯着屏幕两秒）……好的好的，没问题哈。

（产品经理满意地走开。小林慢慢把包放回桌下。）
```

格式要点：

- **场景标题**：场次、地点、时间、内景 / 外景。剪辑和排拍摄顺序都靠它
- **动作写在括号里**，用现在时，只写镜头里能看到的东西。不写「小林心里很绝望」，写「小林慢慢把包放回桌下」
- **对白前写角色名**，对白里的表演提示放括号
- **画外音、旁白**写成「小林（画外音）：」或「旁白：」

这份文字脚本是下一步分镜表的输入。第 5 章会讲怎么把一场戏拆成镜头；第 7 章的剧情示例会把这场戏完整写完并拆成分镜。

## 剧情脚本模板

```text
【选题】一句话：谁 + 想要什么 + 被什么挡住 + 结果
【时长】__ 秒   【场景数】__   【角色数】__

【角色卡】（每个角色一张）
名字 / 一句话 / 想要 / 怕 / 第一眼识别 / 说话方式

【结构】
建立（0–__s）：
冲突（__–__s）：
升级（__–__s）：
结局 / 反转（__–__s）：

【线索表】
| 线索 | 出现位置 | 揭示位置 | 画面要求 |

【场景卡】（每个场景一张）
时间 / 陈设 / 人物 / 发生什么 / 时长 / 注意

【正文】
第 1 场  地点  时间  内/外景
（动作）
角色：（表演提示）台词
```

## 常见坑

| 坑 | 表现 | 改法 |
|---|---|---|
| 开头太慢 | 前 10 秒在交代背景 | 从冲突的前一秒开始 |
| 冲突模糊 | 看完不知道主角想要什么 | 第一个场景里让主角的「想要」可见 |
| 硬反转 | 结局突然冒出一个新信息 | 在前半段埋线索，写线索表 |
| 台词像说明书 | 角色在给观众讲解剧情 | 换成动作和潜台词 |
| 场景写得太大 | 写了地铁、商场、写字楼大堂 | 先列你能用的场景再写 |
| 角色太多 | 五六个人，一个人分饰不过来 | 合并角色，两人为主 |
| 照搬热门剧情 | 和对标账号几乎一样 | 借结构不借内容；结构拆解方法见[《账号定位与对标拆解》](../account-positioning/) |
| 冒犯性的笑点 | 嘲笑地域、性别、职业、外貌 | 自嘲最安全；内容审核规则见[《自媒体与短剧合规财税》](../media-compliance/) |

## 本章要点

- 剧情短片的骨架：建立、冲突、升级、结局；从冲突的前一秒开始
- 人物用一句话立住，「想要」和「怕」产生冲突，用视觉标签代替介绍
- 升级一到两次，每次更强；反转要意料之外、情理之中，用线索表成对管理
- 台词推动剧情或表现人物，能用动作就不用台词，潜台词比明说好
- 先列能用的场景再写故事；新手从一个场景两个人物开始
- 用「场景标题 + 动作 + 对白」格式写正文，它是分镜表的输入

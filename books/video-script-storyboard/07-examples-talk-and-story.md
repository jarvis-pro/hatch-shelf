# 示例一、二：知识口播与剧情短片

前六章讲了方法，这一章和下一章给五个完整示例。每个示例都按同样的四步走：选题卡 → 完整脚本 → 完整分镜表 → 拍摄清单。建议的用法是：找一个和你的选题最像的示例，把它的结构原样抄过去，只换内容。

这一章是前两个：知识口播和剧情短片。它们分别代表「靠嘴」和「靠演」两个极端。

示例中出现的人物、对话、场景都是为本书编写的。凡是需要真实数字的地方（比如电脑优化前后的开机时间），表里留了空，**拍的时候填你实测的数字**，不要照抄、也不要编。

## 示例一：知识口播「旧电脑别急着换」

### 选题卡

```text
- 一句话选题：旧电脑别急着换，先做这 3 件事
- 给谁看：用了三年以上 Windows 笔记本、不太懂电脑的上班族
- 看完得到：3 个能马上操作的步骤，不花钱
- 类型：知识口播（真人出镜 + 录屏插入）
- 目标时长：60–70 秒
- 平台和画幅：抖音 / 视频号，9:16 竖屏
- 我的语速：3.5 字/秒（自测）
- 开头钩子：你的电脑是不是开机要两分钟？
- 结尾动作：评论区说你的电脑型号和用了几年
- 必要素材：一台真的变慢的 Windows 电脑；三段录屏；优化前后开机时间实测
```

### 文字稿（带标记）

字数控制：65 秒 × 3.5 字/秒 ≈ 227 字，扣掉开头结尾的纯画面，正文控制在 200 字左右。

```text
【钩子 0–4s】
你的电脑 / 是不是开机要**两分钟**↑ / 开个网页都卡↑ //

【承诺 4–10s】
先别急着换。//
做完这**三件事**（伸三根手指）/ 不花**一分钱** / 大部分旧电脑 / 还能再撑一阵。//

【第一件 10–28s】
第一件 / 也是**最管用**的：/ 关掉开机自己跑的软件。//
[插：任务管理器录屏]
→ 右键开始按钮 / 任务管理器 / 点「启动应用」。//
状态是「已启用」的 / 除了杀毒软件和输入法 / 不认识的 / 全部**禁用**。//

【钩子句 28–31s】
光这一步 / 我这台电脑的开机时间 / 就少了**一半**。//

【第二件 31–45s】
第二件 / 清临时文件。//
[插：存储设置录屏]
→ 设置 / 系统 / 存储 / 临时文件 / 全选 / 删除。//
**下载文件夹**那一项 / 先别勾 / 里面可能有你要的东西。//

【第三件 45–58s】
第三件 / 很多人想不到：/ 浏览器**插件**。//
[插：浏览器扩展页录屏]
装了十几个插件 / 每个都在后台吃内存。//
用不上的 / 直接移除。//

【收尾 58–65s】
做完还是卡 / 那可能真是硬件的问题了。//
评论区 / 说说你的电脑型号 / 和用了几年 / 我帮你看看还值不值得救。
```

两个注意点：

- 「开机时间少了一半」是要在录屏时**实测**的。如果实测结果不是一半，就照实说「少了二十几秒」之类；如果没什么变化，换一句钩子，不要编
- 菜单路径以你录屏时的系统版本为准。Windows 的菜单名称在不同版本里会变，录屏前先在自己电脑上走一遍，台词跟着实际界面改

### 分镜表

景别约定：近景 = 胸部以上，特写 = 肩部以上。A 机：正面三脚架，平视。录屏用 Windows 自带的录屏或任意录屏工具，后期裁成竖屏或做成画中画。

每个镜头一项：粗体里是镜号、景别、运镜、时长，后面依次是画面、台词、字幕、音效、道具与场地、备注；为「无」的列省略，运镜较长时写在后面。

- **镜 1 · 特写 · 固定 · 4s**：画面：一台旧笔记本屏幕，开机转圈画面；画面右上角叠一个正在走的秒表；台词：我（画外）：你的电脑是不是开机要两分钟？开个网页都卡？；字幕：顶部：开机 __ 秒（填实测）；音效：BGM 起：轻，略带焦虑；秒表滴答；道具与场地：旧笔记本、书桌；备注：钩子画面，录真实开机过程，后期加速
- **镜 2 · 近景 · 固定 · 6s**：画面：我坐在书桌前正对镜头，伸出三根手指；台词：先别急着换。做完这三件事，不花一分钱，大部分旧电脑还能再撑一阵。；字幕：顶部：旧电脑别急着换 · 3 件事；音效：同上；道具与场地：书桌、背景书架（清空私人物品）；备注：A 机；手指在胸前，别挡脸
- **镜 3 · 近景 · 固定（后期缓推） · 3s**：画面：同上，表情认真；台词：第一件，也是最管用的：关掉开机自己跑的软件。；字幕：① 关掉开机自启；道具与场地：同上；备注：拍得比成片宽一点，留放大余量
- **镜 4 · 录屏 · 5s**：画面：鼠标右键开始按钮 → 任务管理器 → 启动应用页；运镜：录屏，后期放大鼠标附近；台词：（接上）右键开始按钮，任务管理器，点「启动应用」。；字幕：右键开始 → 任务管理器 → 启动应用；音效：鼠标点击声（后期）；道具与场地：旧笔记本；备注：关掉通知；桌面清空私人文件
- **镜 5 · 录屏 · 7s**：画面：启动应用列表，鼠标逐个点「禁用」；保留杀毒软件和输入法；运镜：录屏，后期放大列表；台词：状态是「已启用」的，除了杀毒软件和输入法，不认识的，全部禁用。；字幕：保留：杀毒 / 输入法；音效：点击声 ×3；道具与场地：同上；备注：禁用前先记下原状态，录完可恢复
- **镜 6 · 近景 · 固定 · 3s**：画面：我对镜头，略带得意；台词：光这一步，我这台电脑的开机时间就少了一半。；字幕：开机 __ 秒 → __ 秒（填实测）；音效：「叮」提示音；道具与场地：书桌；备注：数字必须实测；不是一半就改台词
- **镜 7 · 近景 · 固定 · 2s**：画面：同上；台词：第二件，清临时文件。；字幕：② 清临时文件；道具与场地：书桌
- **镜 8 · 录屏 · 6s**：画面：设置 → 系统 → 存储 → 临时文件，勾选、删除；运镜：录屏，后期放大；台词：（画外）设置，系统，存储，临时文件，全选，删除。；字幕：设置 → 系统 → 存储 → 临时文件；音效：点击声；道具与场地：旧笔记本；备注：路径以录屏时系统为准
- **镜 9 · 录屏 · 4s**：画面：鼠标停在「下载」选项上，画红框；运镜：录屏 + 后期红框；台词：（画外）下载文件夹那一项先别勾，里面可能有你要的东西。；字幕：「下载」先别勾！；音效：警示音（轻）；道具与场地：同上；备注：红框后期加
- **镜 10 · 近景 · 固定 · 3s**：画面：我对镜头，表情「你肯定没想到」；台词：第三件，很多人想不到：浏览器插件。；字幕：③ 删浏览器插件；道具与场地：书桌
- **镜 11 · 录屏 · 录屏 · 6s**：画面：浏览器扩展管理页，十几个插件，逐个点「移除」；台词：（画外）装了十几个插件，每个都在后台吃内存。用不上的，直接移除。；音效：点击声；道具与场地：旧笔记本、浏览器装好演示用插件；备注：提前装几个演示插件，不删自己真实在用的
- **镜 12 · 近景 · 固定 · 3s**：画面：我对镜头，语气放缓；台词：做完还是卡，那可能真是硬件的问题了。；音效：BGM 渐弱；道具与场地：书桌
- **镜 13 · 近景 · 固定 · 5s**：画面：同上，手指向下方（评论区方向）；台词：评论区说说你的电脑型号和用了几年，我帮你看看还值不值得救。；字幕：评论区：型号 + 用了几年；音效：BGM 收；道具与场地：书桌；备注：结尾停 1 秒再停机

**合计**：57s（实际念一遍约 60–65s）

几点说明：

- **13 个镜头里，A 机位的近景占了 7 个**，但它们是一次连续录完的，后期再切开插入录屏。所以拍摄量其实很小
- **景别变化靠录屏**：近景说话 → 录屏操作 → 近景说话，画面每 3–7 秒变一次
- 镜 3「后期缓推」：同一个机位，通过放大画面造成「靠近」的感觉，强调「最管用」

### 拍摄清单

```text
拍摄顺序
1. 录屏组（先做，因为要实测开机时间）
   ☐ 镜 1：优化前开机过程，录全程，记下秒数 ____
   ☐ 镜 4、5：任务管理器（禁用前截图记下原状态）
   ☐ 重启，再录一次开机，记下秒数 ____（填进镜 6 字幕和台词）
   ☐ 镜 8、9：存储设置
   ☐ 镜 11：浏览器扩展（先装好演示插件）
2. 出镜组（A 机一次录完，按段录）
   ☐ 镜 2–3、6–7、10、12–13，每段录 3 条，报段号
3. 空镜
   ☐ 键盘特写、笔记本合上、窗外

道具：旧笔记本（充满电）、演示用浏览器插件、书桌清理干净
器材：手机 + 三脚架、补光灯、领夹麦、提词器（放标记稿）
时间：录屏 40 分钟 + 出镜 30 分钟 + 空镜 10 分钟 ≈ 1.5 小时
```

先录屏后出镜，是因为台词里的数字要等实测之后才能定。这是「最不可控的先做」的典型例子。

## 示例二：剧情短片「就改一个小地方」

### 选题卡

```text
- 一句话选题：总说「没问题」的新人，在电影开场前被要求改需求，终于说了一次「不」
- 给谁看：职场新人、程序员、产品经理
- 看完得到：共鸣 + 一个小反转带来的爽感
- 类型：剧情短片，两个角色，两个场景
- 目标时长：45–60 秒
- 平台和画幅：抖音 / 视频号，9:16 竖屏
- 开头钩子：18:40 和「七点电影院门口见」，观众马上知道他要赶时间
- 结尾动作：字幕提问「你上次说『不』是什么时候？」
- 人手：我（演小林）+ 一个朋友（演产品经理）
- 场地：家里书桌（扮工位）、家门口（扮办公室门）
```

### 角色卡

```text
小林
- 一句话：入职三个月的前端，什么需求都接，从不说不
- 想要：七点赶到电影院
- 怕：被说态度不好
- 第一眼识别：灰色卫衣、工牌、显示器贴满便利贴
- 说话方式：「好的好的」「没问题哈」

产品经理
- 一句话：笑眯眯地加需求的人
- 想要：（观众以为）把需求塞给小林；（实际）也想准点下班
- 第一眼识别：衬衫、眼镜、抱着笔记本电脑
- 说话方式：句尾带「哈」，语气轻松
```

### 结构与线索

```text
建立（0–6s）：18:40，七点有约，开始收拾包
冲突（6–20s）：产品经理来改「一个小地方」，屏幕上二十几个红圈，小林答应
升级（20–30s）：快七点了，产品经理又来：「首页也顺便……」
结局（30–48s）：小林第一次说「今天做不完」；产品经理爽快答应，掏出同一场电影票

| 线索 | 出现位置 | 揭示位置 | 画面要求 |
|---|---|---|---|
| 电影票 | 镜 4，夹在产品经理笔记本侧面 | 镜 18、19 | 镜 4 里露出一角但不给特写；镜 19 大特写能看清影院和场次 |
| 产品经理也看表 | 镜 12，进门前低头看了眼手表 | 镜 18 | 动作自然，一闪而过 |
```

### 剧本正文

```text
第 1 场  工位  傍晚  内景

（小林坐在工位前，显示器上贴满黄色便利贴。手机亮起：18:40，消息「七点电影院门口见」。小林笑了，开始往双肩包里装东西。）

产品经理：（从画外走进来）小林——

（小林拉拉链的手停住。产品经理抱着笔记本电脑，侧面夹着一张票。）

产品经理：（笑）就改一个小地方哈。
（把笔记本转过来，屏幕上二十几个红圈。）

小林：（盯着屏幕两秒）……好的好的，没问题哈。

（产品经理满意地走开。小林把包放回桌下，开始飞快地打字。手机屏幕：18:55。）

（产品经理在门口低头看了眼手表，又走回来。）

产品经理：哦对了，首页也顺便——

（小林闭上眼，深吸一口气。）

小林：这个……今天做不完。明天上午给你，行吗？

（安静一秒。）

产品经理：行啊。

（小林愣住。）

产品经理：（从笔记本侧面抽出电影票晃了晃）我七点也有场电影。等你这句话等半天了。

（票的特写：同一家影院，同一场。）

第 2 场  办公室门口  傍晚  内景

（两人一起冲出门。）

字幕：你上次说「不」是什么时候？
```

### 分镜表

景别约定同示例一。机位：A = 书桌正面（拍小林），B = 书桌侧面（两人 / 产品经理），C = 门口。轴线：小林在左、产品经理在右。

格式同示例一。

- **镜 1 · 中景 · 固定 · 2s**：画面：小林坐在工位前打字，显示器贴满黄色便利贴；小林在画面左侧；字幕：18:40；音效：BGM 起：轻快；键盘声（同期）；道具与场地：书桌、显示器、便利贴、工牌（假名）；备注：A 机；台灯暖光营造傍晚
- **镜 2 · 大特写 · 固定 · 2s**：画面：手机屏幕亮起：18:40，消息「七点电影院门口见」；音效：消息提示音（后期）；道具与场地：道具手机（预设截图）；备注：手持；勿扰模式

- **镜 9 · 中景 · 固定 · 2.5s**：画面：产品经理满意地往右走出画面；小林慢慢把包放回桌下；音效：BGM 起：低沉版；道具与场地：双肩包；备注：B 机
- **镜 10 · 特写 · 固定 · 2s**：画面：小林的手在键盘上飞快打字；音效：键盘声加速；道具与场地：键盘；备注：手持

## 本章要点

- 每个示例都走四步：选题卡 → 脚本 → 分镜表 → 拍摄清单，结构可以直接抄
- 知识口播：一个机位连续录完，靠录屏插入制造画面变化；需要实测的数字先测后写台词
- 剧情短片：角色卡 + 线索表 + 剧本正文 + 分镜表；线索第一次出现时不给特写，揭示时给大特写
- 拍摄顺序先排外援、再排难的、手持特写放最后
- 示例里的数字、品牌、名字都不要照抄：实测数字自己填，品牌用虚构的
